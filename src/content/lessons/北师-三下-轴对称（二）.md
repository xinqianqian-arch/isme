> **一句话备课结论**：上一课学会“判断”轴对称图形，这一课要学会“做”和“想”：把纸对折，**贴着折痕**画出一半，剪下展开就是轴对称图形；反过来，看到一半能想出整体。剪不难，难的是“想”——学生要在脑子里把一半沿对称轴**翻**过去，而且翻过去后，离对称轴近的还近、远的还远。

## 一、教材解读

### 前后联系

- **已经学过**：上一课《轴对称（一）》认识了轴对称图形和对称轴，会用对折的方法判断；二年级上册《折一折，做一做》用“折—画—剪”剪过对称的图案。
- **本课要学**：经历得到轴对称图形的过程，会剪出简单的轴对称图形；给出轴对称图形的一半和对称轴，能想象、描述或剪出另一半；能根据对折剪纸的情况推想展开后的样子。
- **后面要用**：本单元最后的《小小设计师》要用轴对称设计图案、补全图案；以后的年级还会在方格纸上画轴对称图形的另一半，那时用的正是本课“近的还近、远的还远”的道理。

所以这节课是轴对称从“认”走向“用”的一步。**会剪只是手上功夫，会“想”才是空间观念。**

### 新旧教材变化

- **目标没有变**：旧版《轴对称（二）》就要求“给出简单轴对称图形的一半和对称轴，能直观地描述（或剪出）另一半”，新版保留了这条主线。
- **任务更完整**：从新教材配套的教学资料看，本课大体包括三件事——剪出轴对称图形、由一半想整体（补全）、对折剪纸后推想展开的样子。
- **用途更明确**：新版在单元末增设了《小小设计师》，这节课学会的“剪”和“补”，要直接用在后面的设计里。

对备课的影响是：学生二年级已经会“折—画—剪”，**这节课不能停在“再剪一次”，而要追问“为什么要贴着折痕画”“展开后会是什么样”**，把操作经验提升为可以说清楚的道理。

### 编排意图

教材沿着“做—想—推”的顺序展开：先动手剪，总结出“对折—贴着折痕画一半—剪—展开”的方法；再反过来，看一半想整体；最后推想对折剪孔后展开的样子。

![四步图：第一步把一张纸沿中线对折；第二步在对折的纸上贴着折痕画出半个花瓶，花瓶的上下两头都碰到折痕；第三步沿线剪下，剪下的是两层的半个花瓶；第四步展开，得到一个完整的轴对称花瓶，中间是对称轴](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-02/lesson-02/steps.svg "剪轴对称图形四步：对折、贴着折痕画一半、沿线剪下、展开")

这三件事背后是同一个道理：**轴对称图形的两侧，是同一半沿对称轴“翻”过去得到的**。剪纸时纸替我们翻，想象时要在脑子里翻。

## 二、学情分析

**已有基础**：会判断轴对称图形、会找对称轴；二年级剪过对称图案，会用剪刀；对剪纸作品有兴趣。

**可能的困难**：

1. **半个图形没贴着折痕画**：剪出来是两块分开的图形，不是一个完整的轴对称图形。
2. **在对折的纸上画了整个图形**：展开后得到两个一样的图形，而且也没连在一起。
3. **想整体时把一半“搬”过去**：把左边的一半原样平移到右边，方向没有反过来。
4. **剪孔题只看个数、不看位置**：知道展开后有 4 个洞，却说不清每个洞在哪，离折痕近的、远的分不清。
5. **多次对折想不清层数**：连续对折后剪，展开能得到几个图形，容易数错。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 经历“对折、画一半、剪、展开”的过程，会剪出简单的轴对称图形，能说出为什么要贴着折痕画一半。（空间观念）
2. 给出轴对称图形的一半和对称轴，能想象并描述（或剪出）整个图形。（几何直观）
3. 能根据对折剪纸的情况推想展开后的图形，并用“离折痕近的还近、远的还远”说明理由。（推理意识）
4. 在剪纸创作中感受对称美和传统文化，体验动手创作的乐趣。

**教学重点**：会剪简单的轴对称图形；能由轴对称图形的一半想出整体。

**教学难点**：准确想象展开后的图形：位置、远近不变，左右方向相反。

## 四、教学过程

### 1. 情境导入（4 分钟）

**一个花瓶，只画一半？** 出示一幅剪纸花瓶，再出示对折的红纸上只画了半个花瓶的样子。

![一个孩子坐在桌前，桌上从左到右放着：对折的红纸上贴着折边画着半个花瓶，一把剪刀和碎纸屑，展开后左右对称、中间有折痕的红色剪纸花瓶](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-02/lesson-02/scene.webp "导入画面：纸上只画了半个花瓶，剪下展开却是一个完整的花瓶")

- 提问：只画了一半，剪下来展开，为什么是一个完整的花瓶？
- 学生会说“因为纸是对折的”“剪一次就剪了两层”。
- 再追问：**那这一半，画在纸的哪个位置都可以吗？** 不急着回答，让学生带着问题去剪。

> **设计意图**：从上一课“对折后两侧完全重合”出发，把问题从“是不是”推进到“怎么做”。“画在哪儿”这个追问先不揭底，留给学生在操作中自己发现。

### 2. 动手剪，发现方法（12 分钟）

1. **放手试剪**：每人一张长方形彩纸，任选花瓶、小衣服或自己喜欢的图案，试着剪一个轴对称图形。
2. **展示作品**：老师有意挑出三种作品贴在黑板上：一个完整的轴对称图形；两块分开的半个图形；两个分开的完整图形。
3. **对比讨论**：**同样是对折剪，为什么有人剪出一个，有人剪出两块？** 请剪成两块的同学把折好的纸还原，大家一起找原因。
4. **得出方法**：半个图形要**贴着折痕**画，折痕那里不剪开，展开后两半才能连成一个；只画一半就够了，另一半由纸“翻”出来。
5. **小结步骤**：对折 → 贴着折痕画一半 → 沿线剪下 → 展开（见上面四步图）。
6. **再剪一次**：用总结的方法再剪一个，同桌互相检查：对称轴在哪里？对折回去能不能完全重合？

> **设计意图**：方法不是老师告诉的，而是从“剪错的作品”里找出来的。剪成两块的作品正是最好的教学资源，学生亲眼看到原因，记得比口诀牢。

### 3. 看一半，想整体（10 分钟）

1. **先想**：出示几个轴对称图形的一半和对称轴（比如半个花瓶、半件上衣），请学生闭上眼睛想：整个图形是什么样子？
2. **再说**：请学生用手在空中比画另一半，说说“这一边往外凸，那一边也往外凸”。
3. **后验证**：用剪下的半个图形对折剪，或把半张图沿对称轴折到透明纸上描下来，验证自己想得对不对。
4. **方格纸上更准确**：在方格纸上补全一个图形。关键提问：**另一边的点画在哪里？** 引导学生数格子：这个点离对称轴几格，另一边对应的点也离对称轴几格。

![方格纸上竖着一条对称轴，左边用实线画着半个小房子，右边用虚线补全；左边房檐的点离对称轴 3 格，右边对应的点也是 3 格；左边墙角离对称轴 2 格，右边也是 2 格；右侧写着找关键点、数格子、描点连线三步](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-02/lesson-02/grid-half.svg "方格纸上补全：每个关键点离对称轴几格，另一边对应的点也离几格，再描点连线")

方格纸这一步是给“想”找依据，不要求人人当堂画得又快又准；它会在《小小设计师》和以后的学习中继续用到。

### 4. 推一推，剪孔游戏（8 分钟）

**对折后剪两个洞，展开是什么样？** 先想、再选、最后剪一剪验证。

![左边是一张对折的纸，折痕在左边，靠近折痕的上方剪了一个圆，离折痕较远的下方剪了一个圆；右边是四个选项：A 左边两个洞的位置是右边平移过去的，B 只有两个洞，C 四个洞左右对称，上面一对靠近中间、下面一对离中间远，D 左边的远近和右边弄反了](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-02/lesson-02/holes.svg "答案：C。展开后上面一对洞都离折痕近、下面一对都离折痕远；A 是把一半平移过去了，B 忘了两层纸都被剪了，D 把远近弄反了")

1. 每人先独立选，再说理由。
2. 重点讨论 A 和 D：**A 错在哪里？** ——它把右边“搬”过去了，没有“翻”过去。**D 错在哪里？** ——离折痕近的洞翻过去应该还近，它变远了。
3. 全班动手剪一剪，展开验证。
4. 小结：对折剪出的洞，展开后**个数翻倍，离折痕近的还近、远的还远**。

### 5. 创作展示（4 分钟）

用学到的方法，两分钟剪一个自己设计的轴对称作品。同桌交换，互相指出对称轴，对折检查是否完全重合。挑两三件贴在黑板上，说说作者是怎么想的。

### 6. 课堂小结（2 分钟）

1. 回到导入：**为什么只画半个花瓶就够了？** ——因为纸对折了，剪一次两层，展开就是沿折痕翻过去的另一半。
2. 请学生用一句话说出剪轴对称图形的诀窍：“贴着折痕画一半。”
3. 预告：轴对称图形是“翻”出来的，下节课我们看看图形还能怎么动。

## 五、趣味设计

4 个可以直接用的小设计：

1. **剪纸口诀**：“对折纸，贴折痕，画一半，剪下来，展开看。”边说边做，五个动作对应五句话。
2. **猜猜我是谁**：老师把剪好的作品对折，只露出一半，学生猜展开后是什么。猜对的同学说说“我是看哪儿猜出来的”。也可以反过来，学生出题考老师。
3. **手拉手小人**：把长纸条像扇子一样来回折成几层，画一个小人，两只手都碰到纸的两边，剪下展开就是一串手拉手的小人。先让学生猜能剪出几个，再剪一剪验证。
4. **剪纸文化墙**：把全班的作品贴成一面墙，每件作品用彩色虚线标出对称轴，下面配一句吉祥话，班级布置和数学作业一举两得。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象概念变成可以操作的东西、让每个学生拿到适合自己的练习**。这节课要摸清的是：学生想象展开时，到底是在“翻”，还是在“搬”。

### 课前：学情前测

**用 3 道小题看出学生是“翻”还是“搬”。** 课前发一张小卡片：

1. 对折的纸上有三种画法：贴着折痕画一半、离开折痕画一半、画整个图形，哪种能剪出一个完整的轴对称图形？
2. 对折后剪去两个圆，展开后是哪个？（四个选项，含“平移过去”和“远近弄反”的干扰项）
3. 给出半个图形和对称轴，画出另一半的大致样子。

收集答案后交给 AI 按错因归类，课上就知道“剪孔游戏”该重点讨论哪个干扰项。

可以直接复制的提示词：

```
我是小学三年级数学老师，明天要上北师大版三年级下册第二单元《轴对称（二）》。
课前小测有 3 题：①对折的纸上三种画法，哪种能剪出完整的轴对称图形；
②对折后剪去两个圆，展开后是哪个（A 平移过去、B 只有两个洞、C 正确、D 远近弄反）；
③给出半个图形和对称轴，画出另一半（我会用文字描述学生画的情况）。
下面是全班的答案，每行一名学生：
（粘贴答案）
请帮我：
1. 按错因分类（例如“没贴着折痕”“把一半平移过去”“忽略了两层纸”“远近弄反”），给出每类人数和典型答案；
2. 说明每类错误背后学生可能是怎么想的；
3. 针对人数最多的错因，设计一个 3 分钟以内、需要动手剪或折的课堂活动。
```

### 课中：先想后剪，再看翻折

**先让学生在纸上画出“我想的样子”，再剪、再看课件。** 剪纸本身就是最好的验证，互动课件的作用是让“翻”这个过程看得见：

- **先画后展开**：剪孔题里，学生先在答题纸上画出想象中的展开图，再点课件里的“展开”按钮，看纸慢慢翻开，对照自己的画。
- **拖动小圆**：学生拖动折纸上的洞，靠近折痕或远离折痕，课件同步显示展开后另一边的洞也跟着靠近或远离——“近的还近、远的还远”是学生自己拖出来的。
- **翻过去和搬过去对比**：同一个半图形，课件一次演示“沿对称轴翻过去”，一次演示“平移过去”，让学生说哪一个才是剪纸的结果。
- **作品快速检查**：学生作品拍照投屏，课件把一半翻折叠到另一半上，重合不重合一目了然。

### 课后：分层练习

**按“没贴折痕”“搬过去”“远近错”三类错因布置。** 没贴折痕的学生，多做“三种画法选一选”；把一半搬过去的学生，多做“看一半想整体”；已经掌握的学生，挑战多次对折剪纸。

可以直接复制的提示词：

```
请为北师大版三年级下册《轴对称（二）》生成课后练习，分三层：
- 基础：剪轴对称图形的步骤填空和判断 4 题，针对“半个图形没贴着折痕画”的错误；
- 提升：对折剪孔推想展开图 4 题，用文字描述洞的位置（如“离折痕 1 厘米”“离折痕 3 厘米”），针对“把一半平移过去”和“远近弄反”的错误；
- 挑战：来回折纸剪“手拉手小人” 2 题，问能剪出几个。
要求：用文字描述，不要让我直接使用 AI 画的图；不超出三年级下册范围；每题附答案和一句话讲解。
```

再给家长一个亲子剪纸任务：

```
请用三年级家长能听懂的话，写一张不超过 200 字的“亲子剪纸任务卡”。
今天孩子学的是北师大版三年级下册《轴对称（二）》：把纸对折，贴着折痕画出图形的一半，剪下展开就是轴对称图形。
任务：请孩子教家长剪一个轴对称图形，剪之前先让孩子说说展开后会是什么样；
提醒家长注意剪刀安全。语气亲切，不用专业术语。
```

### 教研：AI 听课伙伴

**用学生作品复盘，而不只是用课堂实录。** 课后把全班作品按“完整的一个”“分开的两块”“两个完整图形”分好类，把数量和几段学生的解释交给 AI，请它分析：“对比讨论”之后，第二次剪的正确率提高了多少；“剪孔游戏”中哪个干扰项最难排除。再请它起草说课稿中“难点突破”这一段的初稿，老师在初稿上修改。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：例题图形、附页、练习题号，AI 可能会编，一律对照课本核实。
2. **演示不替代动手剪**：先想、再剪、最后看动画；剪刀和纸是这节课最好的“课件”，动画只负责把过程放慢。
3. **AI 画的对称图不能直接用**：AI 生成的剪纸图案常常左右不对称、洞的位置也不准，练习用图要用课本图，或老师用课件按坐标画好的图。

十一课件的互动课件就是按这套思路设计的：先画后展开的剪孔游戏、可以拖动的小洞、“翻过去”和“搬过去”的对比演示，都围绕“让学生先想、再动手验证”来做。

## 七、板书设计

## 八、分层作业

括号里是答案要点。

**基础**

1. 用对折的方法剪一个轴对称图形，用彩笔画出它的对称轴。
2. 填空：剪轴对称图形时，先把纸（对折），再贴着（折痕）画出图形的（一半），沿线剪下后（展开）。

**提升**

3. 把一张纸对折，沿折痕剪去一个半圆，展开后是什么？（纸中间出现一个完整的圆形洞）
4. 一张纸对折后，在离折痕 1 厘米和 3 厘米的地方各剪一个小洞，展开后一共有几个洞？各离折痕多远？（4 个；折痕两边各有一个离折痕 1 厘米、一个离折痕 3 厘米的洞）

**挑战**

5. 把一张长纸条像扇子一样来回折，折成 4 层，在最上面一层画一个小人，两只手都碰到纸的两边，剪下展开能得到几个手拉手的小人？（4 个）
6. 在方格纸上画一条竖直的对称轴和一个图形的一半，请同桌补全另一半，再互相检查：每个关键点到对称轴的格数是不是相等。（答案不唯一）

## 九、易错点与应对

1. **半个图形没贴着折痕画**：剪出两块分开的图形。应对：把剪错的作品还原成对折的样子，让学生看清折痕处被剪断了；配一张正误对比图（见下图）。
2. **在对折的纸上画整个图形**：没理解“另一半由纸翻出来”。应对：追问“剪一次剪了几层纸”，让学生说清楚两层的关系。
3. **想整体时把一半平移过去**：方向没有反过来。应对：用透明纸描下一半，沿对称轴翻过去，和平移过去的样子对比。
4. **剪孔题弄错远近**：只记得个数翻倍。应对：口诀“近的还近，远的还远”，并让学生用尺子量一量两边的洞到折痕的距离。

## 十、反思与说课

- **反思重点**：学生能不能说出“为什么要贴着折痕画”？剪孔题选对的学生，能不能说清“近的还近、远的还远”？只会剪、说不出道理，说明“对比讨论”环节被老师讲替代了。
- **说课可以突出**：本课沿“做—想—推”三步，从操作走向想象；把学生剪错的作品作为教学资源，用“翻过去”和“搬过去”的对比突破想象展开图这一难点，为单元末《小小设计师》和以后在方格纸上画轴对称图形打基础。

## 常见问题

**《轴对称（二）》这节课怎么导入比较好？**
出示一幅剪纸花瓶，再出示对折的纸上只画了半个花瓶，问“只画一半，为什么展开是一整个”，接着追问“这一半画在哪儿都可以吗”。前一个问题连接上一课，后一个问题留给学生在剪纸中自己发现。

**学生剪出来总是两块分开的，怎么办？**
不要急着纠正，把这样的作品贴到黑板上当教学资源。请学生把它还原成对折的样子，大家一起找原因：半个图形没碰到折痕，折痕处被剪断了。再剪一次，学生就记住了“贴着折痕画”。

**看一半想整体，是把一半“翻”过去还是“搬”过去？**
是“翻”过去。轴对称图形的另一半，是这一半沿对称轴翻折得到的，左右方向是相反的，离对称轴近的点翻过去还近、远的还远。如果把一半平移过去，方向不会反，得到的就不是轴对称图形。

**新教材为什么在轴对称后面安排《小小设计师》？**
新教材重视让知识落到应用上。学生在这一课学会剪轴对称图形、由一半补全整体，单元末的《小小设计师》就要用这些本领，综合轴对称、平移和旋转设计图案。所以这节课要让学生真正会“想”，不只是会剪。

**AI 在这节课里最该用在哪？**
最该用在三件事上：课前用小测摸清学生想象展开图时是“翻”还是“搬”，课中让学生先画出自己的想象、再用可拖动的翻折演示验证，课后按“没贴折痕”“搬过去”“远近错”三类错因生成分层练习。
