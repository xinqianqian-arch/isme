> **一句话备课结论**：《包装》把小数乘法变成一套能动笔的算法：先按整数乘法算，再看两个乘数一共有几位小数，就从积的右边数出几位点上小数点。难点不在“乘”，而在“点”：0.85×0.4 先去掉 0 再点，会得到 0.034；0.13×0.2 位数不够，忘了补 0。学生能说出**288 个 0.01**、**340 个 0.001**，小数点就不会点错。

## 一、教材解读

### 前后联系

- **已经学过**：多位数乘法竖式；本单元《买文具》用“几个 0.1”算小数乘整数，《街心广场》借助方格图和“转化成整数相乘”理解了 0.3×0.2＝0.06；第一单元学过“小数的末尾添上 0 或去掉 0，小数的大小不变”。
- **本课要学**：用竖式计算一位小数乘一位小数、两位小数乘一位小数；发现积的小数位数等于两个乘数的小数位数之和；会处理积末尾的 0，位数不够时在前面补 0。
- **后面要用**：下一课《蚕丝》算 1.2×1.25、0.35×300，总结“计算小数乘法时要注意什么”，并讨论积和乘数的大小；《手拉手》做小数混合运算；单元复习第 47 页用 3.4×1.2 的竖式回顾“34 个 0.1 与 12 个 0.1 相乘，是 408 个‘0.1×0.1’”。

上一课回答“为什么积会变小”，这一课回答“怎样又快又准地算”。到这一课结束，学生应该能独立、准确地用竖式算小数乘法。

### 新旧教材变化

旧版北师大教材里，《包装》在四年级下册“小数乘法”单元，例题是 2.6×0.8 和 2.4×0.85，每道题先估一估再算。新版放在**五年级上册第三单元第 3 课**，备课时要注意三点：

1. **例题数据变了，两个乘数都可以大于 1**：包装纸每米 2.4 元、用 1.2 m，彩带每米 0.85 元、用 0.4 m。2.4×1.2 要写两层部分积（48 和 24），是真正的“两位数乘两位数”竖式，正好用来说明竖式和整数乘法一模一样。
2. **用计数单位说理更突出**：女孩说“24 个 0.1 乘 12 个 0.1 是 288 个 0.01”，男孩说“85 个 0.01 与 4 个 0.1 相乘，是 340 个……”。这和 2022 年版课标“感悟计数单位在运算中的作用”的要求一致。
3. **“积的小数位数”表格放到了这一课**：旧版放在《街心广场》，新版先在上一课用面积讲清道理，这一课再用 2×0.3、0.2×0.3、0.13×2、0.13×0.2 四个算式归纳规律。新版例题里没有专门的估一估，估算集中放在《蚕丝》“积一定比乘数大吗”和新增的《购物》，教学时仍建议算完用估算检查。

### 编排意图

教材第 39～40 页的线索是：**情境 → 两种想法算包装纸 → 末尾有 0 的彩带 → 归纳位数规律 → 练习应用**。

1. **情境**：三个孩子包礼品盒，包装纸 2.4 元/m，彩带 0.85 元/m；“包装一个礼品盒要用 1.2 m 长的包装纸，还要用 0.4 m 长的彩带。”
2. **买包装纸需要多少元**：男孩说“2.4 乘 10，1.2 乘 10……”，用箭头把 2.4×1.2 变成 24×12＝288，积再“÷（　）”；女孩说“24 个 0.1 乘 12 个 0.1 是 288 个 0.01……”，写出 2.4×1.2＝2.88（元）和 24×12 的竖式。
3. **买彩带需要多少元**：女孩说“340 要除以……”，箭头里的“×（　）”“÷（　）”留给学生填；男孩说“85 个 0.01 与 4 个 0.1 相乘，是 340 个……”，写出 0.85×0.4＝0.340＝0.34（元），旁边提示“小数末尾的 0 可以去掉”。
4. **积的小数位数与乘数的小数位数有什么关系**：填表算 2×0.3＝0.6、0.2×0.3、0.13×2、0.13×0.2，记录两个乘数和积的小数位数。男孩发现“积的小数位数是两个乘数的小数位数之和”；女孩用计数单位解释“0.2×0.3……结果是 6 个 0.01，是两位小数”。
5. **练一练**：① 计算器的小数点显示不出来，0.7×7.8、1.3×0.25、1.44×3.98 只显示 546、0325、57312；② 蛋糕每千克 9.5 元，买 0.7 kg；③ 根据 13×12＝156 填出积是 15.6、1.56、0.156、156 的算式；④ 草原牛的身高、体重分别是蒙古牛的 1.2 倍、1.4 倍，蒙古牛身高 1.2 m、体重 0.33 t。

两道例题有分工：2.4×1.2 讲清“竖式怎么写、积是几个 0.01”；0.85×0.4 专门制造一个“末尾有 0”的积，逼学生想清楚**先点小数点，再去 0**。表格里的 0.13×0.2 又埋了一个“位数不够要补 0”的情况，三个难点在两页里都出现了。

## 二、学情分析

**已有基础**：会用竖式算多位数乘法；能用“几个 0.1”“转化成整数”解释 0.3×0.2＝0.06；知道小数末尾的 0 可以去掉。

**可能的困难**：

1. **竖式按小数点对齐**：照着加减法的习惯，把 0.85×0.4 的 4 写在 8 下面，乘的时候数位乱了。
2. **只数一个乘数的位数**：2.4×1.2 写成 28.8，只看到“一位小数”。
3. **先去 0 再点**：0.85×0.4，先把 340 写成 34，再点三位，得到 0.034。
4. **位数不够不补 0**：0.13×0.2，整数积是 26，直接写成 0.26。
5. **会数不会说**：能背“积的小数位数是两个乘数的小数位数之和”，说不出为什么是“之和”。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 经历用转化和计数单位计算小数乘法的过程，理解小数乘法竖式的道理。（推理意识）
2. 发现积的小数位数等于两个乘数的小数位数之和，能用竖式正确计算小数乘法，会处理积末尾的 0 和位数不够补 0 的情况。（运算能力）
3. 解决包装、买蛋糕、比身高体重等实际问题，体会小数乘法的用处。（应用意识）
4. 养成算完检查的习惯：数一数位数，估一估大小。

**教学重点**：用竖式计算小数乘法，正确确定积的小数点位置。

**教学难点**：理解积的小数位数为什么是两个乘数的小数位数之和；处理积末尾的 0 和位数不够补 0。

## 四、教学过程

### 1. 复习导入（4 分钟）

**礼品盒要花多少钱？** 先用一道口答题复习：0.3×0.2 为什么等于 0.06？请学生用“6 个 0.01”说一说。再出示第 39 页的包装情境。

![三个孩子围着桌子包礼物：左边的男孩展开一卷波点包装纸，中间的女孩双手拉着一条黄丝带，右边的男孩在蓝色礼品盒上系蝴蝶结，桌上还有一个包好的绿色礼盒、剪刀和一卷丝带](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-03/lesson-03/wrapping.webp "导入画面：包一个礼品盒要用 1.2 m 包装纸和 0.4 m 彩带，各要多少元？")

- 请学生找出信息：包装纸 2.4 元/m，用 1.2 m；彩带 0.85 元/m，用 0.4 m。
- 提问：**买包装纸需要多少元？先估一估。** 学生说出：比 1 米多一点，比 2.4 元多一点，肯定不到 4.8 元（2 米的价钱）。

### 2. 买包装纸（10 分钟）

1. 学生列式 2.4×1.2，独立想办法算，可以参考上一课的方法。
2. 汇报两种想法：
   - **转化**：2.4 乘 10 是 24，1.2 乘 10 是 12，24×12＝288。两个乘数各乘了 10，积就乘了 100，所以 288 要除以 100，是 2.88。
   - **计数单位**：2.4 是 24 个 0.1，1.2 是 12 个 0.1，0.1×0.1＝0.01，所以积是 288 个 0.01，是 2.88。
3. 规范竖式：两个乘数末位对齐，先按 24×12 算出 288，再从右边数出两位点上小数点。关键提问：**竖式里的 288 表示 288 个什么？为什么？** 学生说出：288 个 0.01，因为 0.1 乘 0.1 是 0.01。

![两张卡片：左边买包装纸，2.4×1.2 的竖式，部分积 48 和 24，积 2.88，旁边标出 2.4 是 24 个 0.1，1.2 是 12 个 0.1，2.88 是 288 个 0.01，下面写一位加一位等于两位小数；右边买彩带，0.85×0.4 的竖式，积 0.340，末尾的 0 划掉，旁边标出 85 个 0.01、4 个 0.1、340 个 0.001，下面写先点小数点，再去掉 0](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-03/lesson-03/vertical.svg "竖式和整数乘法写法一样，多出来的只有一步：看清积是“几个 0.01”还是“几个 0.001”，再点小数点")

4. 用估算检查：2.88 元比 2.4 元多一点，不到 4.8 元，和开头的估计一致。

> **设计意图**：竖式本身学生早就会写，真正新的只有“点小数点”。先让学生用转化和计数单位两种想法各说一遍，再落到竖式上，学生就知道竖式里的 288 不是“二百八十八”，而是 288 个 0.01。有了这个道理，后面去 0、补 0 都有依据，不用死记。

### 3. 买彩带（8 分钟）

1. 学生独立计算 0.85×0.4。巡视时收集 0.34 和 0.034 两种答案。
2. 请写 0.034 的学生说过程：85×4＝340，340 末尾有 0 先去掉，34 再点三位。关键提问：**0.85 是几个 0.01？0.4 是几个 0.1？积是几个什么？** 学生说出：85 个 0.01 乘 4 个 0.1，积是 340 个 0.001，也就是 0.340。
3. 追问：**0.340 末尾的 0 能不能先去掉再点小数点？** 学生说出：不能，先去掉 0 就变成 34 个 0.001 了，小了 10 倍。点好小数点之后，0.340 末尾的 0 才可以去掉，写成 0.34。
4. 强调竖式写法：0.85 和 0.4 末位对齐，4 写在 5 下面，不是小数点对齐。

### 4. 发现规律（8 分钟）

1. 学生独立完成第 40 页的表格：

| 算式 | 2×0.3＝0.6 | 0.2×0.3＝0.06 | 0.13×2＝0.26 | 0.13×0.2＝0.026 |
| --- | --- | --- | --- | --- |
| 第一个乘数的小数位数 | 0 | 1 | 2 | 2 |
| 第二个乘数的小数位数 | 1 | 1 | 0 | 1 |
| 积的小数位数 | 1 | 2 | 2 | 3 |

2. 关键提问：**积的小数位数和两个乘数的小数位数有什么关系？** 学生说出：积的小数位数是两个乘数的小数位数之和。
3. 追问：**为什么是“之和”？** 请学生仿照教材女孩的说法解释 0.13×0.2：0.13 是 13 个 0.01，0.2 是 2 个 0.1，0.01×0.1＝0.001，结果是 26 个 0.001，是三位小数。
4. 关键提问：**0.13×0.2 的整数积只有 26 两位，要点三位小数，怎么办？** 学生说出：在前面补 0，写成 0.026。
5. 小结计算方法：先按整数乘法算，再看两个乘数一共有几位小数，就从积的右边数出几位点上小数点；积末尾有 0，先点小数点再去 0；位数不够，在前面用 0 补足。

### 5. 练一练（8 分钟）

1. **第 1 题，计算器坏了**：0.7×7.8＝5.46，1.3×0.25＝0.325，1.44×3.98＝5.7312。关键提问：**5.7312 合理吗？怎么检查？** 学生说出：一共 2＋2＝4 位小数；1.44 约是 1.5，3.98 约是 4，积约是 6，5.7312 合理。
2. **第 2 题，买蛋糕**：9.5×0.7＝6.65（元）。请学生说说积为什么比 9.5 小：买的不到 1 千克。
3. **第 3 题，根据 13×12＝156 填数**：答案不唯一，如 1.3×12＝15.6，1.3×1.2＝1.56，0.13×1.2＝0.156，13×12＝156（也可以写 1.3×120）。请学生说说自己是怎样凑出小数位数的。
4. **第 4 题，草原牛**：身高 1.2×1.2＝1.44（m），体重 0.33×1.4＝0.462（t）。时间不够可以留作课后作业。

### 6. 课堂小结（2 分钟）

关键提问：**用竖式算小数乘法，你会提醒同学注意哪三件事？** 学生说出：末位对齐按整数乘；数清两个乘数一共几位小数；先点小数点再去 0，位数不够补 0。回到礼品盒：包一个礼品盒，包装纸 2.88 元，彩带 0.34 元。

## 五、趣味设计

4 个可以直接用的小设计：

1. **计算器修理工**：老师用计算器算出整数积（如 57312），只报数字不报小数点，学生 10 秒内说出 1.44×3.98 的积，再用估算检查。
2. **小数点磁贴**：给每组一套数字卡和一个小数点磁贴，老师出题，组员先摆出整数积，再由一人“数位数、贴小数点”，其他人检查。
3. **先点后去口令**：老师故意写 0.85×0.4＝0.034，学生齐声喊“先点后去”；写 0.13×0.2＝0.26，学生喊“位数不够，补 0”。
4. **礼品包装店**：开一家包装店，价目表上写包装纸、彩带每米的价钱，顾客说要几米，店员用竖式算钱，收银员用估算检查，算错了要“重新包装”。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象的算理变成可以操作的东西、让每个学生拿到适合自己的练习**。这节课的错误集中在“点小数点”这一步，类型很固定，正好交给 AI 去归类、去出针对性的练习。

### 课前：学情前测

**先看学生的小数点错在哪一类。** 课前发 4 道小题：2.4×1.2、0.85×0.4、0.13×0.2，再加一道“说一说 2.4×1.2 的积是几个什么”。把答案交给 AI，按“只数一个乘数、先去 0 再点、位数不够不补 0、竖式对齐错”归类。

可以直接复制的提示词：

```
我是小学五年级数学老师，明天要上北师大版五年级上册第三单元“小数乘法”第 3 课《包装》。
课前小测有 4 题：① 2.4×1.2；② 0.85×0.4；③ 0.13×0.2；④ 说一说 2.4×1.2 的积是几个什么。
下面是全班的答案和竖式照片的文字记录，每行一名学生：
（粘贴答案）
请帮我：
1. 按错因分类：只数了一个乘数的小数位数、先去掉末尾的 0 再点小数点、位数不够没有补 0、竖式按小数点对齐、完全正确，给出每类人数和典型答案；
2. 看第 ④ 题，统计有多少学生能用“288 个 0.01”说理；
3. 建议课上“买彩带”环节先展示哪种错误让学生辨析。
```

### 课中：先算，再数单位

**先让学生自己点小数点，再用课件把“几个 0.01”翻译出来。**

- **拖动小数点**：屏幕上出现整数积 288，学生把小数点拖到自己认为的位置，课件同时给出估算范围“比 2.4 多一点，不到 4.8”，点在 28.8 的学生自己就会发现太大了。
- **计数单位翻译**：学生说完自己的想法后，课件把 2.4×1.2 一步步翻译成“24 个 0.1 × 12 个 0.1 → 288 个 0.01”，再把 0.85×0.4 翻译成“340 个 0.001”，让“之和”有画面。
- **错例诊所**：课件依次给出 0.034、0.26、28.8 三份“病历”，全班先判断错在哪一步，再看课件用红色标出出错的那一步。
- **全班即时作答**：第 40 页练一练第 1 题三道题每人作答，课件显示答案分布，老师只讲错得最集中的那一题。

### 课后：分层练习

**按错因布置，不是按题量布置。** 先去 0 的学生，多练积末尾有 0 的题，如 0.25×1.6、0.45×0.2；不补 0 的学生，多练 0.07×0.3 这类积很小的题；已经掌握的学生，挑战根据一个整数乘法写出多个小数乘法。

可以直接复制的提示词：

```
请为北师大版五年级上册《包装》（小数乘法竖式）生成课后练习，分三层：
- 基础：6 道竖式题，其中 2 道积末尾有 0（如 0.25×1.6）、2 道积的位数不够要补 0（如 0.07×0.3），
  要求每题先写“整数积”，再写“一共几位小数”，最后写积；
- 提升：4 道判断改错题，错误分别是“先去 0 再点”“不补 0”“只数一个乘数”“竖式按小数点对齐”；
- 挑战：2 道题，如“根据 36×24＝864，写出 3 个积是 8.64 的算式”。
要求：只用一位、两位小数，不超出五年级上册范围；每题附答案和一句话讲解。
```

再给家长发一张讲解卡：


### 教研：AI 听课伙伴

课后把学生练一练的作答情况（每道题的错误人数和典型错法）交给 AI，请它统计三类错误各占多少，对照本课目标判断“先点后去”“位数不够补 0”有没有真正落实，再起草教学反思和说课稿初稿。还可以请它比较前测和课后练习，看哪类错误减少得最少，下节课《蚕丝》再针对性复习。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：包装纸、彩带的价钱和用量，表格里的四个算式，练一练的数据，以第 39～40 页为准。
2. **演示不替代思考**：先让学生自己点小数点、说理由，再用课件翻译计数单位；先估一估，再看准确结果。
3. **AI 出的题要过一遍**：检查答案的小数位数是否正确、积末尾的 0 是否处理对，有没有超出五年级上册的范围。

这一课最适合做成互动课件的是三处：一个可以拖动小数点、同时显示估算范围的积；一个把小数乘法逐步翻译成“几个 0.1 × 几个 0.01 → 几个 0.001”的计数单位动画；一组“先去 0”“不补 0”“只数一个乘数”的错例诊所。设计时要守住“让学生先想、再动手验证”的顺序：先自己点，再看课件翻译。

## 九、易错点与应对

1. **先去 0 再点**：0.85×0.4 写成 0.034。原因是把“末尾的 0 可以去掉”用错了时机。应对：说清 340 是 340 个 0.001，先点成 0.340，再去 0。
2. **位数不够不补 0**：0.13×0.2 写成 0.26。应对：先说“要几位小数”，再数整数积有几位，不够的用 0 在前面补足。
3. **只数一个乘数**：2.4×1.2 写成 28.8。应对：每题先写“1＋1＝2 位”，再用估算检查：2.4 的 1 倍多一点，不可能是 28.8。
4. **竖式按小数点对齐**：把乘法和加减法混了。应对：乘法竖式先当整数乘，末位对齐；加减法才是小数点对齐。

## 十、反思与说课

- **反思重点**：学生能不能用“288 个 0.01”“340 个 0.001”解释积的小数点？练一练第 1 题有多少人主动用估算检查？只会背“位数相加”、说不出计数单位的学生多，说明“买包装纸”环节两种想法交流得不够；先去 0 的错误多，下一课《蚕丝》的西瓜题（1.98×4.5）要重点讲。
- **说课可以突出**：本课用两道例题分别解决“竖式怎么写”和“末尾的 0 怎么办”，用计数单位让积的小数位数“看得见”，再用表格归纳“积的小数位数是两个乘数的小数位数之和”，把上一课的面积道理落成一套可操作的算法，体现整数乘法和小数乘法算理的一致性。

## 常见问题

**《包装》这节课怎么导入比较好？**
先用一道口答题复习 0.3×0.2＝0.06 的道理，再出示第 39 页的包礼品盒情境，请学生先估一估包装纸大约要多少钱。有了“比 2.4 元多一点”的估计，学生算完会主动检查，点错小数点也更容易发现。

**积的小数位数为什么等于两个乘数的小数位数之和？**
用计数单位最好讲：一位小数是几个 0.1，两位小数是几个 0.01。0.1×0.1＝0.01，0.01×0.1＝0.001，乘数的计数单位越小，积的计数单位就越小。2.4×1.2 是 24 个 0.1 乘 12 个 0.1，积是 288 个 0.01，所以是两位小数。

**小数乘法竖式要不要小数点对齐？**
不用。小数乘法竖式按整数乘法来写，两个乘数末位对齐，算完再点小数点；小数加减法才要小数点对齐。可以把 0.85＋0.4 和 0.85×0.4 两道竖式并排写，让学生说出两种写法为什么不同。

**新教材为什么让学生说“24 个 0.1 乘 12 个 0.1 是 288 个 0.01”？**
2022 年版课标强调感悟计数单位在运算中的作用。用计数单位说理，学生就明白竖式里的 288 是 288 个 0.01，积的小数点怎么点、末尾的 0 能不能先去掉，都能自己判断，不用背口诀。这也让整数乘法和小数乘法用同一个道理连在一起。

**AI 在这节课里最该用在哪？**
最该用在“错因归类”上：这节课的错误类型很固定，课前用 AI 把前测按“只数一个乘数、先去 0、不补 0”分类；课中让学生先拖动小数点，再看课件翻译计数单位；课后按错因生成练习。AI 出的题要检查小数位数和答案。
