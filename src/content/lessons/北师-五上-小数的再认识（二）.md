> **一句话备课结论**：这一课把上一课的 0.1、0.01、0.001 正式命名为小数的**计数单位**，接在整数数位顺序表的右边：小数和整数一样，满十进一。真正的难点是看懂数位顺序表的结构，**以个位为中心**，十位对十分位，百位对百分位，没有“个分位”；再由“0.6 和 0.60 一样大”得出小数的性质，分清哪些 0 能去掉、哪些不能。

## 一、教材解读

### 前后联系

- **已经学过**：上一课理解了小数表示十分之几、百分之几、千分之几；四年级上册“认识更大的数”整理过整数的数位顺序表，知道相邻计数单位之间满十进一；会用计数器拨整数。
- **本课要学**：在计数器上拨小数，认识十分位、百分位、千分位和计数单位 0.1、0.01、0.001；整理小数数位顺序表；体会小数的计数单位也是满十进一；发现小数的末尾添上 0 或去掉 0，大小不变。
- **后面要用**：下一课《一起去买书》要把余数看成“10 个 0.1”；《比大小》要从高位一位一位比；《买菜》的竖式要相同数位对齐；第三单元“小数乘法”的《买文具》还要用涂格子的方法算 0.01×10、0.01×100。

这一课是本单元的“工具课”：后面比大小、算加减，都离不开这张数位顺序表和小数的性质。

### 新旧教材变化

这部分内容旧版在四年级下册《小数的意义（三）》，新版放在五年级上册第 5～7 页，情境同样是北京地铁 10 号线 22.222 米/秒。新版有三处值得注意：

1. **小数的性质换了引入方式**：直接请学生涂一涂 0.6 和 0.60，在计数器上画一画 0.32 和 0.320，再由老爷爷总结“小数的末尾添上‘0’或去掉‘0’，小数的大小不变”。
2. **新增“奇思和妙想”**：两种方式表示计数单位之间的关系。奇思画箭头：1、0.1、0.01、0.001 之间“10 个”和“1/10”互相转化；妙想写算式：0.001×10＝0.01，1÷10＝0.1……
3. **乘 10、100、1000 提前渗透**：练一练第 5 题请学生尝试计算 0.1×10、0.01×100、0.001×1000 等九道题，“你有什么发现？”。新版第三单元“小数乘法”没有单独的《小数点搬家》，所以这道题和“奇思妙想”要讲透，后面要用。

另外，2026 年秋季的五年级四年级下册用的是旧教材，已经学过一遍数位顺序表。备课时可以少讲“是什么”，多问“为什么没有个分位”“0.025 里有几个 0.001”，把认识往深处推。

### 编排意图

教材第 5～7 页的线索是：**拨一拨 22.222 → 认一认数位顺序表 → 满十进一 → 小数的性质 → 计数单位的关系 → 练一练**。

1. **北京地铁 10 号线**：列车最高运行速度是 80 千米/时，约为 22.222 米/秒，男孩说“1 秒就跑 22 m 多，好快！”。五个 2，是一个绝好的问题。
2. **在计数器上拨出 22.222**：说一说每个 2 分别表示多少。课本给出第一个：十分位上的 2 表示 2 个 1/10，也可以表示 2 个 0.1，后两个留给学生填。老爷爷点题：小数点右面第一位是十分位，第二位是百分位，第三位是千分位。
3. **认一认**：数位顺序表分整数部分、小数点、小数部分，两行分别是数位和计数单位；便签上写“小数部分的计数单位分别是 1/10、1/100、1/1000……也可以写成 0.1、0.01、0.001……”，旁边的思考泡问“也是‘满十进 1’吗？”。
4. **满十进一**：“10 个 0.01 元是 0.1 元，10 个 0.1 元是……”，配上 1、0.1、0.01 的面积图。
5. **试一试**：涂一涂 0.6 和 0.60，画一画 0.32 和 0.320，得出小数的性质；再看奇思和妙想表示计数单位之间关系的两种方法。
6. **练一练**：计数器画一画（0.4、0.025、14.24），米尺上填分数和小数，0.03 和 0.30 哪些 0 能去掉，数轴上填数，以及 0.1×10 等九道尝试计算。

## 二、学情分析

**已有基础**：会用计数器拨整数，熟悉整数数位顺序表；知道 0.1 是十分之一、0.01 是百分之一；会用小数表示长度和质量。

**可能的困难**：

1. **数位和计数单位分不清**：说“十分位是 0.1”。其实十分位是位置，0.1 是计数单位，十分位上的 3 表示 3 个 0.1。
2. **以为以小数点为中心对称**：觉得小数点左边是个位，右边就该是“个分位”。
3. **只看单个数字**：问 0.025 里有几个 0.001，学生答 2 个或 5 个。
4. **乱去 0**：把 3.05 写成 3.5，把 600 写成 6，以为“只要是 0 就能去”。
5. **添 0 添错位置**：要把 3.5 写成两位小数，写成了 3.05。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 在计数器上拨小数，认识小数的数位和计数单位，能说出小数中每个数字表示几个计数单位。（数感）
2. 整理小数数位顺序表，体会整数和小数都是满十进一，相邻计数单位之间的关系是 10 倍。（推理意识）
3. 借助涂色和计数器发现小数的性质，能判断哪些 0 可以去掉，会根据需要添 0 改写小数。（几何直观）
4. 体会整数和小数在计数方法上的一致性。

**教学重点**：认识小数的数位和计数单位，理解小数的性质。

**教学难点**：理解数位顺序表以个位为中心的结构；分清哪些 0 能去掉。

## 四、教学过程

### 1. 情境导入（4 分钟）

**地铁 1 秒能跑多远？** 出示第 5 页情境：北京地铁 10 号线最高运行速度约为 22.222 米/秒。

1. 请学生读一读这个数。关键提问：**这里有五个 2，它们表示的大小一样吗**？
2. 学生会说“不一样，位置不同”。追问：各表示多少？先不急着答，留给计数器。

### 2. 拨一拨，说一说（8 分钟）

1. 学生在计数器上拨出 22.222。注意：计数器上要标出小数点。
2. 从左往右说：十位上的 2 表示 2 个 10，个位上的 2 表示 2 个 1。
3. 关键提问：**小数点右边第一个 2 表示多少**？对照课本：表示 2 个 1/10，也就是 2 个 0.1。学生接着填：百分位的 2 表示 2 个 0.01，千分位的 2 表示 2 个 0.001。
4. 揭示：小数点右面第一位是十分位，第二位是百分位，第三位是千分位。

### 3. 认一认：数位顺序表（8 分钟）

1. 拿出四年级上册的整数数位顺序表，请学生自己“往右接”：个位右边是小数点，接着是十分位、百分位、千分位、万分位……
2. 填计数单位：十分之一、百分之一、千分之一……也可以写成 0.1、0.01、0.001。
3. 关键提问：**整数部分最右边是个位，小数部分最左边为什么不是“个分位”**？引导学生发现：个位是中心，十位和十分位、百位和百分位左右对应。

![小数数位顺序表：千位、百位、十位、个位、十分位、百分位、千分位，下面一行是计数单位 1000、100、10、1、0.1、0.01、0.001，再下面是 22.222 的各位数字和每个 2 表示几个计数单位；个位一栏涂成黄色，小数点画在个位和十分位之间；下方三条弧线分别连起十位和十分位、百位和百分位、千位和千分位，中心是个位；最下面写没有“个分位”](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-01/lesson-02/place-table.svg "对称中心是个位，不是小数点：十位对十分位，百位对百分位，所以小数部分从十分位开始，没有“个分位”")

> **设计意图**：学生最容易把小数点当成对称中心，于是想出一个“个分位”。让学生自己把整数数位顺序表往右接，再用弧线连出“十位—十分位”“百位—百分位”，对称中心是个位就一目了然。这比直接告诉学生“没有个分位”更容易记住。

### 4. 满十进一（5 分钟）

1. 思考泡里的问题：**小数的计数单位，也是满十进一吗**？
2. 结合钱和面积图说一说：10 个 0.01 元是 0.1 元，10 个 0.1 元是 1 元；100 格里的 10 小格合起来是 1 条，10 条合起来是整个正方形。
3. 反过来说：1 的 1/10 是 0.1，0.1 的 1/10 是 0.01。

### 5. 试一试：小数的性质（7 分钟）

1. 涂一涂：在 10 条的正方形上涂 0.6，在 100 格的正方形上涂 0.60。关键提问：**涂色部分一样大吗**？学生发现一样大：6 个 0.1 就是 60 个 0.01。
2. 画一画：在计数器上画出 0.32 和 0.320，千分位上的 0 一颗珠子也没有，大小不变。
3. 得出结论：小数的末尾添上 0 或去掉 0，小数的大小不变。
4. 追问：**3.05 中间的 0 能去掉吗？600 末尾的 0 呢**？学生说出：3.05 的 0 在十分位上占位，去掉就变成 3.5；600 是整数，去掉 0 就变成 6；性质说的是“小数的末尾”。

![上面是 0.6 和 0.60 的涂色对比：10 条中涂 6 条，100 格中涂 60 格，中间是等号，下面写小数的末尾添上 0 或去掉 0，小数的大小不变；下面是考考你：0.30、3.05、600、0.03、2.500、10.0、0.020 七张数卡，问哪些数里的 0 可以去掉而大小不变](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-01/lesson-02/zeros.svg "答案：0.30、2.500、10.0、0.020 末尾的 0 可以去掉，写成 0.3、2.5、10、0.02；3.05 中间的 0、600 的 0、0.03 前面的 0 都不能去")

### 6. 奇思和妙想（4 分钟）

1. 出示奇思的箭头图和妙想的算式，请学生同桌互相讲一讲。
2. 关键提问：**奇思的“10 个”和妙想的“×10”是一回事吗**？学生说出：10 个 0.01 是 0.1，就是 0.01×10＝0.1；1 的 1/10 是 0.1，就是 1÷10＝0.1。

![1、0.1、0.01、0.001 四个圆排成一排，上面的红色箭头从左往右，每一步写“÷10”；下面的绿色箭头从右往左，每一步写“10 个”；下方写往右是平均分成 10 份取 1 份，往左是 10 个合成 1 个，满十进一](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-01/lesson-02/units-ten.svg "奇思的箭头和妙想的算式说的是同一件事：相邻两个计数单位之间是 10 倍关系")

### 7. 练一练与小结（4 分钟）

1. 第 1 题快速口答：0.4 里面有 4 个 0.1，0.025 里面有 25 个 0.001；14.24 中个位上的“4”表示 4 个 1，百分位上的“4”表示 4 个 0.01。
2. 第 3 题：0.30 末尾的 0 可以去掉，0.03 的两个 0 都不能去。
3. 小结：小数的数位以个位为中心，计数单位满十进一；小数末尾的 0 可以添、可以去。
4. 第 2、4 题和第 5 题（0.1×10 等九道题）作为课后作业，第 5 题请学生写出自己的发现，下节课交流。

## 五、趣味设计

4 个可以直接用的小设计：

![教室黑板前，七个孩子站成一排，左边三个举着橙色卡片，右边三个举着蓝色卡片，正中间矮一点的孩子双手抱着一个大大的红色圆片；红色圆片左边那个孩子头戴金色纸皇冠，老师站在最右边笑着指向队伍](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-01/lesson-02/place-row.webp "设计 1“人体数位表”：红色圆片是小数点，戴皇冠的是个位；左边三人是百位、十位、个位，右边三人是十分位、百分位、千分位")

1. **人体数位表**：请 7 名学生上台，中间一人抱红色圆片当小数点，左边三人举百位、十位、个位，右边三人举十分位、百分位、千分位。给个位戴一顶纸皇冠。老师报“十位”，十位和十分位两人同时举手；报“百位”，百位和百分位举手。学生一看就知道：一一对应的中心是戴皇冠的个位。
2. **我是计数单位**：每人发一张计数单位卡（1、0.1、0.01、0.001）。老师说“0.01 集合，10 个一组”，凑满 10 人的小组换成一张 0.1 卡。满十进一演一遍，比说十遍管用。
3. **哪个 0 能走**：出示 3.050、0.80、305、20.00 这样的数，每个 0 都是一名“0 同学”。全班判断哪个 0 能“下课回家”，哪个 0 必须“留下来占位”，说出理由。
4. **地铁小故事**：用“地铁 1 秒跑 22.222 米”串起全课：先说五个 2 的意思，再把地铁速度放进数位表，最后问“22.222 米和 22.2220 米一样远吗”。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象的数位结构变成可以操作的东西、让每个学生拿到适合自己的练习**。这一课学生“看过表、背过表”，却未必懂表，AI 能帮老师把这层窗户纸找出来。

### 课前：学情前测

**看学生是背表，还是懂表。** 课前发三道题：① 写出小数部分的前三个数位；② 0.025 里有几个 0.001？③ 3.05 和 3.5 一样大吗？把答案收集起来交给 AI 归类。

可以直接复制的提示词：

```
我是小学五年级数学老师，明天上北师大版五年级上册第一单元《小数的再认识（二）》。
学生四年级下册用旧教材学过一遍小数数位顺序表。
下面是课前小测的答案，每行一名学生：
（粘贴答案）
题目：①写出小数部分的前三个数位；②0.025里有几个0.001？③3.05和3.5一样大吗？
请帮我：
1. 找出这些错误类型并统计人数：写出“个分位”、只看单个数字（答2个或5个）、
   认为中间的0也能去掉；
2. 每类挑一个典型答案，说明学生可能是怎么想的；
3. 建议课上用哪一类错误开场最能引起讨论。
```

### 课中：先接表，再验证

**让学生先自己把整数数位顺序表往右接，再用课件检查。**

- **会对称的数位表**：课件上是整数数位顺序表，学生拖动卡片往右接出十分位、百分位、千分位。接完点“对称”，十位和十分位、百位和百分位同时闪亮，中心落在个位上。写了“个分位”的学生会自己看到那张卡没有对象。
- **满十进一的动画**：100 格中的小格一格一格亮起，满 10 格自动合成一条；10 条合成整个正方形。学生先说“再亮几格就能合成一条”，再看动画验证。
- **全班即时作答**：出示 3.05、0.30、600、2.500，请学生勾出可以去掉的 0。看分布后，只讲错得最集中的那一个。动画和统计都是为了验证学生的想法，演示不替代思考。

### 课后：分层练习

**按错因分层。** 写“个分位”的学生，多做数位顺序表填空；只看单个数字的学生，多做“0.025 里有几个 0.001”这样的题；乱去 0 的学生，多做判断和改写；已经掌握的学生，挑战练一练第 5 题的规律。

可以直接复制的提示词：

```
请为北师大版五年级上册《小数的再认识（二）》生成课后练习，分三层：
- 基础：6道题，说出小数中指定数字表示几个计数单位（如14.24中的两个4），
  以及“0.4里有几个0.1”“0.025里有几个0.001”；
- 提升：6道判断和改写，判断哪些0可以去掉，并把小数改写成指定位数（如3.5写成三位小数）；
- 挑战：2道找规律题，从0.1×10、0.01×100、0.001×1000等算式中发现规律，用计数单位解释。
要求：不出现小数加减法、小数乘法竖式和小数除法；每题附答案和一句话讲解。
```

再给家长发一张讲解卡：

```

内容包括：孩子最容易错在哪（把3.05写成3.5、以为有“个分位”）、
在家可以玩的一个小游戏（看超市价签，说一说每个数字表示多少）。语气亲切，不用专业术语。
```

### 教研：AI 听课伙伴

课后把“为什么没有个分位”和“3.05 的 0 能不能去”这两段学生发言记录交给 AI，请它判断：学生是在复述结论，还是能用“个位是中心”“0 在占位”说出道理？过渡年级的学生哪些说法和旧教材的记忆有关？再让它起草说课稿初稿。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：情境、练一练题目以第 5～7 页为准；旧版四年级下册的同类课，情境和练习有不少调整，AI 可能混用。
2. **演示不替代思考**：先让学生自己接表、自己涂 0.6 和 0.60，再看课件的对称和动画。
3. **AI 出的题要过一遍**：检查有没有提前出现小数点移动的规律结论、有没有“600 去掉 0 等于 6”这类会误导学生的题目没给讲解。

这一课最适合做成互动课件的是三处：一张可以自己往右接、一键显示对称的数位顺序表；一组满十自动合成的计数单位动画，学生先预测再验证；一道全班即时作答的“哪些 0 能去掉”。设计时要守住“让学生先想、再动手验证”的顺序。

## 八、分层作业

括号里是答案要点。

**基础**

1. 练一练第 2 题：在米尺上看，10 cm 和 60 cm 分别是多少米？用分数和小数表示。（10/100 m，0.1 m；60/100 m，0.6 m）
2. 说出 30.503 中每个 3 和每个 5 表示多少。（十位的 3 表示 3 个 10，千分位的 3 表示 3 个 0.001；十分位的 5 表示 5 个 0.1）

**提升**

3. 不改变大小，把 3.5、12、0.40 都写成三位小数。（3.500，12.000，0.400）
4. 判断：0.70 和 0.07 一样大，因为小数末尾的 0 可以去掉。（错，0.07 的 0 不在末尾，0.70＝0.7，0.07 是 7 个 0.01）

**挑战**

5. 练一练第 5 题：计算 0.1×10、0.01×100、0.001×1000 等九道题，你有什么发现？（0.1×10＝1，0.01×100＝1，0.001×1000＝1；乘 10，计数单位变成它左边一位的计数单位，满十进一）
6. 一个三位小数，十分位和千分位上的数字都是 5，百分位上是 0，个位上是 3，这个数是多少？去掉哪个 0 会改变它的大小？（3.505；去掉百分位上的 0 会变成 3.55，大小改变）

## 九、易错点与应对

1. **写出“个分位”**：以为小数点是对称中心。应对：让学生自己把整数数位顺序表往右接，再用弧线连出十位和十分位，看清中心是个位。
2. **说不清有几个计数单位**：0.025 里答“2 个 0.001”。原因是只看单个数字。应对：在计数器上拨出 0.025，先说“2 个 0.01、5 个 0.001”，再把 2 个 0.01 换成 20 个 0.001，合起来 25 个。
3. **乱去 0**：3.05 写成 3.5，600 写成 6。应对：紧扣“小数的末尾”四个字，去 0 前先问：去掉以后，每个数字还在原来的数位上吗？
4. **添 0 添错位置**：3.5 写成两位小数 3.05。应对：在数位表里写，添的 0 只能写在最右边的空位上。

## 十、反思与说课

- **反思重点**：学生能不能说出“为什么没有个分位”？判断“哪些 0 能去掉”时，是在套口诀，还是会问“去掉以后数字还在原来的数位上吗”？过渡年级里背过表的学生，有没有在追问中说出新的理解？
- **说课可以突出**：本课沿着“拨一拨 22.222 → 接数位顺序表 → 满十进一 → 小数的性质 → 计数单位的关系”展开，用“自己往右接表”和“对称弧线”突破“以个位为中心”的难点，体现整数和小数计数方法的一致性；“奇思妙想”和练一练第 5 题为后面的小数乘法打下基础。

## 常见问题

**《小数的再认识（二）》这节课怎么导入比较好？**
直接用教材第 5 页的地铁情境：北京地铁 10 号线 1 秒约跑 22.222 米。请学生读一读，再问“五个 2 表示的大小一样吗”，自然引出数位和计数单位，再拿计数器拨一拨。

**怎样让学生明白小数数位顺序表以个位为中心？**
不要直接给表。让学生拿出整数数位顺序表，自己往右接；接完后用弧线连出十位和十分位、百位和百分位、千位和千分位，学生会发现每对的中间都是个位，“个分位”自然就不存在了。也可以用“人体数位表”的游戏演一演。

**3.05 的 0 和 3.50 的 0 有什么不同？**
3.50 的 0 在小数的末尾，去掉后写成 3.5，大小不变；3.05 的 0 在十分位上占位，去掉就变成 3.5，从 5 个 0.01 变成了 5 个 0.1，大小变了。小数的性质只说“末尾”的 0 可以添上或去掉。

**新教材为什么在这一课加了“奇思和妙想”？**
新版小数乘法单元没有单独的《小数点搬家》，相邻计数单位之间的 10 倍关系、乘 10 和除以 10 的道理，就放在这一课先打基础：奇思用“10 个”和“1/10”的箭头表示，妙想用“×10”“÷10”的算式表示，练一练第 5 题再让学生算一算、找规律。

**AI 在这节课里最该用在哪？**
最该用在区分“背表”和“懂表”：课前用 AI 给学生的错误分类，课中让学生自己接表、看对称和满十进一的动画来验证，课后按错因生成数位、计数单位和去 0 判断的分层练习。
