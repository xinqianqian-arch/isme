> **一句话备课结论**：量角的步骤一句话就能说完——**点重合、边重合、读度数**。真正让学生出错的是第三步：量角器有内外两圈刻度，**是 70° 还是 110°**？要教会学生两个“保险”：一看角的一边对着哪一圈的 0，就沿哪一圈读；二先判断是锐角还是钝角，读完再核对。画角是量角的逆过程，第 2 课时再加上三角板，学生就能画出指定度数的角。

## 一、教材解读

### 前后联系

- **已经学过**：上一课《角的度量（一）》知道把圆平均分成 360 份，1 份所对的角是 1°，1 周角＝360°、1 平角＝180°、1 直角＝90°；会借助 10° 的小格估计角的大小。《旋转与角》认识了锐角、直角、钝角、平角、周角。
- **本课要学**：认识量角器的中心点、零刻度线、内圈刻度和外圈刻度；会用量角器量角、画指定度数的角；知道三角板上各角的度数，会用三角板画 30°、45°、60°、90° 的角，用一副三角板拼出 105°、15° 等角。
- **后面要用**：单元整理与复习要量平行四边形各角、量五角星和自行车上的角，用量角器画 45°、70°、140°、170° 的角；以后学三角形内角和、用方向和角度描述位置，都离不开量角和画角。

### 新旧教材变化

新教材把量角器的全部内容集中在这一课：上一课只讲 1°，这一课从认识量角器开始，一口气讲到量角、画角、三角板上的角，第 33～35 页共三页，练一练有 5 道题。建议按 **2 课时**教：

1. **第 1 课时“认识量角器和量角”**：第 33 页，加练一练第 2、4 题。
2. **第 2 课时“画角和三角板上的角”**：第 34 页，加练一练第 1、3、5 题。

另外两处变化值得注意：

- **和上一课的 360 等分圆衔接**：教材开头就请老爷爷说出“量角器是把半圆平均分成 180 份”，学生一看就知道每份是 1°，不用重新讲 1° 的含义。
- **读数的提醒写进了总复习**：全册总复习（第 106 页）里有一句“用量角器量角时，先看是锐角还是钝角，再决定看内圈刻度还是外圈刻度”。可见内外圈读数是教材特别关注的难点，本课就要把这个习惯建立起来。

### 编排意图

教材第 33～35 页的线索是：**认识量角器 → 在量角器上找角 → 量角 → 画角 → 三角板上的角 → 练习**。

1. **认识量角器**：老爷爷说“量角器是把半圆平均分成 180 份”，男孩说“每份对应的角是 1°。内圈的刻度是……外圈的刻度是……”，图上标出中心点和零刻度线。
2. **在量角器上找角**：找到并画出 50°、140° 的角。一个孩子说“50° 的角里有 50 个 1° 的角……”，另一个说“我从内圈找到了 140° 的角……”。先“找角”再“量角”，让学生看清量角器上的每一个角都是从零刻度线开始的。
3. **量两个角**：先估一估，再量 ∠1、∠2。提示是“先将角的顶点和量角器的中心点重合，再把零刻度线与角的一条边重合，然后……”，旁边的问题是“是 70° 还是 110° 呢？”。
4. **画 60° 的角**：四幅操作照片，配一句“看内圈还是外圈呢？”和“我用量角器可以画出任意度数的角”。
5. **试一试**：量出三角板上的角（30°、60°、90°；45°、45°、90°），用三角板画 60° 和 120° 的角——60° 描一描，120° 拼一拼。

## 二、学情分析

**已有基础**：知道 1° 和直角、平角、周角的度数；会估计角的大小；会用直尺量长度，知道要“从 0 开始量”。

**可能的困难**：

1. **内外圈读反**：锐角读成钝角的度数，70° 读成 110°。这是本课最普遍的错误。
2. **顶点没对准中心点**：把量角器的边缘或底边的某一点当成中心。
3. **边没对准零刻度线**：把角的一边对在量角器的底边上，却不在零刻度线上；或者对准了 10、20 的刻度线还从 0 读。
4. **角的边太短，读不出来**：边没有伸到刻度处，不知道要先把边延长。
5. **画角时点错圈**：画 60° 的角，在外圈 60 处点点，画成了 120°。
6. **三角板拼角想不到减法**：会用“60°＋45°”拼 105°，想不到用“45°－30°”得到 15°。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 认识量角器的中心点、零刻度线、内圈刻度和外圈刻度，知道量角器上每个角都从零刻度线开始。（量感）
2. 会用量角器量角，能根据角的一边对着的零刻度线选对内圈或外圈，并用“锐角还是钝角”检查读数。（推理意识）
3. 会用量角器画指定度数的角，知道三角板上各角的度数，会用三角板画、拼出一些特殊的角。（空间观念）
4. 在估计、测量生活中的角的过程中，发展量感，养成先估后量的习惯。

**教学重点**：用量角器量角、画角。

**教学难点**：正确选择内圈或外圈刻度读数。

## 四、教学过程

教材安排 2 课时。下面 1～6 是第 1 课时（40 分钟），第 2 课时的安排写在本节最后。

### 1. 情境导入（4 分钟）

**有专门量角的工具吗？** 回顾上一课：把圆平均分成 360 份，每份 1°。出示量角器。

- 关键提问：**量角器是什么形状？它和上节课那个 360 等分的圆有什么关系**？引导学生说出：量角器是半圆，是把半圆平均分成 180 份，每份也是 1°。
- 追问：**量角器为什么做成半圆，不做成整圆**？这是教材整理与复习“问题银行”里的问题，先请学生猜一猜，下课前再回来讨论。

### 2. 认识量角器（10 分钟）

1. 每人拿出量角器，同桌找一找：中心点在哪里？零刻度线在哪里？
2. 关键提问：**内圈刻度和外圈刻度有什么不同**？学生发现：两圈都从 0 到 180，但 0 的位置相反——外圈的 0 在左边，往右数；内圈的 0 在右边，往左数。同一条刻度线上，内外圈两个数加起来正好是 180。
3. **在量角器上找角**：找到并画出 50°、140° 的角。请学生说出“50° 的角里有 50 个 1° 的角”；再请从内圈、从外圈找到 140° 的两位同学分别上台指一指。关键提问：**量角器上的角，一条边都在哪里**？——都在零刻度线上，另一条边对着度数。

### 3. 量一量 ∠1（12 分钟）

1. **先估**：∠1 是锐角，比直角小一些，估计在 60°～80°。
2. **再量**：学生自己尝试，再请两三位同学投影展示。结合教材提示，总结步骤：**点重合**——顶点和中心点重合；**边重合**——零刻度线和角的一条边重合；**读度数**——看另一条边对着的刻度。
3. 出现分歧：有人读 70°，有人读 110°。关键提问：**是 70° 还是 110°**？

![量角器放在 ∠1 上：∠1 的一条边沿着零刻度线指向右边，另一条边穿过内圈的 70、外圈的 110；红色箭头沿内圈从右边的 0 数到 70，蓝色虚线箭头沿外圈从左边的 0 数到 110；下方说明看内圈得 70°，外圈的 110 是旁边那个钝角](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-02/lesson-06/read-70.svg "∠1 的一边对着内圈的 0，就沿内圈读：70°。外圈的 110 量的是另一边那个钝角；再用“∠1 是锐角”检查一遍")

4. 引导学生说出两个“保险”：一是**角的一边对着哪一圈的 0，就从这个 0 起沿这一圈读**；二是**读完看一看：锐角不会超过 90°，钝角不会小于 90°**。
5. 板书：∠1＝70°。

> **设计意图**：内外圈读错，根子在于学生只记住“读另一条边对着的数”，没想过这个数是从哪个 0 数过来的。让学生顺着内圈从 0 数到 70、顺着外圈从 0 数到 110，他会看到外圈的 110 恰好是旁边那个钝角，读数就不再靠猜。“先判断锐角钝角”是第二道保险，教材第 106 页总复习也专门提到它。

### 4. 量一量 ∠2（6 分钟）

1. ∠2 是钝角，先估：比直角大一些。
2. 学生独立量，汇报度数。按课本图，∠2 大约是 110°，以学生实际量出的结果为准。
3. 关键提问：**换一条边对零刻度线，结果会变吗**？请一位同学把零刻度线对准 ∠2 的另一条边，改读另一圈，度数不变。说明哪条边对零都可以，关键是读对那一圈。
4. 追问：**角的边太短，够不着刻度怎么办**？——先把边延长再量，延长不改变角的大小。

### 5. 练一练（6 分钟）

1. **第 2 题**：先估一估课本图中道闸、笔记本电脑、游泳运动员入水时红色标出的角，再量一量，填在表里，看看谁估得准。
2. **第 4 题**：量一量椅子靠背与椅面的夹角，再模仿着坐一坐。老爷爷说“当靠背与椅面的夹角大约为 100° 时比较省力”。请学生说一说三种坐姿的感受。

![三格黏土插画：同一个孩子侧身坐在同一把转椅上。第一格黄色背景，靠背竖直，孩子坐得笔直有点僵硬；第二格绿色背景，靠背稍微向后倾，孩子放松地微笑；第三格蓝色背景，靠背向后倒得很多，孩子半躺着快睡着了](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-02/lesson-06/chairs.webp "练一练第 4 题：靠背和椅面的夹角越大，人靠得越斜。量一量、坐一坐，找到“大约 100° 比较省力”的感觉")

### 6. 小结（2 分钟）

1. 全班说一遍量角口诀：**点重合，边重合，零在哪圈读哪圈，锐角钝角核一遍**。
2. 回到导入的问题：量角器做成半圆，是因为任何一个角最多到平角就能直接量出来；比平角大的角，可以用 360° 减去另一部分来算，用不着整圆。（只做了解，不作要求）

### 第 2 课时（40 分钟）

**第 2 课时学画角：用量角器画指定度数的角，再认识三角板上的角，用三角板画角、拼角。**

1. **复习热身（5 分钟）**：用下面的“考考你”复习量角，每题先说“锐角还是钝角”，再说“读哪一圈”。

![考考你：三个量角器读数题。∠1 的一边沿零刻度线指向右边，另一边指向左上方；∠2 的一边沿零刻度线指向左边，另一边指向左上方；∠3 的两条边都不在零刻度线上，分别对着内圈的 30 和 100](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-02/lesson-06/quiz.svg "答案：∠1＝120°（钝角，一边对内圈的 0，读内圈）；∠2＝40°（锐角，一边对外圈的 0，读外圈）；∠3＝70°（两边都不在 0 上，用 100－30＝70）")

2. **画一个 60° 的角（12 分钟）**：先请学生自己想办法画，再交流。结合教材四幅照片，总结四步：画一条射线；量角器的中心点对准射线的端点，零刻度线对准射线；在 60° 刻度处点一个点；移开量角器，从端点经过这个点画射线，标上 60°。关键提问：**看内圈还是外圈**？——射线向右，对着内圈的 0，就在内圈的 60 处点点。画完，同桌用量角器互相量一量，验证是不是 60°。

![画 60° 角的四步：①画一条射线，标出端点；②量角器的中心点对准端点，零刻度线对准射线；③射线向右，用内圈，在内圈 60 处点一个点；④移开量角器，连线，标出 60°](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-02/lesson-06/draw-60.svg "画角是量角倒过来：先定一条边，再找度数点。射线向右就用内圈，射线向左就用外圈")

3. **三角板上的角（10 分钟）**：
   - 量一量两块三角板的角：一块是 30°、60°、90°，一块是 45°、45°、90°（教材里的孩子说“这个角是 90°，另两个角是相等的”）。
   - 用三角板画 60° 的角：三角板上有 60° 的角，描一描就可以。
   - 用三角板画 120° 的角：一块三角板没有 120° 的角，拼一拼——90° 和 30° 拼起来，或两个 60° 拼起来。

![上排：30°、60°、90° 三角板和 45°、45°、90° 三角板，标出每个角的度数；下排三种拼法：60° 和 45° 拼成 105°，45° 和 30° 重叠得到 15°，90° 和 30° 拼成 120°](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-02/lesson-06/set-squares.svg "三角板上的角可以加，也可以减：60°＋45°＝105°，45°－30°＝15°，90°＋30°＝120°")

4. **练一练（11 分钟）**：
   - 第 1 题：在量角器上找出 70°、130° 的角，画在图上。如果两个角都以右边的零刻度线为一条边，70° 和 130° 都在内圈找。
   - 第 3 题：画出 35°、115°、80°、160° 的角。画完同桌交换，用量角器检查。
   - 第 5 题：用三角板画 30°、45°、90° 的角；再用一副三角板拼一拼，还能得到哪些度数的角？教材里的孩子拼出了 105° 和 15°。全班汇总：用两块三角板的角相加，可以得到 75°（30°＋45°）、105°（60°＋45°）、120°（90°＋30°）、135°（90°＋45°）、150°（90°＋60°）、180°（90°＋90°）；相减可以得到 15°（45°－30°，或 60°－45°）。
5. **小结（2 分钟）**：画角时“射线对零线，度数点对圈，连线标度数”；三角板能画 15° 的整数倍中的一些角，其余度数就要用量角器。

## 五、趣味设计

4 个可以直接用的小设计：

1. **量角口诀拍手歌**：“点重合，边重合，零在哪圈读哪圈，锐角钝角核一遍。”两人一组拍手说，说到“读哪圈”时同桌用手指出量角器上的那一圈。
2. **估测王争霸**：教室里找角——门打开的角、书本打开的角、窗户推开的角。先写估计值，再量，估计和实际相差不到 10° 的得一面小旗。记录每一轮的误差，看看是不是越估越准。
3. **椅背实验**：照练一练第 4 题，请三位同学分别坐在靠背角度不同的椅子上（可以用靠垫调节），全班量一量、问一问哪种最舒服，体会“大约 100° 比较省力”。
4. **三角板拼角接力**：每组一副三角板，老师报一个度数（如 75°、135°、15°），小组最快拼出来并说出算式的得分。拼不出来的度数（如 50°）也要说出“为什么拼不出”。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象概念变成可以操作的东西、让每个学生拿到适合自己的练习**。量角是一项操作技能，老师最难做到的，是在 40 多个学生同时量的时候，看清每个人错在哪一步。AI 在这里最能帮忙。

### 课前：学情前测

**先看学生会不会“读”量角器。** 课前发一张量角器读数图：一个角的一边对着内圈的 0，另一边穿过内圈 50、外圈 130。请学生写出度数，并写一句“我是看哪一圈读的、为什么”。把答案交给 AI 按理由归类：读对且理由清楚、读对但说不清、读成 130、不知道两圈的区别。

```

另一边穿过内圈的50、外圈的130，这个角是多少度？写一句你是看哪一圈读的、为什么。
下面是学生的答案，每行一名学生（已去掉姓名）：

### 课中：先估再量，课件把关

**每一步都先让学生在纸上做，再在课件上验证。** 互动量角器适合做这几件事：

- **拖动量角器去对准**：屏幕上有一个角和一个可以拖动、旋转的量角器。学生拖动量角器，课件分别检查“顶点和中心点是否重合”“零刻度线是否和一条边重合”，没对准就提示是哪一步没做好，而不是直接给出度数。
- **读数时只亮学生选的那一圈**：学生先点“我读内圈”或“我读外圈”，课件再沿那一圈从 0 开始画出读数的弧线，读错了，学生会看到弧线画的是旁边那个角。
- **全班即时作答**：出示 ∠1，选项是 70° 和 110°，每人作答后显示分布，请选 110° 的同学说想法，再请同伴用“哪一圈的 0”“锐角还是钝角”来说服他。
- **拍照诊断画的角**：第 2 课时画 35°、115° 等角后，学生把作业拍照上传，能识图的 AI 先标出“度数不对”的作品，老师挑典型错例投屏，比如在外圈 35 处点点、画成了 145°。

### 课后：分层练习

**按错的那一步来分层。** 内外圈读反的学生，多做“先判断锐角钝角，再读数”的题；对不准的学生，多做“找出这样量错在哪里”的题；已经掌握的学生，挑战三角板拼角和不从 0 开始的读数。

可以直接复制的提示词：

```
请为北师大版四年级上册《角的度量（二）》生成课后练习，分三层：
- 基础：6道量角器读数题，用文字描述量角器上的位置（如“一边对着内圈的0，
  另一边穿过内圈的40、外圈的140”），要求先写锐角还是钝角，再写度数，
  其中至少3题考内外圈的选择；
- 提升：4道“找错”题，描述一次错误的量角或画角过程（顶点没对中心点、
  边没对零刻度线、读错圈、画角时在外圈找点），请学生指出错在哪一步并改正；
- 挑战：3道三角板拼角题，用一副三角板（30°、60°、90°和45°、45°、90°）拼出或说明

### 教研：AI 听课伙伴

**用数据看“读数难点”突破了没有。** 把第 1 课时前测中“读成 130”的人数，和第 2 课时“考考你”三道题的作答情况一起交给 AI，请它比较内外圈读错的人数变化，再起草教学反思初稿：哪一个做法最有效，是“沿那一圈从 0 数过去”，还是“先判断锐角钝角”。数据由老师收集，结论由老师判断，AI 只负责整理。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：例题、“试一试”和练一练以第 33～35 页为准；∠1、∠2 和生活中的角，以学生实际量出的度数为准。
2. **演示不替代操作**：量角、画角是手上的技能，每个学生都要用自己的量角器真正量过、画过；课件只负责检查和放大错误，不能用“看老师在屏幕上量”代替。
3. **不要用 AI 画量角器**：AI 画图工具画出的量角器，刻度常常排错、内外圈混乱，**练习用的量角器图要用实物拍照或几何作图软件制作**；AI 出的文字题也要核对度数。

这一课最适合做成互动课件的是三处：一个可以拖动、旋转的量角器，分步检查“点重合、边重合”，读数时沿学生选的那一圈画出弧线；一道全班即时作答的“70° 还是 110°”；一个画角练习区，学生在纸上画完后拍照比对，课件标出度数偏差。设计时要守住一点：每一步都先让学生自己动手，课件只负责验证和暴露错误。

## 八、分层作业

括号里是答案要点。

**基础**

1. 量一量课本练一练第 2 题中的三个角，和你的估计比一比，相差多少度？（以实测为准，重点是先估后量）
2. 用量角器画出 45°、70°、140°、170° 的角。（画完同桌互相量一量检查）

**提升**

3. 一个角的一边对着量角器外圈的 0，另一边对着内圈 60、外圈 120，这个角是多少度？（120°，一边对外圈的 0，读外圈；它是钝角）
4. 小明量一个锐角，读出 150°。他可能错在哪里？这个角实际是多少度？（读错了圈，实际是 180°－150°＝30°）

**挑战**

5. 用一副三角板，能拼出 75° 的角吗？能拼出 50° 的角吗？说说理由。（能，30°＋45°；不能，三角板上的角都是 15° 的整数倍，拼不出 50°）
6. 钟面上 1 时整，时针和分针成多少度？4 时整呢？用量角器量一量，再用“1 大格是 30°”算一算。（30°；120°）

## 九、易错点与应对

1. **内外圈读反**：锐角读成钝角的度数。原因是只看另一条边对着的数，没想这个数从哪个 0 数起。应对：读数前先用手指沿那一圈从 0 滑到另一条边；读完用“锐角还是钝角”核一遍（见上面“是 70° 还是 110°”的图）。
2. **顶点没对准中心点**：把量角器底边的端点当中心。应对：先在量角器上用红笔圈出中心点，量的时候说“点重合”。
3. **边没对准零刻度线**：角的一边对在 10 或 20 的刻度线上，却从 0 读。应对：两边都不在 0 上时，用“大数减小数”，如上面“考考你”的 ∠3；平时坚持“边重合”这一步。
4. **边太短读不出**：应对：先用直尺把边延长，延长不改变角的大小。
5. **画角时在错的那一圈点点**：画 60° 画成 120°。应对：画完立刻用量角器量一遍，或者看一眼“我要画的是锐角，画出来像不像锐角”。

## 十、反思与说课

- **反思重点**：学生能不能说出“为什么读内圈”，而不只是读对？画角时是否养成了“画完量一量”的习惯？第 2 课时“考考你”的三道题，如果 ∠2（一边对外圈的 0）错得最多，说明学生只记住了“读内圈”，还没真正理解“零在哪圈读哪圈”。
- **说课可以突出**：本课按“认识工具—量角—画角—三角板”的顺序分 2 课时展开，用“沿那一圈从 0 数过去”和“先判断锐角钝角”两道保险突破内外圈读数难点，把画角作为量角的逆过程，并用三角板拼角沟通角的加减，发展学生的量感和推理意识。

## 常见问题

**《角的度量（二）》怎么导入比较好？**
接着上一课的 360 等分圆导入：上一课把圆平均分成 360 份，每份 1°；出示量角器，请学生发现它是“把半圆平均分成 180 份”，每份同样是 1°。再抛出教材“问题银行”里的问题“量角器为什么做成半圆”，留到课尾讨论。

**怎样突破量角器内外圈读数的难点？**
教两道“保险”。第一道：看角的一边对着哪一圈的 0，就从这个 0 起沿这一圈读，读数前用手指沿那一圈滑一遍。第二道：读完先判断角是锐角还是钝角，锐角不会超过 90°，钝角不会小于 90°。教材第 106 页总复习里也写着“先看是锐角还是钝角，再决定看内圈刻度还是外圈刻度”。

**量角时是 70° 还是 110°，怎么判断？**
看 ∠1 的哪条边对着零刻度线的 0。课本里 ∠1 的一条边沿零刻度线指向右边，对着内圈的 0，所以读内圈的 70，∠1＝70°；外圈的 110 是从左边的 0 数过来的，量的是另一边那个钝角。再核对一下：∠1 是锐角，不可能是 110°。

**新教材为什么把量角、画角和三角板放在同一课？**
新教材第 31～32 页的《角的度量（一）》专门讲 1° 这个单位，《角的度量（二）》集中讲工具和操作：认识量角器、量角、画角，再看三角板上的角。量角和画角是互逆的两个过程，放在一起学，学生更容易看清“零刻度线、度数点”在两个过程中的作用。内容多，建议分 2 课时。

**AI 在这节课里最该用在哪？**
最该用在“看清每个学生错在哪一步”：课前用读数小测找出会读反的学生，课中用可拖动的量角器分步检查对准情况，课后按错的那一步分层出题。练习用的量角器图不要让 AI 画图工具生成，刻度很容易画错。
