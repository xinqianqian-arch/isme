> **一句话备课结论**：《蚕丝》是小数乘法计算的“收口课”。前几课学生已经会“按整数乘法算、再数小数位数点小数点”，这节课要把方法练熟、把细节补齐：积的末尾有 0 时**先点小数点，再去 0**；再回答一个大问题——积一定比乘数大吗？真正的难点是打破两条旧经验：小数乘法不能“整数部分乘整数部分、小数部分乘小数部分”，乘法也不一定越乘越大。

## 一、教材解读

### 前后联系

- **已经学过**：三年级会用竖式计算多位数乘法。本单元前四课：《买文具》借元角分和图理解小数乘整数；《小数点搬家》探索小数点移动引起的大小变化；《街心广场》借面积图理解小数乘小数，发现积的小数位数等于两个乘数的小数位数之和；《包装》学会小数乘法的竖式，先估再算，知道积末尾的 0 可以去掉。
- **本课要学**：计算 1.2×1.25 和 0.35×300，进一步掌握小数乘法的笔算，重点处理积末尾的 0；总结“计算小数乘法要注意什么”；通过 2.3 乘一组数，发现积和乘数的大小关系。
- **后面要用**：下一课《手拉手》把整数的运算顺序和运算律推广到小数；五年级学小数除法、分数乘法时，“商和被除数”“积和乘数”谁大谁小的判断还会反复用到。

所以这节课既是计算的巩固课，也是从“会算”走向“会判断结果合不合理”的一课。

### 版本说明

本文依据**现行版北师大版四年级下册**（第三单元“小数乘法”第 5 课，教材第 42–43 页）。北师大新版四年级下册预计 2027 年春季启用，届时我们会按新课本更新。

在 2022 年版课标里，小数乘除法属于第三学段（5～6 年级）：学段目标是“能进行简单的小数和分数四则运算和混合运算，感悟运算的一致性”；第二学段（3～4 年级）对小数只要求简单的加减运算。现行版把小数乘法放在四年级下册，比课标的学段安排早一些。备课时可以借用“运算的一致性”这个视角：小数乘法和整数乘法一样，算的都是“有多少个计数单位”。

### 编排意图

教材第 42 页用“你知道吗”给出三条资料：一条秋蚕吐的丝长约 1.2 千米、质量约 0.35 克，春蚕吐的丝大约是秋蚕的 1.25 倍。围绕这些数据安排了四个层次：

1. **小数乘小数**：一条春蚕吐的丝长约多少千米？1.2×1.25。教材并排呈现两种做法：一种是竖式，积是 1.500；另一种写成 1×1＋0.2×0.25＝1.05，旁边打了问号，批注“有一定道理，结合图形想一想”“少算了 2 块”。
2. **小数乘整数，整数末尾有 0**：一条丝巾约用 300 条秋蚕的丝，质量约多少克？0.35×300。竖式里把 300 的“3”和 35 的“5”对齐，两个 0 写在后面，算出 10500，再追问“积的小数点的位置在哪？结果是多少？”
3. **想一想**：计算小数乘法时要注意什么？
4. **算一算，填一填**：2.3 分别乘 1.2、1.05、1、0.9、0.86，表里已经给出两个积（2.3 和 2.07），旁边的问题是“积一定比乘数大吗？”

第 43 页“练一练”6 题：判断三位同学算 4.6×0.85 的竖式谁对、不计算判断三道题、给积点小数点、先想积比第一个乘数大还是小再计算，以及兔子速度、长颈鹿身高两道实际问题。

整条线索是：**算对 → 算明白 → 看出规律**。“拆开乘”的错例放在最前面，是要学生在面积图里看清小数乘法的结构；积和乘数的大小关系放在最后，又把计算变成了判断，为估算和检验服务。

## 二、学情分析

**已有基础**：会把小数乘法转化成整数乘法来算，会数积的小数位数，知道积末尾的 0 可以去掉；在《街心广场》里见过用面积图表示小数乘法。

**可能的困难**：

1. **先去 0 再点小数点**：算出 1500 后先划掉两个 0 得 15，再数三位小数，写成 0.015。
2. **“拆开乘”**：受小数加法“整数部分加整数部分、小数部分加小数部分”的影响，写出 1.2×1.25＝1×1＋0.2×0.25＝1.05。
3. **竖式书写和位数**：0.35×300 按小数点对齐来写；或者把 300 末尾的两个 0 也算进小数位数，得出 1.05。
4. **“越乘越大”**：整数乘法里乘数是非 0 自然数，积不会比另一个乘数小，学生就认定积一定比乘数大；也有学生走到另一头，认为“乘小数积就变小”，连 2.3×1.2 也说变小。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 在“春蚕丝有多长”“丝巾有多重”的问题中，进一步掌握小数乘法的笔算方法，能正确处理积末尾的 0 和位数不够的情况。（运算能力）
2. 借助面积图说明 1.2×1.25 为什么不能只算 1×1 和 0.2×0.25，能从计数单位的角度解释小数乘法为什么可以转化成整数乘法。（推理意识）
3. 通过 2.3 乘一组数的计算和比较，发现一个数（0 除外）乘大于 1、等于 1、小于 1 的数时，积和这个数的大小关系，并用它来估算、检验。（数感）
4. 养成先估再算、算后检验的习惯，感受蚕丝资料里的数学。

**教学重点**：小数乘法的笔算方法，积末尾有 0 时的处理。

**教学难点**：理解“拆开乘”为什么错；发现并说清积和乘数的大小关系。

## 四、教学过程

### 1. 情境导入（4 分钟）

**一根蚕丝能拉多长**？先让学生猜：从一个蚕茧里抽出的丝，大概有多长？学生多半会说“几米”“几十米”。

![一个孩子跪在桑叶托盘旁，托盘里有几条白白胖胖的蚕和两个蚕茧，他手里牵着一根从蚕茧里抽出的细丝，丝线发着光，越过草地和小山一直延伸到远处](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-05/silk.webp "导入画面：一个蚕茧里的丝能拉多长？先猜，再看资料——秋蚕约 1.2 千米")

- 出示资料：一条秋蚕吐的丝长约 1.2 千米，差不多是学校 400 米跑道的 3 圈。学生的惊讶就是最好的开场。
- 再读另外两条信息：质量约 0.35 克；春蚕吐的丝大约是秋蚕的 1.25 倍。
- 提问：**根据这些信息，你能提出什么数学问题**？挑出“春蚕的丝有多长”，丝巾的问题留到后面。

> **设计意图**：先猜再看数据，让 1.2 千米这个数有“分量”。后面算出春蚕丝 1.5 千米时，学生会自然地拿它和 1.2 比，为“积比乘数大还是小”埋下伏笔。

### 2. 春蚕丝多长（11 分钟）

1. **先估**。列式 1.2×1.25 后追问：**春蚕丝比 1.2 千米长还是短**？（长，1.25 倍比 1 倍多）**会超过 2.4 千米吗**？（不会，不到 2 倍）把“比 1.2 大、比 2.4 小”写在黑板一角。
2. **再算**。学生独立用竖式计算，请一名学生边写边说：125×12＝1500；两个乘数一共三位小数，从右往左数三位点上小数点，得 1.500；末尾的 0 划去，是 1.5 千米。
3. **辨一辨**。出示教材上的另一种做法：1.2×1.25＝1×1＋0.2×0.25＝1.05。问：**这样算有没有道理**？
   - 先让估算说话：1.05 比 1.2 还小，和“春蚕丝更长”矛盾，肯定有问题。
   - 再画面积图：长 1.25、宽 1.2 的长方形，按 1 和 0.25、1 和 0.2 分成四块。1×1 和 0.2×0.25 只是其中两块，**另外两块被漏掉了**，这就是教材批注的“少算了 2 块”。
   - 四块合起来：1＋0.25＋0.2＋0.05＝1.5，和竖式的结果一样。

![长 1.25、宽 1.2 的长方形被分成四块：1×1＝1 和 0.2×0.25＝0.05 涂蓝色，1×0.25＝0.25 和 0.2×1＝0.2 涂红色；右侧写着蓝色两块只有 1.05，红色两块被漏掉，四块合起来 1＋0.25＋0.2＋0.05＝1.5](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-05/area-model.svg "“拆开乘”只算了蓝色两块；中间两块“整数×小数”被漏掉，四块合起来才是 1.5")

4. **说算理**。为什么竖式可以按 125×12 来算？1.25 是 125 个 0.01，1.2 是 12 个 0.1，0.01×0.1＝0.001，所以积是 1500 个 0.001，也就是 1.5。小数乘法和整数乘法一样，都在数“有多少个计数单位”。

### 3. 丝巾多重（7 分钟）

1. **先估**：0.35 在 0.3 和 0.4 之间，乘 300 大约在 90 到 120 克之间。
2. **看竖式写法**：教材把 300 的“3”和 35 的“5”对齐，两个 0 甩在后面。先算 35×3＝105，再在后面添上两个 0，得到 10500。这和整数乘法“末尾有 0 的先不管”是一个道理。
3. 关键提问：**积的小数点点在哪里**？0.35 有两位小数，300 没有小数，所以从右往左数两位：105.00，去掉末尾的 0，是 105 克。
4. 追问：**300 后面的两个 0 要不要算进小数位数**？不算，它们是整数末尾的 0，不是小数部分。有学生得出 1.05，就是把它们也数进去了。
5. 把两道题放在一起看：积的末尾都有 0，都是**先点小数点，再去 0**。

![两道竖式：左边 1.25×1.2，部分积 250 和 125，积 1500，数三位小数得 1.500，划去末尾两个 0 得 1.5；右边 0.35×300，3 和 5 对齐，00 写在后面，积 10500，数两位小数得 105.00，去 0 得 105；下方对比：1500→1.500→1.5 正确，1500→15→0.015 错误](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-05/trailing-zeros.svg "顺序不能反：先按两个乘数的小数位数点好小数点，再划去末尾的 0")

### 4. 想一想：注意什么（5 分钟）

请学生结合刚才的两道题和《包装》里的经验，说说“计算小数乘法时要注意什么”，老师整理成四条：

1. **先估一估**：大概是多少，比哪个乘数大还是小。
2. **按整数乘法算**：竖式末位对齐，不用对齐小数点（和小数加减法不同）。
3. **数位数，点小数点**：两个乘数一共有几位小数，就从积的右边起数出几位；位数不够，在前面用 0 补足。
4. **再去 0、再检验**：点好小数点后，末尾的 0 可以去掉；最后和估算的结果比一比。

可以马上用“练一练”第 3 题检验：0.15×0.63，按 15×63＝945 算，要数四位小数，945 只有三位数，前面补 0，得 0.0945。

### 5. 积一定比乘数大吗（9 分钟）

1. **算一算**：2.3 分别乘 1.2、1.05、1、0.9、0.86。分组计算，每组负责一两道，全班汇总：2.76、2.415、2.3、2.07、1.978。
2. 关键提问：**积一定比乘数大吗**？请学生把积和 2.3 比一比，再看乘数，分成三类。

![上方表格：乘数 1.2、1.05、1、0.9、0.86 对应的积是 2.76、2.415、2.3、2.07、1.978；下方数轴上 2.3 处画一条绿色虚线，乘 0.86 和 0.9 的积落在左边，乘 1.05 和 1.2 的积落在右边，乘 1 的积正好在 2.3；底部写着乘数比 1 小积比 2.3 小，乘数比 1 大积比 2.3 大](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-05/product-size.svg "以乘数 1 为界：比 1 大，积落在 2.3 右边；比 1 小，积落在左边")

3. **举例验证**：每组换一个数（如 5.6、0.8、12），各乘一个比 1 大和一个比 1 小的数，看规律是否还成立。
4. **用意义说理**：2.3×1.2 是求 2.3 的 1.2 倍，比 1 个 2.3 多；2.3×0.9 是求 2.3 的 0.9 倍，连 1 个 2.3 都不到，当然更小。
5. 回到春蚕：1.2×1.25 的积比 1.2 大，因为 1.25 比 1 大——这正是开头估算的依据。

> **设计意图**：这个规律不是让学生背的，而是给计算装上“检查器”。学生能说出“乘数比 1 小，积一定比 2.3 小”，以后看到 0.9×1.5＝13.5 就能一眼看出错。

### 6. 练习小结（4 分钟）

1. “练一练”第 2 题：不计算，判断 0.9×1.5＝13.5、9.9×7.1＝60.29、2.8×1.5＝2.4。（三道都错：0.9×1.5 应比 1.5 小；9.9×7.1 接近 10×7＝70；2.8×1.5 应比 2.8 大）
2. 小结：回到开头那根 1.2 千米的蚕丝——春蚕丝约 1.5 千米，丝巾约 105 克。请学生说说今天最想提醒同伴的一条“注意”。

## 五、趣味设计

4 个可以直接用的小设计：

1. **积的大小手势**：老师报算式，如 3.6×0.8、0.5×1.2、7.4×1，全班不计算，用手势回答积和第一个乘数比：手往上举表示“大”，手平伸表示“相等”，手往下压表示“小”。10 道题 1 分钟，专治“越乘越大”。
2. **“0 去哪儿了”侦探卡**：每组拿到 3 张错题卡（1500 写成 0.015、10500 写成 1.05、945 写成 0.945），找出错在哪一步，用红笔改正，再给错题起一个“罪名”，如“先拆房子再点灯”。
3. **一条丝巾里有多长的丝**？织一条丝巾用 300 条秋蚕的丝，首尾连起来是 1.2×300＝360 千米。让学生先猜再算，感受小小的蚕丝背后的大数。
4. **面积图拼一拼**：发一张长 12.5 厘米、宽 12 厘米的长方形纸片（把 1.25、1.2 放大 10 倍），沿 10 厘米处各剪一刀，得到四块。先让学生说“1×1＋0.2×0.25”用了哪两块，再把四块拼回去，直观看到漏掉的部分。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象的算理变成可以操作的东西、让每个学生拿到适合自己的练习**。《蚕丝》的错误很集中（先去 0、拆开乘、越乘越大），正适合让 AI 帮忙做归类和分层。

### 课前：学情前测

**3 道题就能看出全班卡在哪一步。** 课前一天发一个小测：

1. 计算 1.2×1.25（看有没有人“拆开乘”）；
2. 计算 0.35×300（看 0 的处理）；
3. 不计算，判断 2.3×0.9 的积比 2.3 大还是小，说说理由（看“越乘越大”的观念）。

收齐答案后交给 AI 按错因归类，再决定课上把时间花在哪：多数人拆开乘，面积图环节就放慢；多数人去 0 出错，就把两道竖式对比多讲一轮。

可以直接复制的提示词：

```
我是小学四年级数学老师，明天要上北师大版四年级下册第三单元《蚕丝》（小数乘法）。
下面是全班课前小测的答案，题目是：①1.2×1.25 ②0.35×300 ③不计算，判断 2.3×0.9 的积比 2.3 大还是小，说明理由。
（粘贴答案，每行一名学生）
请帮我：
1. 按错误原因分类，例如“先去 0 再点小数点”“把 300 的 0 算进小数位数”“整数部分和小数部分分开乘”“认为积一定比乘数大”，给出每类人数和一个典型答案；
2. 说明每类错误背后学生可能是怎么想的；
3. 针对人数最多的两类，各建议一个 3 分钟以内的课堂纠错活动。
不要超出四年级下册小数乘法的范围。
```

### 课中：先估，再算，再验证

**让估算走在竖式前面，让面积图走在结论前面。** 这节课的顺序是：学生先估范围 → 再用竖式算 → 最后用面积图或数轴验证。互动课件的价值在“验证”和“操作”：

- **可拖动的面积图**：把长方形的长和宽设成 1.25 和 1.2，学生先在纸上圈出“1×1＋0.2×0.25”用到的两块，再在课件里点亮这两块，剩下两块一目了然。把数换成 2.4×1.5，再试一次，“拆开乘”的错误就从个例变成了规律。
- **积的位置滑块**：在数轴上固定 2.3，学生拖动乘数从 0.5 到 1.5，看积的点在 2.3 两边移动。先让学生预测“乘 0.98 时积在哪边”，再松手验证。
- **全班即时作答**：“积的小数点点在哪”做成选择题（0.015、1.5、15），课件当场显示选项分布，老师只讲错得最集中的那一个。
- **AI 帮老师看说理**：请学生用一句话说明“为什么 2.3×0.9 比 2.3 小”，AI 快速筛出只写“因为乘了小数”的回答，挑两三条投屏讨论——乘 1.2 也是乘小数，积却变大了。

### 课后：分层练习

**一人一份的练习，按错因来配。** 先去 0 出错的学生，多练积末尾有 0 的竖式；拆开乘的学生，配面积图题；已经掌握的学生，挑战“不计算比较大小”。

### 教研：AI 听课伙伴

**让 AI 帮你看“说理”有没有落地。** 课后把板书照片、面积图环节的几段学生发言交给 AI，让它对照目标指出：学生是在背“乘数小于 1 积就小”，还是能用“几倍”“几个计数单位”来说明理由；“少算了 2 块”有没有被学生自己说出来。再让它起草教学反思或说课稿初稿，老师在初稿上修改。

### 使用边界

1. **教材细节以课本为准**：资料数据（1.2 千米、0.35 克、1.25 倍）、例题和练习题号，AI 可能记错，一律对照课本第 42–43 页核实。
2. **演示不替代思考**：先估、先算、先说理由，再用面积图和数轴验证；顺序反了，动画越精彩，学生想得越少。
3. **AI 出的题要过一遍**：检查有没有超纲（比如出现小数除法、三位小数乘三位小数），有没有答案错误，再发给学生。

**设计建议**：这一课最适合做成互动课件的是两个“验证器”——一个是可以拖动长宽、点亮四块的面积图，专门对付“拆开乘”；一个是固定被乘数、拖动乘数的数轴，让学生先预测积落在哪一边，再亲眼看规律。配上“积的小数点点在哪”的全班即时作答，就能把这节课的三个错因各个击破。

## 八、分层作业

括号里是答案要点。

**基础**

1. 用竖式计算：1.6×2.5、0.45×200、0.24×0.5、0.04×0.6。（4；90；0.12；0.024，要在前面补 0）
2. “练一练”第 4 题：先想积比第一个乘数大还是小，再计算 0.12×50、2.6×0.5、1.3×2.2、9.6×0.8。（6，大；1.3，小；2.86，大；7.68，小）

**提升**

3. 小明算 2.4×1.5＝2×1＋0.4×0.5＝2.2。他错在哪里？画图说明，并算出正确结果。（漏算了 2×0.5 和 0.4×1 两块；正确结果是 3.6）
4. “练一练”第 6 题：鸵鸟身高 2.75 米，长颈鹿身高是鸵鸟的 2.2 倍，长颈鹿高多少米？（2.75×2.2＝6.05 米；2.2 比 1 大，所以比 2.75 米高）

**挑战**

5. 已知 1.2×1.25＝1.5，直接写出 12×125、0.12×12.5、120×0.125 的积。（1500；1.5；15）
6. a 是一个不为 0 的数，把 a×0.99、a×1.01、a 按从大到小排列。（a×1.01＞a＞a×0.99）

## 九、易错点与应对

1. **先去 0 再点小数点**：把 1500 先写成 15，再数三位，得 0.015。原因是把“末尾的 0 可以去掉”提前用了。应对：口诀“先点灯，再打扫”——先点小数点，再去 0；对照上面的两道竖式图，让学生说出每一步。
2. **整数部分、小数部分分开乘**：1.2×1.25 算成 1.05。原因是把小数加法的做法搬到了乘法。应对：先用估算发现矛盾（1.05 比 1.2 还小），再用面积图找出漏掉的两块。
3. **部分积错位或小数点点错**：“练一练”第 1 题里，一位同学的第二个部分积 368 没有和十位对齐，加出 598，写成 0.598；另一位部分积写对了，小数点却点错，得 0.391。正确的是 3.910，即 3.91 元。应对：说清“368 表示 368 个十”，所以末位要写在十位上；点小数点前先数清两个乘数一共几位小数，再用估算检验（4.6 千克、每千克不到 1 元，总价应接近 4 元）。
4. **“乘小数积就变小”**：从一个极端走到另一个极端。应对：把 2.3×1.2 和 2.3×0.9 放在一起，强调判断标准是“乘数和 1 比”，不是“乘数是不是小数”。

## 十、反思与说课

- **反思重点**：学生能不能说出“为什么 1×1＋0.2×0.25 不对”？能不能不计算就判断积比乘数大还是小，并说出理由？只会背“乘数小于 1 积就小”，说明“几倍”的意义还没有建立起来。
- **说课可以突出**：本课沿着“算对 → 算明白 → 看出规律”的线索展开；用估算和面积图双重验证突破“拆开乘”；用一组算式加数轴让学生自己发现积和乘数的大小关系，把规律变成估算、检验的工具，落实运算能力和数感。

## 常见问题

**《蚕丝》这节课怎么导入比较好？**
让学生先猜“一个蚕茧里的丝有多长”，再出示约 1.2 千米的资料，换算成 400 米跑道的 3 圈。数据本身就很有吸引力，接着请学生根据资料提问题，自然引出 1.2×1.25 和 0.35×300。

**1.2×1.25 为什么不能算成 1×1＋0.2×0.25？**
因为 1.2×1.25 是长 1.25、宽 1.2 的长方形面积，分成四块后，1×1 和 0.2×0.25 只是其中两块，还漏了 1×0.25 和 0.2×1。四块合起来是 1＋0.25＋0.2＋0.05＝1.5。估算也能发现问题：1.05 比 1.2 还小，不符合“春蚕丝更长”。

**积的末尾有 0，先去 0 还是先点小数点？**
先点小数点，再去 0。小数点的位置是按两个乘数的小数位数从积的最右边数出来的，先去掉 0 会让位数数错，比如 1500 会被写成 0.015。点好小数点得 1.500，再去 0 得 1.5。

**为什么要在这一课研究积和乘数的大小关系？**
学到这里，学生已经能熟练计算，最需要的是判断结果合不合理的“检查器”。现行版教材用 2.3 乘一组数，让学生看出乘数比 1 大积就大、比 1 小积就小，既纠正了“越乘越大”的整数经验，也为估算、检验和以后学小数除法打基础。

**AI 在这节课里最该用在哪？**
最该用在三件事上：课前用 3 道小题让 AI 帮你按错因归类，课中让学生拖动面积图和数轴验证自己的估计，课后按错因生成分层练习。不要用动画代替学生自己的估算和说理。
