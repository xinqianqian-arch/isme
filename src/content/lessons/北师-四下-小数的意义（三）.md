> **一句话备课结论**：这一课把前两课的十分之一、百分之一、千分之一正式命名为小数的计数单位，放进数位顺序表：小数和整数一样，满十进一。真正的难点是**看懂数位顺序表的结构**：以个位为中心，十位对十分位，百位对百分位，没有“个分位”。第 2 课时再由“0.6 和 0.60 一样大”得出小数的性质，让学生分清哪些 0 能去掉、哪些不能。

## 一、教材解读

### 前后联系

- **已经学过**：前两课理解了小数表示十分之几、百分之几、千分之几，会用小数表示长度和质量；四年级上册整理过整数的数位顺序表，知道相邻两个计数单位之间的进率是十；会用计数器拨数。
- **本课要学**：在计数器上拨小数，认识十分位、百分位、千分位，以及计数单位 0.1、0.01、0.001；整理小数数位顺序表；体会小数的计数单位也是满十进一；通过涂一涂发现小数的性质：小数的末尾添上 0 或去掉 0，小数的大小不变。
- **后面要用**：下一课《比大小》要从高位一位一位比，靠的就是数位；《买菜》的竖式要相同数位对齐；《比身高》里“把 6 看成 6.0”、练一练里“哪些 0 可以去掉”，用的是小数的性质；第三单元《小数点搬家》要用到练一练第 6 题“0.1×10”这类发现。

这一课是本单元的“工具课”：后面比大小、算加减，都离不开这张数位顺序表和小数的性质。

### 编排意图

第 6～8 页内容多，可以分成两块：第 6 页是数位和计数单位，第 7 页的“试一试”是小数的性质。本文按 2 课时设计；只有 1 课时的学校，可以把练一练第 5、6 题放到课后。

1. **北京地铁 10 号线**：列车最高运行速度是 80 千米/时，约为 22.222 米/秒，旁边的男孩说“1 秒就跑 22 米多，好快！”。22.222 里有五个 2，是一个绝好的问题。
2. **在计数器上拨出 22.222**：说一说每个 2 分别表示多少。课本给出第一个：十分位上的 2 表示 2 个 1/10，也可以表示 2 个 0.1，后两个留给学生填。两个同学点题：“计数器上有小数点”“小数点右面第一位是十分位，第二位是百分位，第三位是千分位”。
3. **认一认**：一张数位顺序表，分整数部分、小数点、小数部分，两行分别是数位和计数单位；旁边的便签写着“小数部分的计数单位分别是 1/10、1/100、1/1000……也可以写成 0.1、0.01、0.001……”，小朋友嘀咕“好像也是满十进 1”。
4. **小数的计数单位也是满十进一**：“10 个 0.1 元是 1 元，10 个 0.01 元是 0.1 元”，配上 1、0.1、0.01 的面积图。
5. **试一试（第 7 页）**：小熊商店的毛巾每条 5 元，小狗商店每条 5.00 元，价格一样吗？再涂一涂 0.6 和 0.60，老爷爷总结：小数的末尾添上“0”或去掉“0”，小数的大小不变。
6. **练一练（第 7～8 页）**：计数器画一画（0.4、0.025、14.24）、米尺上填分数和小数、0.03 和 0.30 涂一涂、把相等的数连起来、数轴上填数，最后是带问号的思考题 0.1×10、0.01×100、0.001×1000。

## 二、学情分析

**已有基础**：会用计数器拨整数，熟悉整数数位顺序表；知道 0.1 是十分之一、0.01 是百分之一；会用小数表示长度和质量。

**可能的困难**：

1. **数位和计数单位分不清**：说“十分位是 0.1”。其实十分位是位置，十分之一（0.1）是计数单位，十分位上的 3 表示 3 个 0.1。
2. **以为以小数点为中心对称**：觉得小数点左边是个位，右边就该是“个分位”，或者把十分位说成“小数点右边的十位”。
3. **说不清一个小数里有几个计数单位**：0.025 里有几个 0.001？学生会说 2 个或 5 个，只看到了单个数字。
4. **乱去 0**：把 3.05 写成 3.5，把 600 写成 6，以为“只要是 0 就能去”。
5. **添 0 添错位置**：要把 3.5 写成两位小数，写成了 3.05。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 结合计数器和数位顺序表，认识小数的数位和计数单位，知道十分位、百分位、千分位上的数分别表示几个 0.1、几个 0.01、几个 0.001。（数感）
2. 理解小数的计数单位之间也是满十进一，能用“几个 0.1、几个 0.01”说出一个小数的组成，体会小数和整数在计数方法上的一致。（推理意识）
3. 通过涂一涂、比一比，发现并说明小数的性质，能根据需要去掉或添上小数末尾的 0。（几何直观）
4. 在地铁速度、商店价格等情境中，感受小数与生活的联系。

**教学重点**：认识小数的数位、计数单位和数位顺序表；理解小数的性质。

**教学难点**：理解小数计数单位之间的十进关系，区分数位和计数单位；分清哪些 0 能去掉、哪些不能。

## 四、教学过程

教材内容较多，本文安排 2 课时。下面 1～6 是第 1 课时（40 分钟），第 2 课时的安排写在本节最后。

### 1. 情境导入（4 分钟）

**22.222 里的五个 2，一样吗？** 出示课本第 6 页的北京地铁 10 号线：最高运行速度 80 千米/时，约为 22.222 米/秒。

- 学生读一读这个数。男孩说“1 秒就跑 22 米多”，追问：“22 米多”的“多”，指的是哪一部分？
- 关键提问：**五个 2 表示的大小一样吗**？学生会说不一样，但说不清各是多少。今天就来给每个位置起名字。

### 2. 拨一拨，说一说（10 分钟）

1. 学生在计数器上拨出 22.222，同桌互相检查：小数点拨在哪里？每一档上拨几颗？
2. 先说整数部分：十位上的 2 表示 2 个十，个位上的 2 表示 2 个一。
3. 再说小数部分：课本给出了十分位，学生照样说出百分位、千分位。

![计数器从左到右是百位、十位、个位、十分位、百分位、千分位，百位不拨珠，其余五档各拨 2 颗，底座上写着 22.222，个位和十分位之间有一个红色小数点；下方逐行写出：十位上的 2 是 2 个十，个位上的 2 是 2 个一，十分位上的 2 是 2 个十分之一也就是 2 个 0.1，百分位上的 2 是 2 个百分之一也就是 2 个 0.01，千分位上的 2 是 2 个千分之一也就是 2 个 0.001](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-01/lesson-03/counter.svg "从左往右说：十位上的 2 是 20，个位上的 2 是 2，十分位上的 2 是 0.2，百分位上的 2 是 0.02，千分位上的 2 是 0.002")

4. 关键提问：**小数点右面第一位，为什么叫十分位**？引导学生联系前两课：这一位上的数表示几个十分之一，所以叫十分位；百分位、千分位同理。
5. 回到导入：“22 米多”的“多”是 0.222 米，也就是 2 个 0.1 米、2 个 0.01 米和 2 个 0.001 米。

### 3. 认一认：小数数位顺序表（10 分钟）

1. 先请学生默写四年级上册学过的整数数位顺序表（写到千位就够）。
2. 关键提问：**小数点右边的数位，该怎样接在这张表上**？学生分组试着补出十分位、百分位、千分位，以及对应的计数单位。
3. 出示课本第 6 页的数位顺序表，对照检查。

![小数数位顺序表：左边整数部分有千位、百位、十位、个位，计数单位是千、百、十、一（个）；中间是小数点；右边小数部分有十分位、百分位、千分位，计数单位是十分之一 0.1、百分之一 0.01、千分之一 0.001；表下面写着相邻两个计数单位之间的进率都是 10，三条弧线把十和十分、百和百分、千和千分连起来，最下面写着个位的左右两边名字一一对应，没有个分位](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-01/lesson-03/place-chart.svg "以个位为中心看：十和十分、百和百分、千和千分一一对应；小数点只是分界，它右边第一位是十分位")

4. 引导学生说发现，逐条板书：
   - 小数由整数部分、小数点、小数部分组成；
   - 小数部分的数位是十分位、百分位、千分位……计数单位是 0.1、0.01、0.001……
   - 以个位为中心，左右两边的名字一一对应；没有“个分位”；
   - 两边都可以无限延伸，课本上用“……”表示。
5. 追问：**“十分位”和“十分之一”有什么不同**？学生说出：十分位是位置，十分之一是计数单位；十分位上的数是几，就表示几个十分之一。

### 4. 满十进一（6 分钟）

1. 读课本：10 个 0.1 元是 1 元，10 个 0.01 元是 0.1 元。对照面积图：10 条是 1 个整正方形，10 小格是 1 条。
2. 在计数器上演示：千分位上一颗一颗地拨，拨到第 10 颗时怎么办？——满十，向百分位进一。全班齐说：10 个 0.001 是 0.01。
3. 学生总结：**相邻两个计数单位之间的进率都是 10**，小数和整数一样，满十进一。

> **设计意图**：数位顺序表如果只让学生背，“十分位、百分位、千分位”很容易和“十位、百位、千位”记混，也看不出为什么没有“个分位”。先让学生自己把四上的表“往右接”，再用“以个位为中心”去看，学生记住的是结构；“满十进一”放在计数器上拨出来，小数和整数的计数方法就连成了一体。

### 5. 练一练（8 分钟）

1. **第 1 题在计数器上画一画**：0.4 课本已经画好，十分位上 4 颗珠，0.4 里有 4 个 0.1；0.025 在百分位画 2 颗、千分位画 5 颗，0.025 里有 25 个 0.001；14.24 中，个位上的 4 表示 4 个一，百分位上的 4 表示 4 个 0.01（百分之一）。重点说 0.025：2 个 0.01 就是 20 个 0.001，再加 5 个，是 25 个。
2. **第 2 题米尺上填一填**：1 厘米是 1/100 米、0.01 米；10 厘米是 10/100 米，也就是 1/10 米，写成 0.10 米或 0.1 米；60 厘米是 60/100 米，也就是 6/10 米，写成 0.60 米或 0.6 米。学生会发现：同一个位置，可以写成两种小数。这两种写法一样大吗？留给第 2 课时。

### 6. 小结（2 分钟）

1. 回到导入：22.222 的五个 2，现在都有了名字。
2. 一句话小结：**小数的计数单位是 0.1、0.01、0.001，相邻两个计数单位之间的进率都是 10**。
3. 课后挑战：练一练第 6 题，0.1×10、0.01×100、0.001×1000，用“10 个 0.1 是 1”来想一想，你有什么发现？

### 第 2 课时（40 分钟）

**第 2 课时研究小数末尾的 0：发现小数的性质，并分清哪些 0 能去掉。**

**① 毛巾价格一样吗（5 分钟）**：出示课本第 7 页的两个商店。

![两个黏土小摊并排：左边绿色遮棚下是小熊店主，身后挂着花朵毛巾和圆点毛巾；右边蓝色遮棚下是小狗店主，身后挂着树叶毛巾和条纹毛巾；两个摊位前各立着一块空白的黄色爆炸形价签，中间一个提着篮子的男孩托着下巴比较](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-01/lesson-03/shops.webp "试一试：小熊商店每条 5 元，小狗商店每条 5.00 元（价格见课本第 7 页），到哪家买更便宜？")

学生说：5.00 元是 5 元 0 角 0 分，就是 5 元，价格一样。追问：那商店为什么要写成 5.00 元？（价签上统一写到“分”，方便比较。）

**② 涂一涂，你发现了什么（10 分钟）**：在 10 条图上涂 0.6，在 100 格图上涂 0.60。

![上面一组：10 条图涂 6 条表示 0.6，即 6 个 0.1；100 格图涂 60 格表示 0.60，即 60 个 0.01，两张图涂色部分一样大；下面一组：100 格图涂 30 格是 0.30，等于 0.3，末尾的 0 可以去掉；100 格图只涂 3 格是 0.03，不等于 0.3，这个 0 在十分位占位，不能去掉](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-01/lesson-03/property.svg "0.6 和 0.60 涂色部分一样大；0.30 末尾的 0 能去掉，0.03 中间的 0 不能去掉")

- 关键提问：**0.6 是 6 个 0.1，0.60 是 60 个 0.01，为什么一样大**？引导学生说出：1 个 0.1 就是 10 个 0.01，6 个 0.1 就是 60 个 0.01，只是分得更细了。
- 再回到米尺：1 分米 = 0.1 米 = 0.10 米 = 0.100 米。
- 请学生用自己的话总结，再对照老爷爷的话：**小数的末尾添上 0 或去掉 0，小数的大小不变**。

**③ 辨一辨：哪些 0 能去掉（8 分钟）**：练一练第 3 题，先涂 0.03 和 0.30，再说哪个 0 可以去掉。学生会发现：0.30 末尾的 0 能去掉；0.03 的 0 在十分位上占位，去掉就变成了 0.3。再补充两个反例：3.05 和 600 里的 0 能去掉吗？（3.05 的 0 在中间，不能去；600 是整数，不能用小数的性质。）

> **设计意图**：小数的性质一句话就能背下来，难的是“末尾”两个字。学生最常见的错误是见 0 就去，所以第 2 课时专门留出时间辨一辨：同样是 0，在末尾、在中间、在整数里，结果完全不同。每次判断都追问“去掉以后大小变了没有”，学生就会自己回到计数单位上去想。

**④ 练一练（12 分钟）**：

1. **第 4 题把相等的数连起来**：3.20 = 3.200，42.040 = 42.04，0.0600 = 0.06。另外两组是“陷阱”：3.90 和 3.09 不相等，34.0800 和 34.8 也不相等（34.0800 = 34.08）。请学生说说陷阱错在哪里：被去掉的是中间的 0。
2. **第 5 题数轴上填数**：左边 0 到 1 平均分成 10 份，第一格是 1/10，7/10 是 0.7；0 到 0.1 平均分成 10 份，3/100 是 0.03，0.06 是 6/100。右边 0 到 3，每一大格平均分成 10 份，箭头依次指向 0.3、0.9、1.7、2.8。哪个数更接近 0.5？（0.3，只差 0.2）哪个数更接近 2？（1.7，只差 0.3）
3. **改写**：不改变大小，把 0.7 写成三位小数（0.700），把 5 写成两位小数（5.00）。回扣第 2 课：500 克 = 0.500 千克 = 0.5 千克。

**⑤ 小结（5 分钟）**：小数的性质说的是“末尾”的 0；去 0、添 0 之后，都要问一句“大小变了没有”。预告下节课：有了数位和小数的性质，0.69 和 0.8 谁大？

## 五、趣味设计

4 个可以直接用的小设计：

1. **数位找朋友**：7 名学生分别举着“千位、百位、十位、个位、十分位、百分位、千分位”的卡片，另一名学生举着大大的小数点站在个位和十分位之间。老师喊“十位”，十分位的同学要马上站出来和他击掌；喊“个位”，没人站出来，全班齐说“没有个分位”。
2. **满十进一大合唱**：老师在千分位上一颗一颗拨珠，全班跟着数，数到第 10 颗时齐喊“满十进一”，把珠子换到百分位。连续玩几轮，学生自然记住 10 个 0.001 是 0.01，10 个 0.01 是 0.1。
3. **小熊和小狗开店**：两名学生扮店主，给同一件商品写价签，比如 5 元、5.0 元、5.00 元，顾客判断哪家便宜；再换成 5.5 元和 5.05 元，顾客还能随便选吗？在游戏里分清“末尾的 0”和“中间的 0”。
4. **0 的去留法庭**：出示 2.50、20.5、4.080、0.70、700，学生当“法官”，判断每个 0 能不能去掉，并说出理由。（2.50 → 2.5；20.5 不能去；4.080 → 4.08；0.70 → 0.7；700 是整数，不能用小数的性质）

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象概念变成可以操作的东西、让每个学生拿到适合自己的练习**。这节课有两个难点：数位顺序表的结构、哪些 0 能去掉。AI 可以帮老师摸清学生对“数位”和“计数单位”的混淆，也能快速出大量“去 0 辨析”的变式题。

### 课前：学情前测

**看学生是记住了名字，还是看懂了结构。** 课前发 3 道小题：

1. 3.45 中的“4”在什么位上？表示什么？
2. 10 个 0.01 是多少？
3. 0.5 和 0.50 哪个大？为什么？

第 1 题能看出谁把“十分位”和“十分之一”混为一谈，第 2 题能看出谁已经有“满十进一”的意识，第 3 题能看出学生对小数的性质有没有直觉。

可以直接复制的提示词：

```
我是小学四年级数学老师，要上北师大版四年级下册第一单元《小数的意义（三）》，
内容是小数的数位、计数单位、数位顺序表和小数的性质，共 2 课时。
下面是全班学生课前小测的答案，每行一名学生，依次是三道题：
1. 3.45 中的“4”在什么位上，表示什么；
2. 10 个 0.01 是多少；
3. 0.5 和 0.50 哪个大，为什么。
（粘贴答案）
请帮我：
1. 第 1 题分成“数位和意义都对”“只说对数位”“说成 4 个 0.01 或 4 个十”“其他”四类；
2. 第 2 题统计答 0.1、0.10、1、其他的人数；
3. 第 3 题把理由分成“用计数单位解释”“用钱或长度解释”“认为 0.50 大”“没写理由”四类，各摘一个典型答案；
4. 建议第 1 课时“认一认数位顺序表”和第 2 课时“涂一涂”各重点讲什么。
```

### 课中：先接表，再验证

**让学生先把整数数位顺序表“往右接”，再用课件验证。**

- **数位表往右长**：学生先猜“个位右边是什么、再右边是什么”，课件再一格一格长出十分位、百分位、千分位，并在个位两边亮起成对的颜色。学生自己猜中“十对十分、百对百分”，比直接看完整的表印象深得多。
- **计数器满十进一**：学生先说“千分位满十进到哪里”，再在互动计数器上一颗一颗拨，看珠子自动进到百分位。
- **涂色重叠比较**：0.6 和 0.60 分别涂完后，课件把两张图叠在一起，涂色部分完全重合，学生亲眼看到“大小不变”；再叠 0.3 和 0.03，差别一目了然。
- **全班即时作答**：出示“3.050、30.5、0.300、600”，每人判断哪些 0 能去掉，课件当场显示分布，老师只讲分歧最大的那一个。

### 课后：分层练习

**按错因布置。** 数位和计数单位分不清的学生，多做“某一位上的数表示几个什么”；乱去 0 的学生，多做“去 0 辨析”；已经掌握的学生，挑战“一个小数由几个计数单位组成”的逆向题。

可以直接复制的提示词：

```
请为北师大版四年级下册《小数的意义（三）》生成课后练习，分三层：
- 基础：6 道题，如“6.375 中的 7 在（ ）位，表示 7 个（ ）”“0.025 里面有（ ）个 0.001”，
  针对“数位和计数单位分不清”的错误；
- 提升：6 道判断题，判断各数中的 0 能不能去掉并说明理由，
  必须包含末尾的 0、中间的 0、整数末尾的 0 三种情况，针对“见 0 就去”的错误；
- 挑战：2 道题，如“一个小数由 3 个一、5 个 0.1 和 8 个 0.001 组成，这个数是多少”
  “0.1×10、0.01×100、0.001×1000 各得多少，你发现了什么”。
要求：小数不超过三位；不涉及小数大小比较和加减法（后面的课才学）；每题附答案和一句话讲解。
```

### 教研：AI 听课伙伴

**用两个课时的数据看效果。** 把第 1 课时前测的错因分布和第 2 课时“去 0 辨析”的全班答案一起交给 AI，请它比较哪种错误减少了、哪种还顽固，再起草教学反思中“数位顺序表的教学”这一段。数据由老师自己收集，结论由老师自己判断，AI 只负责整理。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：地铁的数据、数位顺序表、两家商店的价格和练一练的数以第 6～8 页为准，AI 复述时可能把数位名称写错。
2. **演示不替代思考**：先让学生猜个位右边是什么，再让课件长出数位；先涂再叠，先判断再看答案。
3. **AI 出的题要过一遍**：检查有没有出现“个分位”这类错误说法，有没有把“化简”扩展到整数，有没有提前出比大小的题。

这一课最适合做成互动课件的是三处：一个能拨到千分位、满十自动进位的计数器；一张能“往右长”的数位顺序表，学生先猜下一格的名字，再点出来验证，个位两边成对亮起；一组能把两张涂色图叠在一起比较的方格图，用在 0.6 和 0.60、0.3 和 0.03 的辨析上。设计时守住“让学生先想、再动手验证”的顺序。

## 七、板书设计

板书左边是第 1 课时的数位顺序表，右边留给第 2 课时的小数的性质：

- **标题**：小数的意义（三）
- **数位顺序表**：千位、百位、十位、个位 · 十分位、百分位、千分位；计数单位：千、百、十、一 · 0.1、0.01、0.001
- **发现**：以个位为中心，十对十分，百对百分，千对千分，没有“个分位”；相邻两个计数单位之间的进率都是 10
- **例子**：22.222 中的五个 2 分别表示 2 个十、2 个一、2 个 0.1、2 个 0.01、2 个 0.001
- **小数的性质**（第 2 课时）：5 元 = 5.00 元，0.6 = 0.60；小数的末尾添上 0 或去掉 0，小数的大小不变
- **提醒**：只看末尾，0.03 ≠ 0.3，3.05 ≠ 3.5

## 八、分层作业

括号里是答案要点。

**基础**

1. 6.375 中，“6”在（ ）位，表示 6 个（ ）；“7”在（ ）位，表示 7 个（ ）。（个，一；百分，0.01）
2. 化简：0.50，4.300，20.080。（0.5，4.3，20.08）

**提升**

3. 10 个 0.001 是（ ），100 个 0.001 是（ ），1 里面有（ ）个 0.01。（0.01；0.1；100）
4. 不改变数的大小，把 3 和 0.8 都改写成两位小数。（3.00，0.80）

**挑战**

5. 一个小数由 3 个一、5 个 0.1 和 8 个 0.001 组成，这个数是多少？（3.508，百分位上没有，写 0 占位）
6. 尝试计算 0.1×10、0.01×100、0.001×1000，说说你是怎么想的。（都等于 1。如 10 个 0.1 是 1，100 个 0.01 是 1）

## 九、易错点与应对

1. **数位和计数单位混用**：说“十分位是 0.1”。应对：用“座位和人”打比方，十分位是座位，十分之一是坐在这个座位上的计数单位；多说“十分位上的 3 表示 3 个 0.1”。
2. **以为有“个分位”**：以小数点为中心找对称。应对：回到数位顺序表，以个位为中心看，十位对十分位，个位只有一个。
3. **说不出一个小数里有几个计数单位**：0.025 里有几个 0.001，答成 2 个或 5 个。应对：在计数器上把百分位的 2 颗珠子“换”成 20 颗千分位的珠子，再加上 5 颗。
4. **见 0 就去**：3.05 写成 3.5，600 写成 6。应对：每次去 0 都追问“去掉以后大小变了没有”，用涂色图或钱数检验；强调小数的性质只管“小数的末尾”。
5. **添 0 添错位置**：把 3.5 改写成两位小数写成 3.05。应对：添 0 只能添在最后面，3.5 是 3 元 5 角，3.50 还是 3 元 5 角，3.05 却是 3 元 5 分。

## 十、反思与说课

- **反思重点**：第 1 课时看学生能不能说出“以个位为中心”“没有个分位”，能不能区分十分位和十分之一；第 2 课时看学生能不能说清 0.6 为什么等于 0.60，能不能判断中间的 0 不能去。只会背性质、遇到 3.05 就去 0，说明“辨一辨”的时间不够。
- **说课可以突出**：本课分 2 课时，第 1 课时让学生把整数数位顺序表“往右接”，在计数器上认识小数的数位、计数单位和满十进一，体现整数和小数计数方法的一致性；第 2 课时从两家商店的价格出发，用涂色图发现小数的性质，再通过辨析突破“哪些 0 能去掉”。

## 常见问题

**《小数的意义（三）》这节课怎么导入比较好？**
用课本上的北京地铁 10 号线导入：约 22.222 米/秒，一个数里有五个 2。先问“五个 2 表示的大小一样吗”，学生说得出不一样，却说不清各是多少，自然就想给每个位置起名字。

**怎样突破小数数位顺序表这个难点？**
先让学生默写整数数位顺序表，再自己往右接，最后以个位为中心看：十位对十分位，百位对百分位，千位对千分位，个位只有一个，所以没有“个分位”。同时分清“十分位”是位置，“十分之一”是计数单位，十分位上的数是几，就表示几个十分之一。

**小数里的哪些 0 可以去掉？**
只有小数末尾的 0 可以去掉，大小不变，比如 0.30 = 0.3、42.040 = 42.04。小数中间的 0 不能去，0.03 去掉 0 就成了 0.3；整数末尾的 0 也不能去，600 不能写成 6。判断时问一句“去掉以后大小变了没有”。

**教材为什么先讲数位和计数单位，再讲小数的性质？**
小数的性质要靠计数单位来解释：0.6 是 6 个 0.1，0.60 是 60 个 0.01，1 个 0.1 等于 10 个 0.01，所以一样大。先认识计数单位和满十进一，学生才能自己说出性质背后的道理，而不是只背一句话。

**AI 在这节课里最该用在哪？**
最该用在两处：课前用小测分清学生是记住了数位名字，还是看懂了结构；课后针对“见 0 就去”生成大量辨析题，末尾的 0、中间的 0、整数的 0 混在一起练。课上数位顺序表先让学生猜，再用课件验证。
