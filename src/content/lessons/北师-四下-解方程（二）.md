> **一句话备课结论**：这节课是《解方程（一）》的“乘除版”：天平从“两边同时加减”变成“两边同时变成几倍、平均分成几份”，得到**等式两边都乘同一个数（或除以同一个不为 0 的数），等式仍然成立**。学过上一课，学生会觉得这节课很顺；真正的难点在两处：一是 **x÷3＝9 该乘还是该除**，二是把解题过程写成连等的“老毛病”，课本特意安排了两道错例来辨析。

## 一、教材解读

### 前后联系

- **已经学过**：上一课用天平发现了“等式两边都加上（或减去）同一个数，等式仍然成立”，会解 x＋a＝b、x－a＝b 型方程；本单元第 3 课《方程》列出了 4y＝2000（4 盒种子一共 2000 克）。乘与除的关系、“几个几”和“平均分”的意义，学生早已熟悉。
- **本课要学**：通过观察天平，发现等式两边都乘同一个数（或除以同一个不为 0 的数），等式仍然成立；用它解 4y＝2000、x÷3＝9、7y＝28 这类方程；辨析错误的解法，养成“一步一行、不写连等”的习惯。
- **后面要用**：下一课《猜数游戏》把加减、乘除两条规律连起来，解 2x＋20＝80；练习五里有 4x＋9＝249、36＋2x＝48、m÷0.6＝0.45 等综合练习，以后用方程解决问题也离不开这两条规律。

### 版本说明

本文依据现行版（既有版）北师大版四年级下册第五单元“认识方程”第 70～71 页编写。北师大新版四年级下册预计 2027 年春季启用，届时按新课本更新。

在《义务教育数学课程标准（2022 年版）》里，方程整体放到了第四学段（初中）的“方程与不等式”；小学第三学段在“数量关系”主题下的要求是“能在具体问题中感受等式的基本性质”。用现行版上这一课，课本的要求要完成，同时把功夫花在“为什么两边都乘、都除仍然相等”的感受和说理上，不必额外加深。

### 编排意图

教材第 70～71 页的线索和上一课一样：**观察天平 → 发现规律 → 用规律解方程 → 检验**，最后多了一步**辨析错误**。

1. **4 架天平分 2 组**：x＝5 变成 3x＝3×5，左边的 x 变成 3 个，右边的 5 克也变成 3 个；2x＝20 变成 2x÷2＝20÷2，两边都只留下一半。题目写成一个讨论题：“等式两边都乘同一个数（或除以同一个不为 0 的数），等式还成立吗？与同伴交流你的想法。”男孩说“等式两边都乘同一个数，等式成立”，女孩说“等式两边都除以同一个不为 0 的数，等式成立”。
2. **解前面列出的方程 4y＝2000**：三幅简笔天平，左边的 4y 先拆成 4 个 y，最后一架只剩 y 和 500；提示“方程两边都除以 4”，女孩用“4×500＝2000，y＝500 对了”检验。
3. **从模仿到独立**：x÷3＝9 给了填空支架（x÷3×3＝9 ○ □），7y＝28 只给一个“解：”。
4. **下面的解法正确吗**：两个错例，x－19＝19 写成 x－19＋19＝19－19，x＝0；3x＝36 下面接着写“＝36÷3”，再写 x＝12。旁边提醒“等号两边要相等哦”。
5. **练一练**（第 71 页）：用画图或举例说规律；“森林医生”找错（7x＝35＝35÷7＝5；x－5＝8 写成 x－5－5＝8－5，x＝3）；6 道解方程；游泳池的宽；正方形和长方形花坛；无障碍斜坡。

值得注意的是，第一个错例 x－19＝19 其实是加减方程。教材把它放在乘除这一课，是有意让学生把两课的方法混在一起辨析，而不是学一种练一种。

## 二、学情分析

**已有基础**：会用等式两边都加减同一个数解方程；会写“解：”和检验；理解“4y 表示 4 个 y”“平均分”的意思。

**可能的困难**：

1. **方向搞反**：x÷3＝9 写成 x÷3÷3＝9÷3，看到“÷3”就跟着除。
2. **看不懂 4y÷4**：不明白 4y÷4 为什么等于 y，只会照着写。
3. **写成连等**：3x＝36＝36÷3＝12，做计算题“一路等下去”的习惯带进了解方程。
4. **加减、乘除混用**：x－19＝19 左边加 19，右边却减 19；或者 3x＝36 写成 3x－3＝36－3。
5. **不理解“不为 0”**：以为乘、除随便哪个数都可以。
6. **遇到 0 就犯难**：x÷28＝0 以为没法解，或者写成 x＝28。
7. **列方程卡在等量关系**：游泳池、斜坡这类题，找不到“长×宽＝面积”“每 1 米高需要 8 米”这样的关系。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 观察天平、举例验证，发现等式两边都乘同一个数（或除以同一个不为 0 的数），等式仍然成立，并能说出“不为 0”的原因。（推理意识）
2. 会用这条性质解 ax＝b、x÷a＝b 型方程，书写规范并检验。（运算能力）
3. 能辨析连等、方向相反、两边做的不一样等错误解法，说清错在哪一步。（推理意识）
4. 能根据面积、周长、斜坡等情境找出等量关系，列出简单方程并求解。（模型意识）

**教学重点**：理解等式两边都乘（或除以）同一个数的性质，并用它解 ax＝b、x÷a＝b 型方程。

**教学难点**：根据 x 被“乘”还是被“除”，判断两边该除还是该乘；规范书写，不写连等。

## 四、教学过程

### 1. 复习导入（4 分钟）

**4 盒种子，每盒多重？** 出示第 66 页：4 盒种子一共 2000 克，上节课列出了方程 4y＝2000。

- 先口答两道上节课的方程：x＋35＝90（x＝55），x－1.5＝6（x＝7.5）。
- 关键提问：**4y＝2000 能用上节课的办法解吗？两边减去什么**？学生试一试会发现：两边都减 4，左边是 4y－4，不是 y；减去几都不能让 y 单独留下。
- 引出：需要一条新的规律。

### 2. 发现规律（10 分钟）

1. 出示第 70 页的两组天平（先遮住等式），请学生给每架天平写等式。
2. 关键提问：**从 x＝5 到 3x＝3×5，天平两边发生了什么变化**？学生说出：左边的 x 变成了 3 个，右边的 5 克也变成了 3 个，两边都变成原来的 3 倍，天平仍平衡。
3. 关键提问：**从 2x＝20 到 2x÷2＝20÷2 呢**？两边都平均分成 2 份，各拿掉 1 份，剩下的仍然平衡。
4. 举例验证：12＝12，两边都乘 4，48＝48；两边都除以 3，4＝4。
5. 讨论“0”：**两边都乘 0 行吗？都除以 0 呢**？
   - 都乘 0：0＝0，等式成立，可是 x 也跟着“消失”了，对解方程没有帮助；
   - 都除以 0：0 不能作除数，所以规律里要说“除以同一个不为 0 的数”。
6. 概括：**等式两边都乘同一个数（或除以同一个不为 0 的数），等式仍然成立**。和上节课的规律并排写在黑板上。

> **设计意图**：让学生自己去碰“0”。很多学生默认“乘、除都可以”，自己发现“除以 0 没有意义”“乘 0 虽然成立但没用”之后，“不为 0”这四个字才不会被死记硬背。

### 3. 解 4y＝2000（8 分钟）

1. 关键提问：**4 个 y 和 2000 克一样重，1 个 y 多重**？请学生画一画天平：左边 4 个 y，右边 2000 克。
2. 两边都平均分成 4 份，各留 1 份：4y÷4＝2000÷4，y＝500。
3. 检验：4×500＝2000，左右相等。
4. 追问：**为什么是除以 4，不是减 4**？4y 是 4×y，也就是 4 个 y；要变成 1 个 y，就要平均分成 4 份。
5. 回到导入：每盒种子重 500 克。

![三架天平从上到下：第 1 架左盘 4 个 y，右盘一个 2000，写 4y＝2000；第 2 架两边都平均分成 4 份，左边圈出 1 个 y，右边圈出 1 个 500，写 4y÷4＝2000÷4；第 3 架只剩 y 和 500，写 y＝500；下方检验 4×500＝2000](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-05/lesson-05/balance-4y.svg "两边都平均分成 4 份，各留 1 份，天平仍然平衡：这就是“两边都除以 4”")

### 4. 乘还是除（8 分钟）

1. **x÷3＝9**：关键提问：**x 被怎样了？要让 x 单独留下，两边该乘 3 还是除以 3**？
   - 画线段图：把 x 平均分成 3 份，1 份是 9；要求的是 3 份，所以两边都乘 3：x÷3×3＝9×3，x＝27。
   - 检验：27÷3＝9。
2. **7y＝28**：7 个 y 合起来是 28，求 1 份，两边都除以 7：7y÷7＝28÷7，y＝4。检验：7×4＝28。
3. 把两课的方法放在一起说：**加几就两边减几，减几就两边加几；乘几就两边除以几，除以几就两边乘几**。

![两段线段图对比：上面是 x÷3＝9，x 平均分成 3 份，每份 9，求 3 份，两边都乘 3，x÷3×3＝9×3，x＝27；下面是 7y＝28，28 平均分成 7 份，每份是 y，求 1 份，两边都除以 7，7y÷7＝28÷7，y＝4](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-05/lesson-05/times-or-divide.svg "先看 x 被怎样了：被除以 3，就用乘 3 抵消；被乘了 7，就用除以 7 抵消")

> **设计意图**：天平很难画出“x÷3”，这一步换成线段图。线段图把“知道 1 份求 3 份”“知道 7 份求 1 份”画出来，学生判断乘还是除时有了依据，不用死记“乘号变除号”。

### 5. 方程小医生（8 分钟）

1. 把第 70 页“下面的解法正确吗”的两个错例和第 71 页“森林医生”的两道题合在一起，四人小组当“方程小医生”：先找出错在哪一步，写一句诊断，再改正。

![方程小医生四张病例卡：x－19＝19 右边减了 19，应两边都加 19，x＝38；3x＝36 接着写＝36÷3 是连等，应写 3x÷3＝36÷3，x＝12；7x＝35＝35÷7＝5 也是连等，应写 7x÷7＝35÷7，x＝5；x－5＝8 两边都减 5 得 x＝3 是错的，应两边都加 5，x＝13](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-05/lesson-05/doctor.svg "四个错例分两类：两边做的事不一样，或把解题过程写成连等。答案对的 3x＝36 也要改，因为 3x 并不等于 36÷3")

2. 关键提问：**3x＝36 那位同学最后 x＝12 是对的，为什么还算错**？引导学生读一读“3x＝36÷3”：36÷3 是 12，3x 是 36，两边并不相等。课本里那句“等号两边要相等哦”就是这个意思。
3. 选做练一练第 3 题：6x＝156（x＝26），3x＝630（x＝210），x－47＝47（x＝94），59＋x＝120（x＝61），x÷52＝7（x＝364），x÷28＝0（x＝0）。追问 x÷28＝0：**什么数除以 28 得 0**？两边都乘 28，x＝0。
4. 第 4 题：游泳池长 30 米、面积 600 平方米，30x＝600，x＝20（米）。
5. 第 5、6 题留作课后：正方形花坛 4x＝24，x＝6；改成宽 4 米的长方形、周长不变，可以列 (x＋4)×2＝24 或 2x＋8＝24，x＝8，要用两步，适合学有余力的学生，也是下一课的伏笔；斜坡 2 米高需要 16 米、4 米高需要 32 米、x 米高需要 8x 米，空地长 24 米时 8x＝24，斜坡最高 3 米。

### 6. 课堂小结（2 分钟）

1. 说一说今天的规律，以及“不为 0”的原因。
2. 回到导入：每盒种子 500 克。
3. 留一个问题：第 66 页的“2 个热水瓶和 1 个 200 毫升的水杯，正好倒满 2000 毫升”，列成方程是 2z＋200＝2000，只用一条规律解不出来，下节课把两条规律连起来用。

## 五、趣味设计

4 个可以直接用的小设计：

1. **方程小医生**：四人小组拿一张“病历卡”（错误的解题过程），分工当医生：一人读题，一人找出错在哪一步，一人“开药方”写出正确过程，一人检验“复查”。课本里的“森林医生”就是现成的素材，第 2 轮换成学生自己出的错例。

![一个穿白大褂、挂着听诊器的孩子坐在书桌前，拿放大镜仔细看一张纸；旁边小树枝上站着一只戴护士帽的啄木鸟也凑过来看，桌上还放着一架平衡的天平和一块写字板](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-05/lesson-05/equation-doctor.webp "方程小医生：看病先“望”，一行一行检查等号两边还相不相等")

2. **对口令**：老师说“x 乘 4”，全班答“两边除以 4”；“x 除以 6”，答“两边乘 6”；“x 减 9”，答“两边加 9”。越来越快，最后加减、乘除混着来，练反应，也练“先看 x 被怎样了”。
3. **信封里有几根**：老师在 3 个一样的信封里各装同样多的小棒，告诉学生“一共 12 根”。学生列方程 3x＝12，两边都除以 3，x＝4，再拆开一个信封验证。换一个装了 6 根小棒的信封，说“把这个信封里的小棒平均分成 3 份，每份 2 根”，学生列 x÷3＝2，两边都乘 3，x＝6，再拆开数一数。实物让“乘还是除”看得见。
4. **种子盒故事线**：一节课跟着第 66 页的三幅图走：樱桃（上节课已经解决）→ 4 盒种子（本课解决，每盒 500 克）→ 热水瓶（留到下节课）。学生会发现，越往后，需要的规律越多。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把“乘还是除”变成看得见的东西、让每个学生拿到适合自己的练习**。这节课的错误很集中（方向反、连等、两边做的不一样），AI 最适合帮老师批量准备“错例”、快速归类学生的错误。

**看学生能不能把“乘”和“除”配对。** 课前发 3 道小题：

1. 5x＝45，x 是多少？写出你是怎么想的。
2. x÷4＝6，x 是多少？写出你是怎么想的。
3. 12＝12，两边都乘 0 还相等吗？两边都除以 0 呢？

### 课中：先判断，再分一分

**先让学生说“乘还是除”，再看天平和线段图验证。**

- **可以平均分的天平**：课件里 4 个 y 和 2000 克的天平，学生先说“两边各分成几份、各留几份”，再点“平均分”，看两边同时分开，各留 1 份，天平保持平衡。
- **乘还是除即时作答**：出示 x÷3＝9、7y＝28、x÷52＝7、6x＝156，每题选“两边都乘”还是“两边都除以”，看选项分布，只讲错得最集中的一题。
- **AI 准备病例卡**：“方程小医生”需要很多“有病”的解题过程，自己编既费时又容易单调。课前请 AI 按指定错因生成错例，老师逐条核对后打印成卡片。

可以直接复制的提示词：

```

每张卡给出一个方程和一个“有错误”的解题过程，错误类型这样分配：
- 2 张：把解题过程写成连等，如 3x＝36＝36÷3＝12；
- 2 张：方向反了，如 x÷3＝9 写成 x÷3÷3＝9÷3；
- 2 张：只在等号一边乘或除；
- 2 张：加减方程和乘除方程混用，如 x－19＝19 写成 x－19＋19＝19－19。
要求：方程只含 ax＝b、x÷a＝b、x＋a＝b、x－a＝b 四种，数在 1000 以内，解是整数；
每张卡另附“诊断”（错在哪一步，一句话）和正确的解题过程，正确过程要写“解：”并检验。
```

### 课后：分层练习

**同样是解方程，按错因换练法。** 方向反的学生，多做“先说 x 被怎样了，再选乘还是除”的判断题；写连等的学生，练“读一读每一行等号两边是否相等”；已经掌握的学生，挑战“不求 x，直接说出 10x 等于多少”。

可以直接复制的提示词：

```
请为北师大版四年级下册《解方程（二）》生成课后练习，分三层：
- 基础：6 道 ax＝b、x÷a＝b 型方程，要求写“解：”、一步一行并检验；
- 提升：3 道列方程解决问题，情境用长方形面积、正方形周长、单价×数量＝总价，
  先写等量关系再列方程；
- 挑战：2 道题，例如“x÷28＝0 的解是多少”
  “如果 5x＝60，不求 x，说出 10x 等于多少并说明理由”。
要求：只用等式两边都加减、都乘除同一个数（除数不为 0）的性质；
不出现两步方程、负数和分数；数据符合生活实际；每题附答案和一句话讲解。
```

### 教研：AI 听课伙伴

**看“0”和“乘还是除”两个环节有没有真正突破。** 课后把学生在“讨论 0”环节的发言、即时作答的选项分布和几张学生作业照片交给 AI，请它分析：多少学生能说出“0 不能作除数”；“乘还是除”的错误在线段图出现后是否明显减少。再请它起草教学反思初稿，老师在初稿上修改。

### 使用边界

**用 AI 要守住三条边界。**

1. **教材细节以课本为准**：例题、两个错例和“森林医生”的题目以第 70～71 页为准。
2. **演示不替代思考**：先判断乘还是除，再点“平均分”；先让学生找错，再给诊断。
3. **AI 出的错例要逐条核对**：AI 生成“错例”时，偶尔会把正确过程也写错，或者“诊断”说不到点上，老师要逐条检查，再发给学生。

这一课最适合做成互动课件的是三处：一架可以“平均分成几份”的天平，学生先说分几份、留几份，再点击验证；一组“乘还是除”的全班即时作答题，暴露方向错误；一组可以翻面的“病例卡”，正面是错误过程，学生写完诊断再翻出正确过程。设计时要守住“让学生先想、再动手验证”的顺序，平均分和翻卡都放在学生判断之后。

## 七、板书设计

板书分左右两块，用文字列出即可：

**左边：两条规律**

- 等式两边都加上（或减去）同一个数，等式仍然成立。（上节课）
- 等式两边都乘同一个数（或除以同一个不为 0 的数），等式仍然成立。（本节课）

**右边：解方程**

- 4y＝2000。解：4y÷4＝2000÷4，y＝500。检验：4×500＝2000。
- x÷3＝9。解：x÷3×3＝9×3，x＝27。
- 7y＝28。解：7y÷7＝28÷7，y＝4。
- 方法：乘几就两边除以几，除以几就两边乘几；一步一行，不写连等。

## 八、分层作业

括号里是答案要点。

**基础**

1. 解方程并检验：8x＝96，x÷6＝15，25x＝100。（x＝12；x＝90；x＝4）
2. 一块长方形菜地面积 480 平方米，长 24 米，宽多少米？列方程解答。（24x＝480，x＝20）

**提升**

3. 判断对错并改正：5x＝45＝45÷5＝9。（错，不能连等；应写 5x÷5＝45÷5，x＝9）
4. 一辆汽车 3 小时行了 195 千米，平均每小时行多少千米？列方程解答。（3x＝195，x＝65）
5. 解方程：x÷0.4＝2.5。（两边都乘 0.4，x＝1，用到第三单元的小数乘法）

**挑战**

6. 如果 5x＝60，不求 x，你能说出 10x 等于多少吗？说说理由。（120，两边都乘 2）
7. 一个正方形花坛周长 24 米，改成宽 4 米的长方形，周长不变，长是多少米？列方程解答。（(x＋4)×2＝24，两边都除以 2 得 x＋4＝12，x＝8；也可以列 2x＋8＝24）

## 九、易错点与应对

1. **方向搞反**：x÷3＝9 写成 x÷3÷3＝9÷3。原因是看到“÷3”就跟着除。应对：先问“x 被怎样了”，再画线段图看“1 份是 9，求 3 份”。
2. **写成连等**：3x＝36＝36÷3＝12、7x＝35＝35÷7＝5。原因是把方程当计算题。应对：请学生逐个读出每个等号两边的数，36 等于 12 吗？坚持一步一行。
3. **两边做的不一样**：x－19＋19＝19－19，左边加、右边减。原因是只顾让左边“抵消”，右边照抄了原来的符号。应对：用“两边同时”的口令；检验时 0－19 不够减，错误立刻暴露。
4. **忽视“不为 0”**：认为两边都除以 0 也可以。应对：回到除法的意义，0 不能作除数；两边都乘 0 虽然成立，但 x 没了，解不出方程。

这四类错误在上面“方程小医生”的图里都有对应的例子，课上可以直接用。

## 十、反思与说课

- **反思重点**：学生判断“乘还是除”时，是先说出“x 被怎样了”，还是凭感觉？辨析错例时，能不能说出“3x 和 36÷3 不相等”，而不只是说“格式不对”？如果只会说“格式不对”，说明连等的问题还没有真正想通。
- **说课可以突出**：本课和上一课结构对应，沿着“观察天平 → 发现规律 → 用规律解方程 → 辨析错误”展开；用线段图补充天平难以表现的“x÷3”，用“方程小医生”把课本的错例变成活动，让学生在找错中理解“等号两边要相等”，为下一课解两步方程做好准备。

## 常见问题

**《解方程（二）》这节课怎么导入比较好？**
从第 66 页的“4 盒种子一共 2000 克”导入：先请学生用上节课“两边都减”的办法试着解 4y＝2000，发现减去几都不能让 y 单独留下，自然产生“需要新规律”的想法，再去观察天平。

**为什么是“除以同一个不为 0 的数”，乘的时候却没说“不为 0”？**
因为 0 不能作除数，两边都除以 0 没有意义。两边都乘 0 时等式其实成立（0＝0），所以课本没有限制；但这样 x 也跟着没了，对解方程没有帮助，解方程时不会去乘 0。这一点让学生自己举例讨论，比直接告诉他们记得更牢。

**x÷3＝9 学生总是两边除以 3，怎么突破？**
先问“x 被怎样了”：x 被除以了 3，要回到 x，就得乘 3 抵消。再画线段图：x 平均分成 3 份，1 份是 9，求 3 份当然用乘。最后检验 27÷3＝9。学生写成 x÷3÷3 时，请他想想左边还是不是 x。

**教材为什么专门安排“下面的解法正确吗”和“森林医生”？**
连等和“两边做的不一样”是这个阶段最常见、也最顽固的错误。让学生自己当医生去找错，比老师反复强调格式更有效；而且错例里混进了加减方程 x－19＝19，逼着学生把两课的方法放在一起比较，而不是学一种、练一种。

**AI 在这节课里最该用在哪？**
最该用在准备和归类错误上：课前用前测看学生能不能把乘和除配对、怎么看待“0”；课中请 AI 批量生成指定错因的病例卡，老师核对后用于“方程小医生”；课后按错因生成分层练习。AI 出的错例和答案一定要逐条核对。
