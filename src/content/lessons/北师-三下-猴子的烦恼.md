> **一句话备课结论**：这节课不是教“三种带 0 的特殊除法”，而是让学生明白一件事：**每一位只有两种情况——够分，商几就写几；不够分，就商 0**。被除数中间有 0 不难，真正的难点是 612 ÷ 3 这样被除数里没有 0、商里却有 0 的题：十位上的 1 个十不够分，商 0 占位，很多学生会漏写，算成 24。

## 一、教材解读

### 前后联系

- **已经学过**：《分松果》会用竖式记录每一位都够分的除法；《家庭阅读》会把某一位剩下的换成下一位的单位再合起来分，知道竖式从高位算起。
- **本课要学**：本单元第 3 课，一般安排 1 课时。先由“没有桃子可分”认识 0 除以任何不是 0 的数都得 0，再学被除数中间、末尾有 0，以及商中间、末尾有 0 的三位数除以一位数。
- **后面要用**：下一课《集邮》会遇到“最高位不够商 1”和商末尾的 0；《算得对吗》要检查除法算得对不对，漏写 0 是最常见的错误之一。

### 新旧教材变化

- **旧版**：《猴子的烦恼》在三年级下册第一单元“除法”中，前面有《分桃子》《分橘子》《商是几位数》；“商中间有 0”“商末尾有 0”常被当成几种特殊类型分别讲。
- **新版**：放在第四单元“整数除法（一）”第 3 课。公开的新教材解读特别指出：新版把 0 和其他数字同等对待，无论被除数每一位是几，平均分时只有“够分”和“不够分”两种情况，够分时商几就写几，不够分时就商 0，由此概括出三位数除以一位数竖式的一般方法，**弱化竖式的“类别”，凸显算法的一致性**。

对备课的影响：**不要再按“被除数中间有 0”“商中间有 0”“末尾有 0”分类型讲、分类型练**。每一道题都问同一个问题：“这一位够不够分？”学生只要会问这一句，各种带 0 的题都能自己解决。

### 编排意图

主线是：**0 ÷ 3 = 0 → 每一位都问“够不够分” → 不够分就商 0 占位 → 竖式可以简写**。下图是 306 ÷ 3 的完整写法和简便写法，以及商中间有 0 的 612 ÷ 3。

![306 ÷ 3 的完整竖式逐步标注：3 个百 ÷ 3 每份 1 个百；0 个十没有可分的，不够分十位商 0，0 × 3 = 0；还有 6 个一，6 个一 ÷ 3 每份 2 个一，正好分完。下面两个小竖式：306 ÷ 3 的简便写法，商 0 后直接落下 6；612 ÷ 3，十位 1 不够分 3 份，商 0，商是 204](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-04/lesson-03/zero-steps.svg "306 ÷ 3 和 612 ÷ 3 道理一样：十位不够分，商 0 占位")

306 ÷ 3 的 0 是“被除数这一位本来就是 0”，612 ÷ 3 的 0 是“这一位有 1 个十，但不够分成 3 份”。两种情况用的是同一个判断，这正是新教材想让学生看到的。

## 二、学情分析

**已有基础**：会笔算两、三位数除以一位数，知道“剩下的换成下一位再合起来分”；知道 0 个物体平均分还是 0 个。

**可能的困难**：

1. **漏写商中间的 0**：612 ÷ 3 算成 24，十位上的 4 其实应该写在个位上。
2. **漏写商末尾的 0**：840 ÷ 6 算成 14，个位的 0 没有写。
3. **以为 0 ÷ 3 = 3**：把“0 除以一个数”和“一个数除以 1”混在一起。
4. **完整写法太繁、简便写法看不懂**：不知道为什么简写时可以直接把 6 落下来。
5. **不会用估算检查**：算出 24 也不觉得奇怪，因为没想到 612 ÷ 3 至少是 200。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 结合“猴子分桃”的情境，理解 0 除以任何不是 0 的数都得 0。（数感）
2. 经历用“够不够分”判断每一位商几的过程，掌握被除数中间、末尾有 0 和商中间、末尾有 0 的三位数除以一位数的笔算，能正确写出商中间、末尾的 0。（运算能力）
3. 能用估算判断商的位数和大致大小，发现并改正漏写 0 的错误，说清 0 在商里的占位作用。（推理意识）

**教学重点**：掌握商中间、末尾有 0 的除法竖式计算方法。

**教学难点**：理解某一位不够分时商 0 占位的道理，特别是被除数里没有 0、商里却有 0 的情况。

## 四、教学过程

### 1. 情境导入（5 分钟）

**一个桃子都没有，怎么分？** 出示三只小猴围着一个空篮子发愁的画面。

![三只黏土小猴坐在一个空篮子旁边，一只挠头，一只往篮子里看，一只摊开双手，身后的桃树上没有桃子](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-04/lesson-03/monkeys.webp "导入画面：篮子里一个桃子也没有，3 只猴子每只分几个？")

- 关键提问：**篮子里 0 个桃子，平均分给 3 只猴子，每只分几个？怎么列式？**——0 ÷ 3 = 0。
- 再问：0 个桃子分给 5 只、分给 8 只呢？学生发现：**0 除以任何不是 0 的数都得 0**。
- 板书时写完整这句话。“为什么要说不是 0 的数”可以留一个悬念，不在本课展开。

> **设计意图**：从“没东西可分”的生活经验出发，学生很容易接受“每份是 0”。这个 0 后面会在竖式里反复出现：某一位上是 0，或者不够分，每份都是 0。

### 2. 被除数中间有 0（10 分钟）

1. 出示问题：**猴子们摘了 306 个桃子，平均分给 3 只猴子，每只分多少个？** 先估：300 ÷ 3 = 100，每只 100 多个。
2. 学生在计数器上分：3 个百，每只 1 个百；十位 0 个十，**没有可分的，每只 0 个十**；6 个一，每只 2 个一。合起来是 102。
3. 写成竖式，先写完整写法：十位上 0 ÷ 3 商 0，0 × 3 = 0，再落下 6（见“编排意图”中的图）。
4. 关键提问：**十位的商 0 能不能不写？**——不能。不写就成了 12，和“100 多”对不上。0 在这里表示“十位上每只分到 0 个十”，占着十位的位置。
5. 引出简便写法：十位商 0 后，乘出来、减下去都是 0，可以省略这两行，直接把 6 落下来。**省的是竖式里的 0，不是商里的 0。**

### 3. 商中间有 0（10 分钟）

1. 出示 612 ÷ 3，先估：600 ÷ 3 = 200，商一定是 200 多。
2. 同桌在计数器上分：6 个百，每份 2 个百；十位只有 1 个十，**不够分成 3 份**。关键提问：**不够分怎么办？**
3. 学生会想到《家庭阅读》里的办法：1 个十换成 10 个一，和 2 个一合成 12 个一，每份 4 个一。
4. 追问：**十位上每份分到了几个十？**——0 个。所以十位商 0，商是 204。
5. 和 306 ÷ 3 比一比：**一个是被除数十位是 0，一个是被除数十位是 1，为什么商的十位都是 0？**——都是因为十位不够分。

> **设计意图**：这是本课真正的难点。用同一个问题“够不够分”把两道题连起来，学生就不需要记两种类型，而是用同一个方法判断。估算“200 多”则是一道保险：算出 24，学生自己就能发现不对。

### 4. 末尾有 0（5 分钟）

1. 出示 840 ÷ 6。百位：8 个百每份 1 个百，剩 2 个百；2 个百换成 20 个十，和 4 个十合成 24 个十，每份 4 个十；个位 0 个一，每份 0 个一。
2. 关键提问：**个位上的商 0 能省吗？**——不能。省了就成 14，和估算的“100 多”差得太远。
3. 小结：个位上是 0，或者个位不够分，都要在个位商 0。

### 5. 当小医生（7 分钟）

全班先独立判断，再说理由。重点听学生是不是用“够不够分”或“估一估”来说理：

![当小医生：第 1 题 618 ÷ 3 的商写成 2、空、6；第 2 题 520 ÷ 5 = 104；第 3 题 850 ÷ 5 的商写成 17；第 4 题写着 0 ÷ 8 = 8](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-04/lesson-03/variants.svg "答案：① 错，十位 1 个十不够分 3 份要商 0，正确是 206；② 对；③ 错，个位 0 要商 0，正确是 170；④ 错，0 ÷ 8 = 0")

### 6. 小结（3 分钟）

1. 回到小猴的烦恼：没有桃子，每只分 0 个；某一位不够分，那一位就商 0。
2. 请学生用一句话总结：**每一位只问“够不够分”：够分，商几就写几；不够分，就商 0。**

## 五、趣味设计

1. **够不够手势**：老师报一位上的数和除数（如“1 个十，分 3 份”），够分就竖大拇指，不够分就用手比一个圆圈表示 0。一分钟内快速过十几组，形成条件反射。
2. **0 的自我介绍**：请学生扮演竖式里的 0，用一句话说“我为什么不能被擦掉”，比如“我是十位上的 0，我表示每只猴子分到 0 个十，我不在，2 就跑到十位去了”。
3. **估算侦探**：每道题先估“大约几百”，算完再对一对。商比估算少了一位，就是“0 被偷走了”，全班一起找“小偷”。
4. **猴子的烦恼故事线**：导入是“没有桃子”，中间是“306 个桃子”“612 个桃子”，结尾请学生给小猴写一张“分桃子提醒卡”，把今天的方法写给小猴看。

## 六、AI 赋能

AI 赋能不是把 PPT 做得更炫，而是落在老师最费时间、又最难做好的几件事上：**找出谁会漏写 0、把“够不够分”变成看得见的判断、让每个学生练到自己最容易漏 0 的那类题**。

### 课前：学情前测

**用三道题看清漏 0 的人在哪儿。** 课前发：① 0 ÷ 4 = ？② 306 ÷ 3；③ 612 ÷ 3。第 3 题最关键：被除数里没有 0，商里却有 0，漏写的学生会算成 24。

可以直接复制的提示词：

```
我是小学三年级数学老师，明天上北师大版三年级下册第四单元“整数除法（一）”第 3 课《猴子的烦恼》。
下面是全班课前小测的答案，每行一名学生，共 3 题（0 ÷ 4、306 ÷ 3、612 ÷ 3）：
（粘贴答案）
请帮我：
1. 每题按“正确 / 漏写商中间的 0 / 其他错误”分类，给出人数和典型错误；
2. 找出“306 ÷ 3 对、612 ÷ 3 错”的学生，说明他们可能把“商 0”理解成了“被除数有 0 才商 0”；
3. 建议课堂上 612 ÷ 3 这道题用什么追问来暴露这个误解。
```

### 课中：先判断，再验证

**每一位都先让学生判断“够不够分”，再看课件。** 互动课件在这节课最有用的地方：

- **一位一位亮起来**：课件把被除数的百位、十位、个位依次高亮，学生先举手势判断“够分 / 不够分”，再点击，课件把桃子分到猴子手里；不够分的那一位，猴子手里空空的，竖式上同时出现一个 0。
- **擦掉 0 试试看**：学生把商里的 0 拖走，课件马上把后面的数字挤到前面，显示“204 变成 24”，再和估算的“200 多”对比，学生自己明白 0 为什么不能省。
- **完整写法和简便写法对照**：课件同时展示两种写法，点击“简写”，乘出来、减下去的 0 两行渐渐消失，商里的 0 不动。学生看清“省的是哪两行”。
- **全班即时作答**：“小医生”环节全班同时提交，老师只讲正确率最低的那一题。

### 课后：分层练习

**专门练最容易漏 0 的那类题。** 按错因分层：

```
请为北师大版三年级下册《猴子的烦恼》生成课后练习，分三层：
- 基础：6 道三位数除以一位数，商中间或末尾有 0，其中至少 3 道被除数里没有 0
  （如 618 ÷ 3、824 ÷ 4、540 ÷ 5），要求先估一估商是几百多，再写竖式；
- 提升：4 道改错题，错误类型是“漏写商中间的 0”和“漏写商末尾的 0”，要求写出错在哪一位、为什么；
- 挑战：2 道，如“□05 ÷ 5 的商中间有 0，□ 里可以填几”。
要求：不出现最高位不够商 1 的题，不超出三年级下册范围；每题附答案和一句话讲解。
```

（挑战题参考：□05 ÷ 5 只有 □ 填 5 时商是 101，中间有 0；其他数都不行。请老师核对 AI 的答案。）

### 教研：AI 听课伙伴

**看学生是“记类型”还是“问够不够分”。** 课后把实录交给 AI：

```

2. 612 ÷ 3 环节有没有学生暴露“被除数没有 0 就不会商 0”的想法，老师是怎么回应的；
```

### 使用边界

1. **教材细节以课本为准**：本文例题是常见教学设计中的数据，课本上的情境数字、练一练题号、页码请对照教材核实。
2. **演示不替代思考**：每一位都先让学生判断“够不够分”，再用课件验证；不要一上来就播放“商 0”的动画。
3. **AI 出的题要过一遍**：本课不处理最高位不够商 1 的情况（那是《集邮》的内容），也不要展开“为什么 0 不能作除数”，AI 出的题和讲解里如果有，要删掉或改写。

十一课件的互动课件就是按这套思路设计的：逐位高亮、先判断再分桃的演示，可以拖走 0 看后果的竖式，完整写法和简便写法的对照，都围绕“先判断够不够分、再验证”来做。

## 八、分层作业

括号里是答案要点。

**基础**

1. 口算：0 ÷ 7，0 ÷ 1，0 ÷ 9。（都是 0）
2. 用竖式计算：408 ÷ 4，618 ÷ 3，850 ÷ 5。（102；206；170）

**提升**

3. 判断并改正：612 ÷ 3 = 24。（✗，十位 1 个十不够分 3 份，要商 0，正确是 204）
4. 先估一估商是几百多，再计算：540 ÷ 5。（100 多；108）

**挑战**

5. □05 ÷ 5 的商中间有 0，□ 里可以填几？（只能填 5：505 ÷ 5 = 101）
6. 一个三位数除以 3，商是 102，余数是 2，这个三位数是多少？（3 × 102 + 2 = 308）

## 九、易错点与应对

1. **漏写商中间的 0**：612 ÷ 3 算成 24。应对：每一位都问“够不够分”；算完用估算检查“应该是 200 多”。
2. **漏写商末尾的 0**：840 ÷ 6 算成 14。应对：强调“个位上是 0 或个位不够分，个位也要商 0”；简便写法只省竖式里的两行，不省商里的 0。
3. **0 ÷ 3 = 3**：混淆“0 除以一个数”和“一个数除以 1”。应对：回到“没有桃子可分”的情境，问“每只猴子手里有几个”。

## 十、反思与说课

- **反思重点**：学生说理时，是说“因为十位不够分”，还是说“因为被除数有 0”？后者说明学生在记类型，遇到 612 ÷ 3 这类题还会出错。
- **说课可以突出**：本课以“够不够分”这一个问题统一了被除数中间、末尾有 0 和商中间、末尾有 0 的各种情况，用估算作为检查手段，体现了新教材“弱化竖式类别、凸显算法一致性”的编排思路。

## 常见问题

**《猴子的烦恼》这节课怎么导入比较好？**
用“篮子里一个桃子也没有，3 只猴子怎么分”导入。学生从生活经验出发，很自然地得出 0 ÷ 3 = 0，再推广到“0 除以任何不是 0 的数都得 0”，后面竖式里出现 0 时也有了依据。

**怎样让学生不漏写商中间的 0？**
两个办法一起用：一是每一位都先问“够不够分”，不够分就商 0；二是先估再算，612 ÷ 3 先估出“200 多”，算出 24 学生自己就会发现不对。

**被除数中间有 0 和商中间有 0 有什么不一样？**
306 ÷ 3 是被除数十位本来就是 0，没有可分的，商 0；612 ÷ 3 是被除数十位有 1 个十，但不够分成 3 份，也商 0。两种情况的判断方法完全一样，都是“不够分就商 0”。

**新教材为什么不再分类型讲带 0 的除法？**
新版教材把 0 和其他数字同等对待，强调平均分时每一位只有“够分”和“不够分”两种情况，以此概括三位数除以一位数的一般方法。这样学生掌握的是一个通用的判断，而不是几种要分别记住的类型。

**AI 在这节课里最该用在哪？**
最该用在三件事上：课前用 306 ÷ 3 和 612 ÷ 3 两道题找出“只会被除数有 0 才商 0”的学生；课中让学生拖走商里的 0 看看会发生什么；课后专门针对漏写中间 0、末尾 0 分层出题。
