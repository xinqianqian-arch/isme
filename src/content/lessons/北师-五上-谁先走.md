> **一句话备课结论**：这节课只讲一个判断标准：**双方获胜的可能性相同，游戏才公平**。能把结果一一列出来时，就数一数双方各有几种可能，掷骰子“大于 3”有 3 种，“小于 3”只有 2 种；列不出来时，比如抛瓶盖，就要做试验、看全班的数据。最大的误区是“只有两种结果，就一定公平”。

## 一、教材解读

### 前后联系

- **已经学过**：上一课《不确定性》知道结果不能事先确定，可能性有大有小，并且和所占份数有关。
- **本课要学**：判断游戏规则是否公平，修改不公平的规则，设计公平的规则；知道有些情况不能只靠想，要用试验数据来判断。
- **后面要用**：下一课《摸球游戏》，用摸球数据推测盒子里哪种球多，正好接着“用数据说话”往下走；初中学概率时，还会用列表、画树状图研究游戏的公平性。

### 新旧教材变化

旧版的《谁先走》在五年级上册第七单元“可能性”。新版把旧版四上的可能性单元整体移走，和五上合成第八单元，《谁先走》排在《不确定性》之后、《摸球游戏》之前，成为单元中间的一课。

教材用强强和小华下象棋引出问题，第 104～106 页依次是：判断两种方法是否公平、修改笑笑的方法、再设计一个公平方案、“试一试”抛瓶盖、四道练一练。对备课的影响是：上一课刚学过“可能性有大有小”，这一课可以直接用它来判断公平，不必再从头建立可能性的概念；内容多，建议用 2 课时，第 2 课时专门做抛瓶盖试验。

### 编排意图

教材的线索是“会判断 → 会修改 → 会设计 → 用数据检验”：

1. **判断**：抛硬币，“正面朝上与反面朝上的可能性相同”；掷骰子，“点数大于 3 有 3 种可能，点数小于 3 有 2 种可能”。
2. **修改**：智慧老人请学生修改笑笑的方法，使它对双方都公平。
3. **设计**：把 2 个红球、2 个白球放进袋中摸，或者抽签决定。
4. **检验**：瓶盖扔出后，盖面朝上淘气去，盖面朝下笑笑去。笑笑说“两种可能，应该是公平的吧”，教材却让大家做 20 次、汇总全班数据，再提示“想一想，盖子哪一面重一些”。

前三步靠列举和推理，第四步靠试验数据。抛瓶盖是这一课的点睛之笔：它告诉学生，“有两种结果”和“两种结果的可能性相同”是两回事。

## 二、学情分析

**已有基础**：知道结果不确定、可能性有大有小；玩过抛硬币、石头剪刀布、抽签，对“公平”有朴素的感觉。

**可能的困难**：

1. **只数结果的种类**：认为抛瓶盖只有两种结果，所以公平。
2. **漏掉没人赢的结果**：说掷骰子“大于 3、小于 3，一人一半”，没发现 3 不属于任何一方。
3. **修改后仍不公平**：提出“掷到 3 就重掷”，没意识到剩下的还是 3 种对 2 种。
4. **把其他颜色也算进去**：练一练第 3 题，看到 1 号口袋有红球、蓝球，就说不公平。
5. **用少量数据下结论**：自己组抛了 20 次正好 10 对 10，就说“公平”。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 结合“谁先走”等情境，能列出简单游戏的所有可能结果，判断规则是否公平，并说明理由。（推理意识）
2. 能修改不公平的规则，设计对双方都公平的游戏规则。（应用意识）
3. 经历抛瓶盖试验和汇总全班数据的过程，体会“结果有两种”不等于“可能性相同”，感受数据的作用。（数据意识）
4. 在游戏中体会公平的意义，愿意用数学的道理说服别人。

**教学重点**：判断游戏规则是否公平，设计公平的游戏规则。

**教学难点**：理解公平的含义是“双方获胜的可能性相同”；不能列举时，会用试验数据来判断。

## 四、教学过程

### 1. 情境导入（4 分钟）

**下棋之前，谁先走？** 出示第 104 页强强和小华下象棋的情境。

![教室一角，穿浅蓝 T 恤和橙色 T 恤的两个男孩隔着一盘象棋对坐，摊着手不知道谁先走；桌上放着一枚硬币和一个骰子，后面一个穿粉裙子的女孩举着一个小布袋，好像有了新主意](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-08/lesson-02/chess.webp "导入画面：硬币、骰子、布袋都能用来决定谁先走，哪种办法对双方公平？")

1. 关键提问：**你能替他们想个办法，决定谁先走吗**？学生会说抛硬币、石头剪刀布、抽签、掷骰子。
2. 出示教材里的两种方法：抛硬币，正面朝上强强先走，反面朝上小华先走；笑笑的方法，掷骰子，点数大于 3 强强先走，小于 3 小华先走。
3. 请学生先举手表态：两种方法都公平吗？把票数写在黑板一角。

### 2. 判断公平（12 分钟）

1. 关键提问：**什么样的方法才算公平**？引导学生说出：两个人先走的可能性一样大。
2. 抛硬币：只有正面、反面两种结果，可能性相同，所以公平。
3. 掷骰子：请学生把所有可能的点数写出来，再分给两个人。

![笑笑的方法：骰子点数 1、2 小于 3，小华先走，2 种；点数 3 两人都不算，1 种；点数 4、5、6 大于 3，强强先走，3 种，所以不公平；修改后，大于 3 的 4、5、6 和不大于 3 的 1、2、3 各 3 种，或者单数 1、3、5 和双数 2、4、6 各 3 种，游戏公平](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-08/lesson-02/dice.svg "把六个点数分给两个人：原方法是 3 种对 2 种，还有一个 3 谁也不算；改过以后两边都是 3 种")

4. 学生发现：大于 3 有 4、5、6 三种，小于 3 只有 1、2 两种，**3 谁也不算**。强强先走的可能性大，不公平。
5. 回到导入时的票数：投“公平”的同学，现在怎么想？

> **设计意图**：学生凭感觉会说“大于 3、小于 3，一人一半”。让他们动手把六个点数逐个分到两边，漏掉的 3 和多出来的一种就藏不住了。“列出所有结果，再数一数”，是本课判断公平的基本方法。

### 3. 修改方法（8 分钟）

1. 出示智慧老人的话：请你修改笑笑的方法，使它对双方都公平。同桌讨论，至少想出一种。
2. 学生常见的改法：点数大于 3 强强先走，不大于 3 小华先走；单数强强先走，双数小华先走；1、2、3 强强先走，4、5、6 小华先走。
3. 出示一个“陷阱”改法：掷到 3 就重新掷。关键提问：**这样改公平了吗**？学生会发现：重掷以后，能决定胜负的还是 4、5、6 和 1、2，仍然是 3 种对 2 种，不公平。
4. 小结：改规则时，要让双方的可能结果一样多。

### 4. 设计方案（8 分钟）

1. 读第 105 页：把 2 个红球、2 个白球放入袋中摇匀，摸到红球强强先走，摸到白球小华先走；也可以抽签决定。
2. 关键提问：**为什么这两个方案是公平的**？学生说出：红球、白球一样多；两张签一张“先”、一张“后”。
3. 小组再设计一个方案，写清用什么、怎么定输赢，并说出“为什么公平”。可以用转盘、扑克牌、石头剪刀布。
4. 选两组展示，其他组当评委，评一评公不公平。

### 5. 练一练（6 分钟）

1. **第 1 题**：甲转盘一半蓝一半黄；乙转盘分成 4 份，两份蓝、两份黄。学生说出规则：指针指向蓝色一方赢，指向黄色另一方赢，两个转盘都公平。追问：乙转盘有 4 格，也公平吗？——蓝色、黄色各占一半。
2. **第 3 题**：奇思和妙想摸球，白球妙想得分，黄球奇思得分。

![练一练第 3 题四个口袋：1 号 3 个白球、3 个黄球、1 个红球、2 个蓝球；2 号 3 个白球、2 个黄球；3 号 1 个白球、1 个黄球、3 个红球；4 号 2 个白球、2 个蓝球、1 个黄球](https://media.11aike.com/textbooks/bsd/grade-5/volume-1/unit-08/lesson-02/bags.svg "答案：1 号、3 号口袋公平，白球和黄球一样多；红球、蓝球谁也不得分，不影响公平。2 号、4 号白球多，对妙想有利")

### 6. 小结（2 分钟）

1. 请学生说一句话：**双方获胜的可能性相同，游戏才公平**。
2. 留一个问题：淘气想用抛瓶盖决定谁去看比赛，只有两种结果，公平吗？下节课动手试一试。

### 第 2 课时（40 分钟）

**第 2 课时做抛瓶盖试验，体会“两种结果不等于可能性相同”。**

1. **复习热身（5 分钟）**：快速判断两条规则：掷骰子，1 点甲赢，2～6 点乙赢；抽扑克 1～6，单数甲赢、双数乙赢。（第一条不公平，第二条公平）
2. **提出问题（5 分钟）**：读第 105 页“试一试”：智慧老人只有两张票，淘气说盖面朝上他去，盖面朝下笑笑去。笑笑说“两种可能，应该是公平的吧”。请学生先猜，并说理由。
3. **同伴试验（12 分钟）**：同桌合作抛 20 次，记录盖面朝上、盖面朝下的次数。提醒：在桌面上低处抛，注意安全，不要往人身上扔。
4. **汇总全班（10 分钟）**：各组报数，老师在表格里一组一组累加。学生会看到：各组结果不一样，有的组差不多，有的组差很多；全班合起来，两种结果的次数往往相差比较明显。关键提问：**从汇总的数据看，这个游戏对双方公平吗**？再结合教材提示“盖子哪一面重一些”，说出：瓶盖两面不一样，两种结果的可能性不一定相同。
5. **练一练第 2、4 题（6 分钟）**：抛金属瓶盖的游戏先猜再试；用 1～6 的扑克牌设计公平规则（单数、双数；大于 3、不大于 3 等）。
6. **小结（2 分钟）**：能列出结果的，数一数；列不出来的，做试验，看全班的数据。

## 五、趣味设计

4 个可以直接用的小设计：

1. **规则评审团**：每组写一条“谁先走”的规则贴到黑板上，其他组举“公平 / 不公平”牌，被判不公平的组要当场修改。
2. **陷阱改法大辩论**：把“掷到 3 就重掷”写在黑板中间，正方说公平、反方说不公平，用“列出所有结果”来辩。
3. **瓶盖大数据**：在黑板上画一条累计柱，每组报完就加上去，全班看着两种结果的差距越来越清楚。
4. **石头剪刀布公平吗**：两人各出一种，列出所有 9 种情况，数出各赢 3 种、平 3 种，学生会很有成就感。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象的规律变成可以操作的东西、让每个学生拿到适合自己的练习**。这节课有两类判断：能列举的靠推理，不能列举的靠数据。AI 和互动课件在两边各有用处，但都不能代替学生自己去数、去抛。

### 课前：学情前测

**查清学生判断公平时看的是什么。** 课前发 3 道题：① 抛瓶盖，盖面朝上甲赢、朝下乙赢，公平吗？② 掷骰子，大于 3 甲赢、小于 3 乙赢，公平吗？③ 用一个骰子设计一个公平规则。

可以直接复制的提示词：

```
我是小学五年级数学老师，明天要上北师大版五年级上册第八单元《谁先走》。
下面是学生课前小测的答案，每行一名学生（已去掉姓名）：
（粘贴答案）
题目：①抛瓶盖，盖面朝上甲赢、朝下乙赢，公平吗？②掷骰子，点数大于3甲赢、
小于3乙赢，公平吗？③用一个骰子设计一个公平的规则。
请帮我：
1. 统计第①题认为“两种结果就公平”的人数；
2. 统计第②题漏掉点数3、认为“一人一半”的人数；
3. 第③题把学生的规则分成公平、不公平两类，不公平的写出原因；
4. 建议课上先讨论哪道题。只用“可能性相同、大、小”描述，不用分数。
```

### 课中：先判断，再试验

**能列举的，先让学生分一分；列不出的，让真实数据说话。**

- **掷骰子模拟**：学生先在纸上把 1～6 分给强强和小华，再让课件掷 600 次，统计两人各先走多少次。接着试“掷到 3 就重掷”，学生会看到强强仍然明显多，“陷阱改法”不攻自破。
- **瓶盖不模拟**：瓶盖哪一面更容易朝上，课件算不出来，只能靠真实试验。互动课件在这里的作用是汇总：各组输入次数，屏幕上实时累加成全班数据，学生看着差距越来越清楚。
- **规则展示墙**：小组设计的规则拍照上传，全班投票“公平 / 不公平”，老师只挑分歧最大的一条来讨论。

### 课后：分层练习

**按错因布置练习。** 只数结果种类的学生，多做瓶盖、图钉这类“两种结果但可能性不同”的辨析；漏掉结果的学生，多做“把所有结果分给双方”的题；已经掌握的学生，挑战石头剪刀布、掷两枚硬币等需要列表的游戏。

可以直接复制的提示词：

```
请为北师大版五年级上册《谁先走》生成课后练习，分三层：
- 基础：4道判断游戏规则是否公平并说理由的题，用骰子、转盘、摸球；
- 提升：3道“修改规则使它公平”的题，其中1道是“掷到某个数就重掷”的陷阱；
- 挑战：2道需要列出所有结果的题，如石头剪刀布、同时抛两枚硬币。
要求：只用“可能性相同、大、小”描述，不出现分数或百分数；每题附答案、
所有可能结果的列举和一句话理由；不出现需要真实试验才能判断的题。
```

### 教研：AI 听课伙伴

课后把学生对“掷到 3 就重掷”的辩论发言和全班瓶盖数据交给 AI，请它分析：学生是用“列举结果”在说理，还是凭感觉？有多少学生能说出“两种结果不等于可能性相同”？

```
下面是我上北师大版五年级上册《谁先走》时的课堂记录：
①学生对“掷到3就重掷是否公平”的辩论发言；②全班各组抛瓶盖20次的数据。
（粘贴记录）
请帮我：分析学生说理时是否列出了所有结果；指出哪些发言仍在凭感觉判断；
根据各组数据和全班合计，说明小组数据与全班数据的差别；写一段300字以内的反思初稿。
```

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：谁的方法、几个球、抛几次，以第 104～106 页为准。
2. **演示不替代思考**：先让学生把点数分一分、说出几种对几种，再看模拟；瓶盖的数据必须来自学生真实试验，不能用 AI 编的数据代替。
3. **AI 出的题要过一遍**：删掉用分数表示可能性的说法；检查骰子、转盘题的结果有没有列全。

这一课最适合做成互动课件的是三处：一个可以改规则的掷骰子模拟器，学生先判断、再掷几百次验证，专门拆穿“掷到 3 重掷”这类改法；一个全班实时汇总的瓶盖数据表，看小组数据和全班数据的差别；一面规则展示墙，让每个小组的设计都能被评一评。设计时要守住“让学生先想、再动手验证”的顺序。

## 八、分层作业

括号里是答案要点。

**基础**

1. 掷一个骰子，单数甲先走，双数乙先走，公平吗？（公平，单数、双数各 3 种）
2. 掷一个骰子，点数是 1 甲先走，点数是 2～6 乙先走，公平吗？（不公平，1 种对 5 种）

**提升**

3. 练一练第 1 题（3）：自己设计一个转盘和规则，使游戏对双方都公平。（如平均分成 6 份，3 份红、3 份绿，指向红色甲赢，指向绿色乙赢）
4. 练一练第 4 题：用点数为 1～6 的扑克牌各一张，设计一个公平的规则。（如摸到单数甲赢、双数乙赢；摸到 1～3 甲赢、4～6 乙赢）

**挑战**

5. 石头剪刀布公平吗？列出所有情况说明。（9 种情况，甲赢 3 种，乙赢 3 种，平 3 种，公平）
6. 同时抛两枚硬币，两枚都正面朝上甲赢，一正一反乙赢，公平吗？（不公平。结果有正正、正反、反正、反反 4 种，甲 1 种、乙 2 种）

## 九、易错点与应对

1. **只数结果种类**：抛瓶盖有两种结果，就说公平。应对：做第 2 课时的瓶盖试验，用全班数据说话，再想一想“盖子哪一面重一些”。
2. **漏掉没人赢的结果**：说“大于 3、小于 3 一人一半”。应对：要求把六个点数逐个写出来，分给双方，剩下的单独圈出来。
3. **陷阱改法**：“掷到 3 就重掷”。应对：追问“重掷以后，谁的结果多”，再用模拟验证。
4. **用一组数据下结论**：自己组正好 10 对 10，就说瓶盖公平。应对：对比各组数据，说明次数少时结果偶然性大，要看全班汇总。

## 十、反思与说课

- **反思重点**：学生判断公平时，是先列出所有结果再数，还是凭感觉？“掷到 3 就重掷”能不能被学生自己驳倒？瓶盖试验后，有多少学生能说出“两种结果不等于可能性相同”？
- **说课可以突出**：本课沿“判断 → 修改 → 设计 → 用数据检验”展开，前三步用列举和推理，第四步用全班试验数据，把“公平就是可能性相同”讲透，也为下一课《摸球游戏》用数据推测做好铺垫。

## 常见问题

**《谁先走》这节课怎么导入比较好？**
直接用第 104 页强强和小华下象棋的情境，先让学生自己想办法决定谁先走，再出示抛硬币和掷骰子两种方法，请大家举手表态“公平吗”。先表态再讨论，学生会更想知道自己对不对。

**怎样让学生明白“两种结果”不等于“公平”？**
用第 105 页的抛瓶盖试验。先让学生猜，很多人会像笑笑一样说“两种可能，应该公平”；再同桌抛 20 次、汇总全班数据，学生会看到两种结果的次数往往差得比较明显。最后结合“盖子哪一面重一些”，说清结果有两种，可能性不一定相同。

**掷到 3 就重新掷，笑笑的方法就公平了吗？**
不公平。重掷以后，能决定谁先走的还是 4、5、6 和 1、2 这五个点数，强强 3 种，小华 2 种。要真正公平，可以改成“大于 3 和不大于 3”或“单数和双数”，让双方都是 3 种。

**新教材里《谁先走》和前后两课是什么关系？**
新版把旧版四上的可能性单元整体移走，和五上合成第八单元。《谁先走》夹在中间：前一课知道可能性有大有小，这一课用“可能性相同”判断公平；抛瓶盖又引出“用数据判断”，下一课《摸球游戏》接着用摸球数据推测盒子里哪种球多。

**AI 在这节课里最该用在哪？**
最该用在两处：一是掷骰子模拟，学生先把点数分给双方，再掷几百次验证，拆穿“掷到 3 重掷”这类改法；二是全班瓶盖数据实时汇总。瓶盖的可能性不能靠 AI 模拟，必须来自学生自己的试验。
