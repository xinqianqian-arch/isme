> **一句话备课结论**：上一课学生已经发现“积的小数位数等于两个乘数小数位数之和”，这一课把它变成一套能落笔的竖式算法：**先估一估，再按整数乘，最后数位数点小数点**。难点不在乘，而在两个“0”：积的位数不够，要在前面补 0；积的末尾有 0，要先点小数点再去掉。

## 一、教材解读

### 前后联系

- **已经学过**：四年级上册学过三位数乘两位数的笔算；本册第一单元学过“小数的末尾去掉 0，大小不变”；本单元《小数点搬家》学了小数点移动的规律，《街心广场》借助面积发现积的小数位数等于两个乘数小数位数之和。
- **本课要学**：在买包装纸和彩带的情境中，先估计再计算小数乘小数；掌握竖式算法，会处理积末尾的 0，积的位数不够时在前面补 0。
- **后面要用**：下一课《蚕丝》继续算 1.2×1.25、0.35×300，总结“计算小数乘法要注意什么”，并探究“积一定比乘数大吗”；《手拉手》说明运算顺序和运算律在小数中仍然适用；以后学小数除法的竖式、算图形面积，都以这一课的计算为基础。

上一课回答“为什么”，这一课回答“怎么算”。到这一课结束，学生应该能独立、准确地算出任意一道小数乘法。

### 版本说明

本文依据现行版（既有版）北师大版四年级下册编写，《包装》是第三单元“小数乘法”的第 4 课，在课本第 40～41 页。北师大版新修订的四年级下册计划 2027 年春季启用，届时我们会按新课本更新本文。

2022 年版课标把“能进行简单的小数、分数四则运算和混合运算，感悟运算的一致性，发展运算能力和推理意识”放在第三学段（5～6 年级）。小数乘法竖式和整数乘法竖式写法一样，只多了“点小数点”这一步，正是“运算一致性”最直观的体现：会整数乘法，小数乘法只差一个道理。

### 编排意图

教材第 40～41 页的线索是：**估一估 → 转化成整数乘 → 确定小数点 → 处理特殊情况 → 练习应用**。

1. **情境**：三个孩子包礼物，“包装一个礼品盒要用 0.8 米长的包装纸，还要用 2.4 米长的彩带”；包装纸每米 2.6 元，彩带每米 0.85 元。
2. **买包装纸：2.6×0.8**。男孩先估：“不到 1 米，不会超过 2.6 元。”女孩说：“我会算 26×8……”课本用箭头图表示：2.6 和 0.8 都扩大到原来的 10 倍，变成 26×8＝208，再把 208 缩小到原来的 1/100，得 2.08；旁边又写出“一位小数＋一位小数 → 两位小数”。
3. **买彩带：2.4×0.85**。女孩估：“每米不到 1 元，不会超过 2.4 元。”男孩说：“先按照整数乘法计算，再确定积的小数点位置。结果是 2.040。”课本给出 24×85 的竖式（120、1920、2040），又给出“也可以写成”的小数竖式，并提示“最后的 0 可以去掉”。
4. **尝试**：0.82×0.03 和 0.05×0.2，一道积的位数不够要补 0，一道既要补 0 又要去 0。
5. **练一练**：买蛋糕（先估够不够再算）、给积点小数点、6 道竖式、比较大小、买香蕉 25 元够不够、草原牛的身高和体重。

教材每一次计算都先“估一估”，而且估的方法很一致：**一个乘数不到 1，积就不会超过另一个乘数**。这既是检验竖式结果的好办法，也为下一课《蚕丝》“积一定比乘数大吗”埋下了伏笔。练一练第 4 题比较 6.5×0.9 和 6.5，就是这个道理的直接应用。

## 二、学情分析

**已有基础**：会笔算三位数乘两位数；知道积的小数位数等于两个乘数小数位数之和；会用小数点移动的规律；知道小数末尾去掉 0 大小不变。

**可能的困难**：

1. **积的小数点和乘数的小数点对齐**：受小数加减法的影响，2.6×0.8 的积点成 20.8，小数点和上面两个乘数对齐。
2. **位数不够不补 0**：0.82×0.03，整数积是 246，只有三位数字，学生点成 0.246。
3. **先去 0 再点小数点**：2.4×0.85 的整数积 2040，先把 0 去掉变成 204，再数三位，得 0.204。
4. **不估算**：算出 20.8 元也不觉得奇怪，没想到 0.8 米包装纸不可能比 1 米还贵。
5. **整数乘法本身出错**：进位、错位，尤其是第二层积对齐的位置。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 在买包装纸和彩带的情境中，经历“估一估、算一算”的过程，掌握小数乘小数的竖式计算方法。（运算能力）
2. 能说出“先按整数乘、再数小数位数点小数点”的道理，会处理积末尾的 0 和积的位数不够时补 0。（推理意识）
3. 会用“一个乘数不到 1，积就小于另一个乘数”等方法估算，检验计算结果是否合理。（数感）
4. 能用小数乘法解决买蛋糕、买香蕉等实际问题，判断钱够不够。（应用意识）

**教学重点**：小数乘小数的竖式计算方法。

**教学难点**：确定积的小数点位置，特别是积的位数不够要补 0、积的末尾有 0 时先点后去。

## 四、教学过程

### 1. 情境导入（3 分钟）

**包一个礼品盒要花多少钱？** 出示课本第 40 页的情境，请学生找出数学信息。

![两个黏土小朋友在木桌上包礼物：左边的男孩从一卷蓝底波点包装纸上拉出一段，用黄色软尺量长度；右边的女孩正给条纹礼盒系粉色蝴蝶结；桌上还有一卷粉色彩带、一把剪刀和一个还没包的纸盒](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-04/wrapping.webp "导入画面：包一个礼盒，要量包装纸，还要量彩带。用了几米？每米多少钱？")

- 学生找出：包装纸用 0.8 米，每米 2.6 元；彩带用 2.4 米，每米 0.85 元。
- 提问：**买包装纸要多少元，怎样列式？** 学生说出 2.6×0.8，理由是“每米的价钱×米数＝总价”。

### 2. 买包装纸：先估再算（10 分钟）

1. **先估**：**会超过 2.6 元吗？** 学生说出：0.8 米不到 1 米，1 米才 2.6 元，所以不会超过 2.6 元。还可以估得更细：0.8 米比 1 米少一点，价钱也比 2.6 元少一点，2 元多。
2. **独立尝试**：学生用自己的办法算，有人用元角（2.6 元＝26 角），有人借上一课的规律，有人直接列竖式。
3. **交流课本的方法**：2.6 和 0.8 都扩大到原来的 10 倍，变成 26×8＝208；因为两个乘数一共扩大到原来的 100 倍，积就要缩小到原来的 1/100，得 2.08。
4. 关键提问：**为什么要把 208 缩小到原来的 1/100？** 学生说出：算的时候把两个乘数都扩大到原来的 10 倍，积就扩大到原来的 100 倍，所以要“还回去”。
5. **对照估算**：2.08 比 2.6 小，又是 2 元多，结果合理。请点成 20.8 的同学自己对一对：20.8 元比 1 米的价钱还贵很多，不可能。

### 3. 买彩带：积的末尾有 0（10 分钟）

1. **先估**：彩带每米不到 1 元，2.4 米不会超过 2.4 元。
2. **独立列竖式**：引导学生把 2.4 和 0.85 的末位对齐，像整数一样乘，不用管小数点对不对齐。
3. **算出整数积**：24×85，第一层 24×5＝120，第二层 24×80＝1920（课本把这一层写成 1920，末尾的 0 也可以不写，把 192 和十位对齐），合起来是 2040。
4. **点小数点**：2.4 有一位小数，0.85 有两位小数，积应该有 1＋2＝3 位小数，从 2040 的右边起数出三位，点上小数点，得 2.040；末尾的 0 去掉，是 2.04 元。

![两个竖式并排：左边 2.6×0.8，2.6 标 1 位、0.8 标 1 位，积 2.08 标 2 位，下面用两道弧从右往左数出两位，步骤写着 26×8＝208，1＋1＝2 位小数，估：0.8 不到 1，积比 2.6 小；右边 2.4×0.85，末位对齐，第一层积 120 是 24×5，第二层积 1920 是 24×80，积 2.040 标 3 位，三道弧从右往左数出三位，末尾的 0 用红线划掉，步骤写着 24×85＝2040，1＋2＝3 位小数，先点小数点，再去掉末尾的 0](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-04/vertical-two.svg "竖式按末位对齐，先当整数乘；再看两个乘数一共几位小数，从积的右边数出几位点上小数点，最后去掉末尾的 0")

5. 关键提问：**2040 末尾的 0，能先去掉再点小数点吗？** 请学生试一试：先去 0 变成 204，再数三位是 0.204 元。和估算（2 元左右）一比，明显不对。结论：**先点小数点，再去掉末尾的 0**。
6. 追问：**为什么点好小数点后，末尾的 0 可以去掉？** 学生想到第一单元学过的：小数的末尾去掉 0，小数的大小不变。

> **设计意图**：课本把“积的末尾有 0”放在第二个例题里，正好让学生面对“先去 0 还是先点小数点”的选择。让学生自己试一试错的顺序，再用估算发现 0.204 不合理，比老师直接告诉规则印象深得多。估算在这里不是额外任务，而是检查竖式的工具。

### 4. 位数不够怎么办（7 分钟）

1. **尝试**：课本第 40 页最后两题，0.82×0.03 和 0.05×0.2，学生独立算，再和同伴交流。
2. **0.82×0.03**：82×3＝246，两个乘数一共 2＋2＝4 位小数，可是 246 只有三位数字。关键提问：**数字不够数，怎么办？** 在前面补 0，再在个位写 0，得 0.0246。
3. **0.05×0.2**：5×2＝10，一共 2＋1＝3 位小数，在前面补 0，得 0.010，再去掉末尾的 0，是 0.01。这一题两个“0”都遇到了。
4. 再出一道练一练第 3 题里的 9.8×0.5：98×5＝490，两位小数，点成 4.90，再去 0，是 4.9。

![三行跳格子图：0.82×0.03，82×3＝246，要 4 位小数，格子里依次是绿色的 0（写 0）、红色的 0（补 0）、2、4、6，四道弧从右往左数，正确答案 0.0246，常见错误 0.246；0.05×0.2，5×2＝10，要 3 位小数，格子是写 0、补 0、1 和划掉的 0，正确答案 0.010＝0.01，常见错误 0.001；9.8×0.5，98×5＝490，要 2 位小数，格子是 4、9 和划掉的 0，正确答案 4.90＝4.9，常见错误 0.49](https://media.11aike.com/textbooks/bsd/grade-4/volume-2/unit-03/lesson-04/zero-cases.svg "一律先从右往左数出位数、点上小数点；数字不够就在前面补 0，点好以后末尾的 0 再去掉。顺序反了，就会得到 0.001、0.49 这样的错答案")

5. **归纳算法**，请学生用自己的话说，老师整理成三步：**一算，按整数乘法算出积；二数，看两个乘数一共有几位小数；三点，从积的右边起数出几位点上小数点**。位数不够，在前面用 0 补足；末尾有 0，先点小数点再去掉。

### 5. 练一练（8 分钟）

1. **第 1 题 买蛋糕**：淘气带了 10 元，蛋糕每千克 9.5 元，称了 0.7 千克。先估：0.7 千克不到 1 千克，不会超过 9.5 元，10 元够。再算：9.5×0.7＝6.65（元）。
2. **第 2 题 点小数点**：1.36×0.8，整数积 1088，三位小数，是 1.088；0.78×0.04，整数积 312，四位小数，位数不够补 0，是 0.0312。
3. **第 3 题 竖式**：课上选做 4.8×0.25、0.32×0.8、9.8×1.03 三道。4.8×0.25＝1.2（整数积 1200，点成 1.200 再去 0）；0.32×0.8＝0.256（补 0）；9.8×1.03＝10.094（整数积 10094，三位小数）。其余 9.8×0.5＝4.9，4.8×1.2＝5.76，0.32×1.2＝0.384 留作课后。
4. **第 4 题 比较大小**：6.5×0.9＜6.5，2.4×1.1＞2.4，1×0.95＜1×1.2，2.4×1.5＞3.4×0.55（3.6 和 1.87）。前三组不用算，看另一个乘数比 1 大还是比 1 小就能判断，请学生说说理由。

### 6. 小结（2 分钟）

1. 回到导入：包一个礼品盒，包装纸 2.08 元，彩带 2.04 元。
2. 请学生说出小数乘法的三步和两个“0”的处理方法。
3. 留一个问题给下一课：今天发现 0.8、0.85 这样小于 1 的乘数会让积变小，**积一定比乘数大吗**？下一课《蚕丝》接着研究。

## 五、趣味设计

4 个可以直接用的小设计：

1. **“一算二数三点”口令操**：说“一算”，双手握拳上下叠在一起，像竖式；说“二数”，伸出手指数位数；说“三点”，用食指在空中点一下。每做一道题，全班先做一遍口令操再动笔，三步不漏。
2. **包装小店**：教室一角布置成包装小店，价目表写着“包装纸每米 2.6 元、彩带每米 0.85 元、丝带每米 1.2 元”等。学生拿着“购物单”（比如要 0.6 米丝带），先估再算，算完到“收银台”请同伴验算。
3. **小数点侦探**：把学生常见的错答案（20.8、0.204、0.246、0.001）贴在黑板上当“案件”，小组当侦探，用估算或数位数找出“作案手法”，看哪组破案又快又有理。
4. **估算擂台**：出示一道小数乘法，先不算，学生举牌选“比 1 小”“1 到 2 之间”“2 到 3 之间”“比 3 大”，再列竖式验证，估对的加分。练的是“先估再算”的习惯。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象的算理变成可以操作的东西、让每个学生拿到适合自己的练习**。计算课的作业量大，错误又很分散，最适合让 AI 帮老师“看竖式、分错因”。

### 课前：学情前测

**看学生会不会把“位数相加”用到竖式上。** 课前发 4 道竖式：1.2×0.4、2.5×0.6、0.12×0.3、0.6×0.05。四道题分别对应“正常”“末尾有 0”“位数不够”“既补 0 又去 0”。学生拍照上传（去掉姓名），交给能识图的 AI 按错误类型归类。

可以直接复制的提示词：

```
我是小学四年级数学老师，明天要上北师大版四年级下册第三单元《包装》，
内容是小数乘小数的竖式计算：先按整数乘，再数两个乘数一共几位小数，点上小数点。
附件是学生课前小测的竖式照片（已去掉姓名），题目是：
1.2×0.4，2.5×0.6，0.12×0.3，0.6×0.05。
请帮我：
1. 逐题判断对错，把错误归为五类：整数乘法算错、积的小数点和乘数对齐、
   位数不够没补0、先去0再点小数点、末尾的0没有去掉，给出每类人数；
2. 每类挑一张最典型的竖式，说明学生可能是怎么想的；
3. 建议我在“买彩带”和“位数不够怎么办”两个环节，各重点讲哪一类错误。
```

### 课中：先估，再列竖式

**每道题都先估，再用竖式算，最后回头对一对。**

- **估算滑块**：屏幕上是 0 到 3 元的数轴，学生先把“买包装纸大约多少元”拖到数轴上，再列竖式，最后把计算结果标上去，看和估的位置差多少。
- **数位数动画**：学生算出整数积 2040 后，点击“数位数”，小数点从积的右边一格一格往左跳，每跳一格亮一道弧；跳到第三格停下，末尾的 0 才变灰。先点后去的顺序直接演示出来。
- **全班即时作答**：出示“2.4×0.85＝？A. 2.04 B. 0.204 C. 20.4”，看选项分布，请选 B 的同学说说自己是怎么点的。
- **拍照诊断**：随机抽几位学生的竖式拍照，AI 快速标出错在哪一步，老师挑一张对的、一张错的并排投屏讲。

### 课后：分层练习

**同一套算法，按错因分层。** 积的小数点和乘数对齐的学生，多做“先估再算”的题；位数不够没补 0 的学生，多做 0.0x×0.x 这类题；先去 0 再点的学生，多做整数积末尾有 0 的题；已经掌握的学生，挑战逆向题和判断题。

可以直接复制的提示词：

```
请为北师大版四年级下册《包装》生成课后练习，分三层：
```

### 教研：AI 听课伙伴

课后把前测和课后练习的错误分布一起交给 AI，请它比较课前、课后各类错误的人数变化，判断“先点后去”“位数不够补 0”这两个难点突破得怎么样，再起草教学反思初稿，老师在初稿上修改。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：情境数据、两个例题的写法和练一练题目以第 40～41 页为准。
2. **演示不替代思考**：先让学生自己估、自己点小数点，再看“数位数动画”；先播动画，学生只会照着点。
3. **AI 出的题要过一遍**：检查答案有没有算错（AI 算多位小数乘法也会出错），数据是否合理，有没有超出两位小数乘两位小数的范围。

这一课最适合做成互动课件的是三处：一条估算数轴，学生先拖出估计值、再标出计算结果，养成“先估再算再对”的习惯；一个“数位数”的分步动画，小数点从积的右边一格一格往左跳，位数不够时出现补 0 的空格，末尾的 0 在点好小数点之后才变灰；一组全班即时作答的选择题，专门暴露“先去 0 再点”和“小数点对齐”两种想法。设计时守住“让学生先估、先算，再动手验证”的顺序。

## 七、板书设计

板书结构清楚即可，用文字列出：

- **包装**
- 包装纸：2.6×0.8＝2.08（元）　估：不到 1 米，不会超过 2.6 元
- 彩带：2.4×0.85＝2.04（元）　24×85＝2040 → 2.040 → 2.04
- **小数乘法三步**：一算，按整数乘法算出积；二数，两个乘数一共有几位小数；三点，从积的右边起数出几位，点上小数点
- 位数不够，在前面用 0 补足：0.82×0.03＝0.0246
- 末尾有 0，先点小数点再去掉：0.05×0.2＝0.010＝0.01

## 八、分层作业

括号里是答案要点。

**基础**

1. 用竖式计算：4.8×1.2，0.32×1.2，2.5×0.04。（5.76；0.384；整数积 100，三位小数，0.100＝0.1）
2. 给积点上小数点：3.5×0.6，整数积 210；0.24×0.05，整数积 120。（2.10＝2.1；0.0120＝0.012）

**提升**

3. 妈妈想买 3.8 千克香蕉，每千克 5.90 元，25 元够吗？（估：6×4＝24，两个数都往大估还不到 25，够；算：5.9×3.8＝22.42 元）
4. 草原牛的身高是蒙古牛的 1.2 倍，体重是蒙古牛的 1.4 倍。蒙古牛身高 1.2 米、体重 0.33 吨，草原牛的身高、体重各是多少？（1.2×1.2＝1.44 米；0.33×1.4＝0.462 吨）

**挑战**

5. 小明算 3.6×0.25 时，把 0.25 看成了 2.5，算出 9。正确的积是多少？（乘数缩小到原来的 1/10，积也缩小到原来的 1/10，是 0.9）
6. 两个乘数都是一位小数，积可能是一位小数吗？举例说明。（可能，比如 0.5×0.2＝0.10＝0.1，积末尾的 0 去掉后只剩一位）

## 九、易错点与应对

1. **积的小数点和乘数对齐**：2.6×0.8 点成 20.8。原因是把小数加减法“小数点对齐”的经验搬过来。应对：每题先估，“0.8 米不可能比 2.6 元贵”；明确乘法竖式只要末位对齐，积的小数点靠“数位数”来点。
2. **位数不够不补 0**：0.82×0.03 写成 0.246。应对：数位数时画弧，一道弧对一个数字，数字不够就在前面补 0，个位写 0（见“位数不够怎么办”环节的跳格子图）。
3. **先去 0 再点小数点**：2.4×0.85 写成 0.204，0.05×0.2 写成 0.001。应对：坚持“先点后去”，再用估算检查；告诉学生，末尾的 0 是在数位数时“占着位置”的，点好之前不能拿走。
4. **结果没化简**：答案写成 2.040 元。不算错，但要提醒：点好小数点后，末尾的 0 可以去掉，按课本“最后的 0 可以去掉”的要求写成 2.04 元。

## 十、反思与说课

- **反思重点**：学生是不是每道题都先估？“先点后去”和“位数不够补 0”这两类题的正确率怎样？如果学生能说出“为什么要把 208 缩小到原来的 1/100”，说明算法和算理连上了；如果只会机械数位数，下一课《蚕丝》开头可以再回到积的变化讲一次。
- **说课可以突出**：本课沿着“估一估 → 转化成整数乘 → 数位数点小数点 → 处理两个 0”的主线，把上一课发现的规律落实成竖式算法；用估算检查结果的合理性，让“一个乘数不到 1，积小于另一个乘数”自然出现，与下一课《蚕丝》的探究衔接。

## 常见问题

**《包装》这节课怎么导入比较好？**
用包礼物的情境：请学生说说包一个礼盒要买什么、用多少，再从课本第 40 页找出“包装纸每米 2.6 元，用 0.8 米”。先问“会超过 2.6 元吗”，让估算成为第一步，后面算出结果才有东西可以对照。

**积的末尾有 0 时，为什么要先点小数点再去 0？**
因为积的小数位数是从整数积的右边数出来的，末尾的 0 在数的时候也占一位。2.4×0.85 的整数积是 2040，要数出三位，得 2.040，再去 0 是 2.04；如果先去 0，就成了 204，再数三位变成 0.204，只有正确结果的 1/10。

**小数乘法竖式要不要小数点对齐？**
不用。小数加减法要小数点对齐，是为了相同数位相加减；小数乘法是先当成整数来乘，所以按末位对齐写更方便，积的小数点最后靠“数两个乘数一共几位小数”来点。

**教材为什么先算 2.6×0.8，再算 2.4×0.85？**
2.6×0.8 是一位小数乘一位小数，积不用处理 0，适合先把“转化成整数乘、再缩小”的道理讲清；2.4×0.85 是一位小数乘两位小数，整数积 2040 末尾有 0，正好引出“先点后去”。最后再用 0.82×0.03、0.05×0.2 处理位数不够补 0，难度一步一步往上走。

**AI 在这节课里最该用在哪？**
最该用在“看竖式、分错因”上：课前用前测找出会把小数点对齐、会先去 0 的学生；课中拍照诊断，挑典型竖式对比讲；课后按错因出分层练习，批改时让 AI 指出错在哪一步而不是直接给答案。AI 算多位小数也会出错，答案要老师核对。
