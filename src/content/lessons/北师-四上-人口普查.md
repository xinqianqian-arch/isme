> **一句话备课结论**：这节课学大数的读写，方法就一句话：**先分级，再从高级到低级一级一级地读、写**。每一级都按个级的读法来，读完加上“亿”或“万”。真正的难点在 0：读的时候哪些 0 读、哪些不读；写的时候哪一位一个单位也没有，要写 0 占位。

## 一、教材解读

### 前后联系

- **已经学过**：二年级会读写万以内的数，知道中间有 0 读一个“零”、末尾的 0 不读；上一课整理了数位顺序表，知道四位一级。
- **本课要学**：借助分级和数位顺序表，读出亿以上的大数（如 1443497378），写出用汉字表示的大数（如一亿零一百五十二万七千四百五十三）；总结大数的读法和写法。
- **后面要用**：下一课《大豆产量》比较大数的大小、把整万整亿的数改写成以“万”或“亿”为单位；第 6 课《国庆庆典》求近似数，都建立在“会分级、会读写”的基础上。

所以这节课是全单元的“技能课”：前三课认识了计数单位和数位，这节课把它们用起来。

### 新旧教材变化

旧版北师大版四年级上册也有《人口普查》，同样借全国和各地的人口数学习读写大数，数据来自更早的人口普查。新版换成了 2020 年第七次全国人口普查的数据，全国总人口 1443497378 人。备课时有三处细节值得注意：

1. **读和写分开呈现**：北京、广东、香港的人口用数字给出，要求读；澳门、台湾、山东的人口用汉字给出，要求写。
2. **两种读数工具并列**：课本第 8 页一边是“亿级 | 万级 | 个级”的分级卡，一边是数位顺序表，学生可以任选一种。
3. **练一练换成了国际数据**：英国、加拿大、巴西、沙特阿拉伯 2022 年的人口，读写并练，并留了“收集大数信息”的开放任务。

对备课的影响：数据更新了，但方法没变。旧版教案里“分级、读、写、总结 0 的读法”的主线可以沿用，关键是让学生自己从例子里总结出读写方法，而不是先背口诀。

### 编排意图

第 8～9 页按“读数 → 写数 → 说方法 → 练一练”展开：

1. **你能读出全国总人口数吗？北京、广东、香港的呢？** 分级卡把 1443497378 分成 14、4349、7378，男孩提示“先把数分级，十四亿……”；数位顺序表上写着广东的 126012510，读作“一亿二千六百零一万二千五百一十”。
2. **你能写出澳门、台湾、山东的人口数吗？** 数位顺序表里已经示范了澳门：六十八万三千二百一十八写作 683218。台湾和山东留给学生。
3. **说一说，你是怎么读数和写数的？** 男孩说“我先把数分级，从最高一级的数……”，女孩说“请数位顺序表帮忙，借助计数单位读数或写数”。
4. **练一练**：读英国和加拿大的人口数，在数位顺序表里写巴西和沙特阿拉伯的人口数；“先读一读，再用线连起来”，六个数长得很像，专门辨析 0 的读写。

六个地区的数据挑得很有讲究：北京中间有 0（3095），广东万级、个级都有 0，香港末尾有两个 0，山东万级开头是 0。**每一个数都是一个 0 的读写难点**。

## 二、学情分析

**已有基础**：会读写万以内的数；上一课认识了数位顺序表和四位一级；知道人口普查，对“全国有多少人”“我们省有多少人”感兴趣。

**可能的困难**：

1. **不会分级，从左往右四位一分**：把 126012510 分成 1260、1251、0，读得一团糟。分级必须从个位起往左数。
2. **0 该读不读、不该读的读了**：7474200 读成“七百四十七万四千二百零零”；126012510 读成“一亿二千六百一万……”，漏了“零”。
3. **写数漏写占位的 0**：一亿零一百五十二万七千四百五十三写成 11527453，万级只写了“152”，没有补成四位。
4. **写数多写 0**：把“零”也写成一个 0，再补一个 0，写成 1001527453，多出一位。
5. **万级读完忘了加“万”**：21893095 读成“二千一百八十九三千零九十五”。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 结合人口普查数据，借助分级和数位顺序表，会读、写亿以上的大数。（数感、符号意识）
2. 经历读数、写数和交流的过程，总结出“先分级，从高级起，一级一级读写”的方法，掌握数中有 0 时的读写规则。（符号意识）
3. 能用读写大数的方法解读人口、面积等生活数据，愿意收集并交流身边的大数信息。（应用意识）
4. 了解我国人口普查的意义，感受数据在社会生活中的作用。

**教学重点**：掌握大数的读法和写法。

**教学难点**：数中间、末尾有 0 时的读法；写数时用 0 占位。

## 四、教学过程

### 1. 情境导入（4 分钟）

**全国到底有多少人？** 出示插画，介绍人口普查：2020 年，普查员走进千家万户，登记每个人的信息。

![公寓门口，一位穿浅蓝色马甲、挂着工作牌的普查员手拿平板电脑微笑着，门里奶奶、爸爸、妈妈和孩子一起迎接，孩子踮着脚好奇地看平板](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-01/lesson-04/census-visit.webp "导入画面：普查员挨家挨户登记，才得出“全国总人口 1443497378 人”这个数。先问学生：你家被登记过吗？")

- 出示全国总人口 1443497378，关键提问：**这个数你能读出来吗**？请几名学生试读，有人会卡住，有人会读错。
- 不急着纠正：“这么长的数，有没有办法读得又快又准？今天就来研究。”

### 2. 读数（12 分钟）

1. **先分级**。关键提问：**上节课的数位顺序表能帮上什么忙**？引导学生从个位起，每四位画一条竖线：14 | 4349 | 7378。
2. **一级一级读**。亿级是 14，读作“十四亿”；万级是 4349，读作“四千三百四十九万”；个级是 7378，读作“七千三百七十八”。合起来：十四亿四千三百四十九万七千三百七十八。
3. 关键提问：**每一级是怎么读的**？学生发现：都是按个级的读法读，读完加上这一级的级名。
4. 小组合作读北京、广东、香港的人口数，重点交流 0：
   - 北京 21893095：2189 | 3095，读作二千一百八十九万三千零九十五；
   - 广东 126012510：1 | 2601 | 2510，读作一亿二千六百零一万二千五百一十；
   - 香港 7474200：747 | 4200，读作七百四十七万四千二百。
5. 关键提问：**哪些 0 读出来了，哪些没有读**？学生总结：每级末尾的 0 不读，其他地方有一个或连续几个 0 都只读一个“零”。

![三个例子分别把数字按亿级、万级、个级分组上色：全国总人口 14、4349、7378 读作十四亿四千三百四十九万七千三百七十八；山东 1、0152、7453，万级开头的 0 标黄，读作一亿零一百五十二万七千四百五十三；香港 747、4200，末尾两个 0 标黄，读作七百四十七万四千二百；最下面写着读数三步](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-01/lesson-04/read-steps.svg "读大数三步：分级，从最高级读起，处理 0。标黄的 0 是本课的关键：级首、中间的 0 读一个“零”，每级末尾的 0 不读")

### 3. 写数（12 分钟）

1. 看课本示范：澳门六十八万三千二百一十八，万级写 68，个级写 3218，合起来 683218。
2. 学生独立写台湾、山东的人口数，再同桌互查。台湾：二千三百五十六万一千二百三十六，写作 23561236。
3. 重点讨论山东：一亿零一百五十二万七千四百五十三。投出学生中常见的三种写法：

![数位顺序表从十亿位到个位，下面三行写法：第一行 11527453 打叉，万级只写了 152，变成一千一百多万；第二行 1001527453 打叉，零写成 0 后又补了 0，多出一位；第三行 101527453 打勾，千万位写 0 占位，万级是 0152](https://media.11aike.com/textbooks/bsd/grade-4/volume-1/unit-01/lesson-04/write-compare.svg "正误对比：万级要写满四位。千万位一个单位也没有，就写 0 占位；写完再分级读回去，和原来的数对一对")

4. 关键提问：**万级为什么要写 0152，而不是 152**？学生说出：万级有千万、百万、十万、万四个数位，千万位上一个单位也没有，要写 0 占位；不写的话，1 就跑到了千万位，整个数变小了。
5. 关键提问：**怎样检查自己写得对不对**？——写完再四位一级分一分，读一遍，看和原来的汉字是否一样。

> **设计意图**：写数的错误在作业里才会大量暴露，课上主动把三种写法投出来，让学生自己找出“漏 0”和“多 0”的原因。“写完分级读回去”这个检查办法，比记住“哪一位没有就写 0”更管用，学生在后面的练习里会反复用到。

### 4. 说一说方法（4 分钟）

**你是怎么读数和写数的？** 结合课本第 9 页两位同学的话，师生一起总结：

- **读数**：从个位起四位一级分级；从最高级读起，每级按个级的读法读，再加上级名；每级末尾的 0 不读，其他地方一个或连续几个 0 只读一个“零”。
- **写数**：从最高级写起，按级写；哪一位一个单位也没有，就写 0 占位；写完分级读一读检查。
- 两种工具都可以：分级卡适合读数，数位顺序表适合写数。

### 5. 练一练（6 分钟）

1. 第 1 题：读英国、加拿大的人口数——66971395 读作六千六百九十七万一千三百九十五，38929902 读作三千八百九十二万九千九百零二；在数位顺序表里写巴西、沙特阿拉伯的人口数——巴西 203080756，沙特阿拉伯 32175224。
2. 第 2 题先读一读，再连线：
   - 九千六百七十二万 → 96720000（9672000 读作九百六十七万二千）；
   - 六千零八十万零七十 → 60800070（6080070 读作六百零八万零七十）；
   - 一百二十亿零八十 → 12000000080（1200000080 读作十二亿零八十）。
   追问：**一百二十亿零八十，万级四个 0，为什么只读一个“零”**？
3. 第 3 题收集大数信息，作为课后任务，贴到“祖国大数墙”上。

### 6. 小结（2 分钟）

**今天读写大数的秘诀是什么？** 学生说出：先分级，从高级起，一级一级读写，注意 0。回到导入：再读一次 1443497378，全班齐读，又快又准。

## 五、趣味设计

4 个可以直接用的小设计：

1. **分级竖线**：每人发一张写着大数的长纸条，用彩笔从个位起每四位画一条竖线，再一级一级读出来。读得又快又准的同学，可以上台当“普查播报员”，播报下一个数。
2. **我是普查员**：小组模拟人口普查，每组拿到一张“普查结果卡”（写着某地区人口的汉字），把它写成数字填进数位顺序表；另一组负责读回去核对。读写互查，0 的错误当场暴露。
3. **0 的去留**：老师读一个数，学生用手势判断 0 的读法——读出“零”的地方拍一下手，不读的 0 双手交叉。比如 7474200、126012510、12000000080。
4. **长得像的数**：课本第 2 题的六个数两两长得很像。学生两人一组，一人读一个，另一人在两个相似的数里选，选错的同学说说是哪一个 0 骗了自己。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象概念变成可以操作的东西、让每个学生拿到适合自己的练习**。读写大数是一个技能，错误类型很集中，AI 最能帮忙的是快速给错误归类，再按错因出足量的练习。

### 课前：学情前测

**看学生的 0 错在哪里。** 课前发 4 道小题：读 21893095、7474200，写“六千零八十万零七十”“一亿零一百五十二万七千四百五十三”。收集答案后交给 AI，按错因分类：分级方向错、0 该读没读、0 不该读读了、漏写占位 0、多写 0、忘加级名。

可以直接复制的提示词：

```
我是小学四年级数学老师，明天要上北师大版四年级上册第一单元《人口普查》，
内容是大数的读法和写法。下面是全班学生课前小测的答案，每行一名学生，
依次是 4 道题：读 21893095；读 7474200；写“六千零八十万零七十”；
写“一亿零一百五十二万七千四百五十三”。
（粘贴答案）
请帮我：
1. 先给出 4 道题的正确答案；
2. 把错误按“分级方向错”“该读的零没读”“不该读的零读了”“漏写占位的 0”
   “多写了 0”“忘加级名”分类，给出每类人数和一个典型答案；
3. 建议课上“读数”“写数”两个环节分别重点讲哪一类错误。
```

### 课中：先读写，再核对

**让学生先动笔，再用课件分级、核对。**

- **分级竖线**：学生先在纸上给数画分级线、读出来，课件再从个位起每四位“切”一刀，三个级分别变色，读音一级一级出现。学生对照自己的读法，看哪里不一样。
- **写数即时诊断**：学生把山东的人口数写在平板或答题卡上，课件当场汇总全班写法，把“11527453”“1001527453”“101527453”三种答案的人数投出来，请写错的同学说想法。
- **读写互转**：课件随机出一个数，一半学生读，一半学生写，然后交换核对。AI 可以帮老师现场生成一组“长得像”的数，专门考 0。

### 课后：分层练习

**按错因开处方。** 分级方向错的学生，多练“画分级线”；0 读错的学生，多练含 0 的读数；漏写、多写 0 的学生，多练在数位顺序表里写数；已经掌握的学生，挑战“只读一个零”的数怎么写出不同的数。

可以直接复制的提示词：

```
请为北师大版四年级上册《人口普查》生成课后练习，分三层：
- 基础：6 道读数题，数在亿以内，其中 2 道末尾有 0、2 道中间有 0、
  2 道某一级开头有 0，针对“0 的读法”；
- 提升：6 道写数题，给出汉字写法，其中至少 3 道需要写 0 占位
  （如一亿零三百万零五十），针对“漏写或多写 0”；
- 挑战：2 道开放题，如“用 4 个 0 和 4 个 5 组成一个八位数，只读一个零，
  能写出几个”。
要求：数不超过千亿；不涉及比较大小和改写（后面两课才学）；
每题附正确读法或写法，以及一句话说明 0 是怎么处理的。
```

还可以让 AI 把读写练习变成学生感兴趣的情境：

```
请以“我们的家乡和祖国”为主题，编 6 道小学四年级大数读写题，
配合北师大版四年级上册《人口普查》。
要求：情境可以是人口、粮食产量、高铁里程等，但所有数据必须注明
“为练习编写，非真实统计数据”；每道题的数至少有一个 0；
附答案。
```

### 教研：AI 听课伙伴

课后把学生练习的错误统计交给 AI，请它对比课前和课后的错误分布：“漏写占位 0”是否明显减少？哪一类错误还顽固？再请它根据统计起草教学反思初稿，并建议下节课课前三分钟复习哪一类题。

### 使用边界

用 AI 要守住三条边界：

1. **数据以课本和官方来源为准**：人口普查数据以课本第 8～9 页为准；AI 编的情境题数据是虚构的，要让学生知道“这是练习用的数”。
2. **演示不替代思考**：先让学生自己画分级线、自己读写，再用课件核对；先暴露错误，再讲规则。
3. **AI 出的题要过一遍**：AI 偶尔会把含 0 的数读错，答案要老师逐题核对；还要检查有没有提前出比较大小、改写的题。

这一课最适合做成互动课件的是三处：一个“分级切刀”，学生先自己画分级线，再点一下让课件从个位起四位一切、三级变色、逐级出读音；一个写数即时汇总板，全班写完同一个数后当场显示几种写法和人数；一组“0 的去留”判断题，学生点选哪个 0 要读，课件即时反馈。设计时守住“让学生先想、再动手验证”的顺序。

## 八、分层作业

括号里是答案要点。

**基础**

1. 读出下面各数：21893095，7474200，60800070。（二千一百八十九万三千零九十五；七百四十七万四千二百；六千零八十万零七十）
2. 写出下面各数：二千三百五十六万一千二百三十六，六十八万三千二百一十八。（23561236；683218）

**提升**

3. 写出下面各数，并说说哪一位写了 0 占位：一亿零三百万零五十，五千零六万。（100300050，千万位、十万位、万位、千位、百位、个位写 0；50060000，百万位、十万位和个级都写 0）
4. 下面的读法对吗？错的改正。7000400 读作七百万四百（✗，个级开头的 0 要读，应读作七百万零四百）；30500000 读作三千零五十万（✓）。

**挑战**

5. 用 4 个 0 和 4 个 8 组成一个八位数，要求一个零也不读，写出两个。（0 只能放在每级的末尾，如 88880000、88808000、88008800、80008880）
6. 收集一条家乡的大数，写出读法，说说其中的 0 是怎么处理的。

## 九、易错点与应对

1. **从左往右分级**：把 126012510 分成 1260、1251、0。应对：口诀“分级从个位起”，画分级线时手指先放在个位，往左数四位画一条。
2. **该读的零漏读**：126012510 读成“一亿二千六百一万……”。应对：读之前先圈出所有的 0，再判断它在级末还是级中、级首。
3. **末尾的 0 也读出来**：7474200 读成“……四千二百零零”。应对：用“每级末尾的 0 不读”去判断，读完再按读法写回去，看会不会多出 0。
4. **写数漏写、多写 0**：一亿零一百五十二万七千四百五十三写成 11527453 或 1001527453（见上面的正误对比图）。应对：除最高级外，每一级都要写满四位；写完分级读回去检查。

## 十、反思与说课

- **反思重点**：学生能不能说出“哪些 0 读、哪些不读”的理由，而不只是记口诀？写数时会不会主动用“分级读回去”检查？课后练习里“漏写占位 0”的比例是否明显下降？
- **说课可以突出**：本课用第七次全国人口普查的真实数据，沿“读数 → 写数 → 总结方法”的线索展开；借上一课的数位顺序表和分级，把大数的读写转化为“一级一级按个级读写”；以 0 的读写为难点，通过学生的错误写法对比来突破。

## 常见问题

**《人口普查》这节课怎么导入比较好？**
从人口普查本身导入：普查员挨家挨户登记，最后得出全国总人口 1443497378 人。直接让学生读这个数，读不出来、读不准的困难，就是本课要解决的问题。

**怎样教学生读含 0 的大数？**
先分级，再判断每个 0 在哪里：每级末尾的 0 不读，其他地方一个或连续几个 0 只读一个“零”。读之前先把所有 0 圈出来，逐个判断，比背口诀更可靠。

**写大数时为什么总漏写 0？**
因为学生按汉字直接往下写，“一百五十二万”就写成了 152，没意识到万级要写满四位。教学生“除最高级外每级写满四位”，并且写完一定分级读回去检查。

**新教材的《人口普查》和旧版有什么不同？**
课题和读写方法没有变，数据换成了 2020 年第七次全国人口普查。新版的特点是读、写分开呈现，分级卡和数位顺序表两种工具并列，练一练用了英国、加拿大、巴西、沙特阿拉伯的人口数据，还专门安排了六个“长得像”的数辨析 0 的读写。

**AI 在这节课里最该用在哪？**
最该用在“错因归类”上：课前小测、课中写数、课后练习的错误交给 AI 分类，老师就能针对“漏写占位 0”“0 读错”分别开处方。AI 偶尔会把含 0 的数读错，答案要老师核对。
