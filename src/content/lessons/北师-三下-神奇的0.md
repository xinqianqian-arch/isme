> **一句话备课结论**：“0 乘任何数都得 0”学生一听就会背，难的是两件事：一是**说得出为什么**，而不是和“0 加任何数还得原数”搅在一起；二是竖式里遇到中间的 0，**知道 0 所在的那一位也要乘、也要写**，有进位时还要加上进位。208×4 是全课最该停下来的一道题。

## 一、教材解读

### 前后联系

- **已经学过**：一年级就认识了 0，会算 0 的加减；本单元前两课学了两、三位数乘一位数的不进位和进位竖式。
- **本课要学**：理解并说明“0 乘任何数都得 0”，和 0 的加、减区分开；会算乘数中间或末尾有 0 的两、三位数乘一位数。
- **后面要用**：下一课《去奶奶家》的“练一练”就有 260×3、209×4 这样的竖式；单元“整理与复习”（第 17 页）的“我的问题”还会追问“0 乘任何数等于 0，0 除以任何数呢？”；四年级上册学乘两位数时，因数中间有 0 的漏乘问题会再次出现。

**中间的 0 写不写、进位加不加，是后面所有含 0 计算的“老问题”，这节课要先立好规矩。**

### 新旧教材变化

旧版北师大教材里，这部分内容在三年级上册第六单元“乘法”，课题是《0×5=？》。新版放在**三年级下册第一单元“整数乘法（一）”**，课题改成《神奇的0》，排在进位乘法《去游乐园》之后。

新版第 7～8 页的编排有三个特点：

1. **用三组算式串引出 0 的乘法**：3×3、2×3、1×3、0×3；8×30、8×20、8×10、8×0；200×3、200×2、200×1、200×0。学生顺着规律就能推出乘 0 的结果。
2. **竖式按“末尾有 0”“中间有 0”“有没有进位”排了四道**：240×2、130×5、203×3、208×4，从易到难，正好覆盖四种情况。
3. **把 0 的加、减放在同一课比较**：第 8 页有 0+50、25−0 这样的算式，请学生说说发现了什么。

对备课的影响是：这节课不只是“记住一条规律”，而是一节**推理课加计算课**。要给学生时间用两种方法说理，也要在 208×4 这类题上放慢节奏。

### 编排意图

教材的主线是：**先推出规律，再用到竖式里，最后和加减比一比**。

1. **两条路推出 0×3=0**：一条是看算式串的规律，乘数每少 1，积就少一个 3，最后得 0；一条是用乘法的意义，0×3 就是 3 个 0 相加。
2. **概括**：0 乘任何数都得 0，0×□ 里填什么都一样。
3. **用到竖式里**：末尾有 0（240×2、130×5），中间有 0（203×3、208×4）。
4. **对比**：0 加任何数、任何数减 0，结果还是原来的数，和乘 0 不一样。

![左边看规律：3×3＝9、2×3＝6、1×3＝3、0×3＝0，每次少 3；右边想意义：0×3 表示 3 个 0 相加，0＋0＋0＝0，所以 0×3＝0，8×0、200×0 也得 0；下方结论：0 乘任何数都得 0，对比 0＋5＝5、5－0＝5](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-01/lesson-03/zero-pattern.svg "两种想法都能说明 0×3＝0：看规律是推出来的，想意义是解释出来的")

这一课的价值在于**推理**：学生不是从老师那里“接到”一条规律，而是自己从算式串里推出来，再用乘法的意义检验它。

## 二、学情分析

**已有基础**：会算 0 的加减；会写不进位、进位的乘法竖式；知道乘法表示几个几相加。

**可能的困难**：

1. **乘 0 和加 0 混淆**：0×9 写成 9，或把 5+0 算成 0。学生记住了“0 很特别”，却分不清在哪种运算里特别。
2. **只会背、说不出理由**：问“为什么 0×3=0”，只会说“老师说的”。
3. **中间的 0 漏写**：203×3 写成 69，602×4 写成 248，十位 0×3 得 0 后没有写 0 占位。
4. **中间有 0 又有进位**：208×4 中，十位 0×4=0，忘了加个位进上来的 3，写成 802。
5. **末尾有 0 时漏写个位的 0**：130×5 写成 65，个位 0×5 得 0 却没写。

## 三、教学目标与重难点

**教学目标（核心素养导向）**

1. 通过观察算式串的规律和运用乘法的意义两种方法，理解并说明“0 乘任何数都得 0”，能区分 0 在乘法和加、减法中的不同结果。（推理意识）
2. 掌握乘数中间或末尾有 0 的两、三位数乘一位数的竖式计算，知道 0 所在数位要写 0 占位，有进位要加进位。（运算能力）
3. 能用估算判断积的大小是否合理，并用所学解决简单的实际问题。（数感）
4. 在“0 为什么神奇”的讨论中，体会数学结论要有理由，养成先想再说的习惯。

**教学重点**：理解“0 乘任何数都得 0”；乘数中间、末尾有 0 的竖式计算。

**教学难点**：乘数中间有 0 又有进位时，0 所在数位的计算和书写（如 208×4）。

## 四、教学过程

### 1. 情境导入（4 分钟）

**三个空盘子，一共有几个苹果？** 出示野餐图：毯子上摆着三个空盘子。

![草地野餐垫上并排放着三个空盘子，一个男孩挠着头，一个女孩笑着指向空盘子](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-01/lesson-03/picnic.webp "导入画面：每盘 0 个苹果，3 盘一共有几个？能用乘法算吗？")

- 提问：每个盘子里有几个苹果？3 个盘子一共有几个？
- 追问：**能用乘法算吗？怎么列式？** 学生说出 0×3，结果是 0。
- 再出示教材的“0 来啦”主题图：0 跑进了三组算式里，会发生什么？

> **设计意图**：空盘子让“0×3=0”有了看得见的意义。学生先在生活里认同这个结果，后面再用规律推理时，就会觉得“规律推出来的和我想的一样”。

### 2. 规律与意义（8 分钟）

1. 学生独立完成三组算式串，填出 0×3、8×0、200×0 的结果。
2. 关键提问：**你是怎么想的？** 收集两种说法：
   - 看规律：3×3=9，2×3=6，1×3=3，每次少 3，所以 0×3=0；8×30、8×20、8×10，每次少 80，所以 8×0=0。
   - 想意义：0×3 是 3 个 0 相加，0+0+0=0；8×0 是 8 个 0 相加，也是 0。
3. 关键提问：**0×□，□里可以填几？积是多少？** 学生填 5、100、1000……发现积都是 0。概括：0 乘任何数都得 0。
4. 请学生用“因为……所以……”说一遍理由，同桌互相听。

### 3. 和加减比一比（4 分钟）

1. 出示第 8 页的算式：0+50、0+126、0+0、25−0、100−0、526−0。
2. 关键提问：**你发现了什么？和乘 0 一样吗？** 学生说出：0 加任何数还得那个数，任何数减 0 还得那个数；乘 0 却得 0。
3. 快速抢答：0×7、7+0、7−0、0×0、0+0，学生举牌回答。

### 4. 末尾有 0（8 分钟）

1. 学生独立算 240×2、130×5。
2. 交流 240×2：个位 0×2=0，个位写 0；十位 4×2=8；百位 2×2=4。积是 480。
3. 交流 130×5：个位 0×5=0，写 0；十位 3×5=15，写 5 进 1；百位 1×5=5，加 1 得 6。积是 650。
4. 关键提问：**个位上的 0 也要乘吗？不写会怎样？** 让学生看错例 65：把 650 少写一个 0，就少了很多，估一估就能发现。

### 5. 中间有 0（10 分钟）

1. 学生独立算 203×3。交流：个位 3×3=9；十位 0×3=0，**十位写 0 占位**；百位 2×3=6。积是 609。
2. 关键提问：**十位上 0×3 得 0，这个 0 能不能不写？** 学生说出：不写就变成 69，6 跑到了十位，意思全变了。
3. 学生独立算 208×4，先不交流，老师巡视，记下十位写了几。
4. 交流：个位 8×4=32，写 2 进 3；十位 0×4=0，**再加上进上来的 3，十位写 3**；百位 2×4=8。积是 832。
5. 关键提问：**十位明明是 0×4，为什么写 3 不写 0？** 引导出：0×4 得 0，但个位进上来的 3 个十还在，要加上。
6. 小结：中间有 0，0 也要乘；没有进位就写 0 占位，有进位就写进上来的数。

> **设计意图**：203×3 和 208×4 放在一起，是这节课的关键对比。前一题十位写 0，后一题十位写 3，学生要说出两题的不同在“有没有进位”，才算真正理解 0 在竖式里的作用。

### 6. 练习小结（6 分钟）

1. “练一练”第 2 题任选两道竖式；第 4 题不算出得数，先估一估再填符号（105×6 和 600、190×5 和 1000、140×7 和 980）。
2. 考考你：判一判，错的改正。

![考考你：四道题判断对错，1. 305×3＝905；2. 420×3＝1260；3. 260×4＝104；4. 0×9＝9](https://media.11aike.com/textbooks/bsd/grade-3/volume-2/unit-01/lesson-03/quiz.svg "答案：1. ✗，十位 0×3＝0 后忘加进位 1，应为 915；2. ✓；3. ✗，漏写了个位的 0，应为 1040；4. ✗，0 乘任何数都得 0，0×9＝0")

3. 回到三个空盘子：用一句话说说今天发现的“0 的神奇”——乘 0 得 0；加 0、减 0 不变；竖式里的 0 也要乘、也要写。

## 五、趣味设计

4 个可以直接用的小设计：

1. **“0 来啦”故事线**：沿用教材里会跑的 0：它跑进乘法，碰到谁谁就变成 0；跑进加法、减法，就“隐身”了，原来的数不变；跑进竖式中间，它就站岗占位。一节课跟着 0 走三站。
2. **空手魔术**：学生张开空手表示 0。“3 只空手合起来，有几颗糖？”“8 个同学每人 0 颗糖呢？”用身体演示 0×3、8×0，再请学生自己编一个。
3. **得 0 还是不变**：卡片上写 0×7、7+0、7−0、0×0、0+0、100×0，学生快速把卡片分到“得 0”和“不变”两个篮子里，30 秒计时。
4. **占位小卫士**：算中间有 0 的竖式时，请学生在 0 所在的那一位写完后，画一面小旗，提醒自己“这一位乘过了，也写过了”。

## 六、AI 赋能

很多所谓的“AI 课件”，只是把 PPT 做得更炫。真正的 AI 赋能，应该落在老师最费时间、又最难做好的几件事上：**摸清学生真实的想法、把抽象的规律变成可以验证的东西、让每个学生拿到适合自己的练习**。这节课学生容易“会背不会说”，AI 主要用来听学生怎么说、看学生怎么错。

### 课前：学情前测

**看看学生把 0 想成了什么。** 课前发 3 道小题：① 0×6=？6+0=？6−0=？② 说一说为什么 0×6 等于这个数；③ 用竖式算 203×3。交给 AI 归类：乘加混淆、能算不能说、中间的 0 漏写、全部正确。哪一类多，就决定课上在“说理”还是“竖式”上多花时间。

可以直接复制的提示词：

```
我是小学三年级数学老师，明天要上北师大版三年级下册第一单元《神奇的0》，
内容是0乘任何数都得0、乘数中间或末尾有0的竖式。
下面是学生课前小测的答案，每行一名学生（题目：①0×6、6+0、6−0；
②说一说为什么0×6等于这个数；③竖式算203×3）：
（粘贴答案）
请帮我：
1. 按问题分类：乘0和加0混淆、能算但说不出理由、竖式中间的0漏写、全部正确，
   给出每类人数和典型答案；
2. 对第②题的说理，挑出用“几个0相加”或“看算式规律”说得最清楚的3条；
3. 建议课上先突破哪一类问题，并说明理由。
```

### 课中：先猜，再验证

**规律要学生自己推出来，课件只负责“验证”和“放大”。**

- **算式串逐个出现**：课件先出示 3×3=9、2×3=6、1×3=3，停住，请学生预测下一个算式和积，说出理由后再点出 0×3=0。8×30 这一组同样先猜后验。
- **随便乘一个数**：学生上台在课件里输入任意数，比如 999 或 12345，再乘 0，结果总是 0。“任何数”不再是一句空话，而是学生自己试出来的。
- **竖式逐步高亮**：算 208×4 时，课件每一步先停住，问“十位写几？”，全班选 A. 0、B. 3、C. 8，看完选项分布再点下一步。分歧大的地方，就请选 0 的同学和选 3 的同学各说理由。
- **说理收集**：请每个学生写一句“为什么 0 乘任何数都得 0”，AI 帮老师把说法分成“用规律”“用意义”“只是重复结论”三类，挑典型的投屏讨论。

### 课后：分层练习

**按错因练，而不是多做几道。** 乘加混淆的学生，多做“得 0 还是不变”的辨析；中间 0 漏写的学生，多做中间有 0 的竖式，并要求说出 0 所在数位写的是什么；已经掌握的学生，挑战数字谜和估算判断。

可以直接复制的提示词：

```
请为北师大版三年级下册《神奇的0》生成课后练习，分三层：
- 基础：8道口算辨析，混合0乘一个数、一个数乘0、0加一个数、一个数减0，
  针对“乘0和加0混淆”的错误；
- 提升：6道竖式，末尾有0不进位、末尾有0有进位、中间有0不进位、中间有0有进位各至少1道，
  要求学生写出“0所在数位写的是几、为什么”；
- 挑战：2道题，如“□0□×4=1632，□里各是几”。
要求：只用两、三位数乘一位数；不涉及除法和“0不能作除数”；
每题附答案，竖式题逐位写出计算过程。
```

“练一练”第 1 题要求“举例说一说为什么 0 乘任何数都得 0”，可以让 AI 帮忙准备一些生活例子，老师挑选后用来启发学生：

```
请给小学三年级学生编5个生活中的小例子，说明“0乘任何数都得0”。
每个例子不超过40字，要能列出一个乘0或0乘几的算式，
例如“每个盘子里0个苹果，3个盘子一共0个”。
不要用“0不能作除数”这类超出三年级下册的内容。
```

AI 编的例子要逐个检查算式和情境是否对应，比如“3 个盘子里各 0 个”是 0×3，不要写成 3+0。

### 教研：AI 听课伙伴

课后把学生的说理句子和 208×4 的作答分布交给 AI，请它对照目标指出：用“规律”说理的学生多，还是用“意义”说理的多？208×4 十位写 0 的错误在课末是否减少？再请它起草教学反思初稿，老师补充课堂上的真实细节。

### 使用边界

用 AI 要守住三条边界：

1. **教材细节以课本为准**：三组算式串、四道竖式和“练一练”的题目都以第 7～8 页为准，不用 AI 生成的“教材原题”。
2. **演示不替代思考**：算式串一定先让学生猜，再点出答案；先放答案，推理就没有了。
3. **AI 出的题要过一遍**：检查计算结果，检查有没有提前引入除法里的 0，再发给学生。

这一课最适合做成互动课件的是三处：一组先猜后验的算式串，下一个算式要等学生说出预测才出现；一个可以随便输入数字的“乘 0 实验”，让学生自己验证“任何数”；一道逐步停顿的含 0 竖式，在 208×4 的十位停下来让全班作答。设计时要守住“让学生先想、再动手验证”的顺序。

## 八、分层作业

括号里是答案要点。

**基础**

1. 用竖式计算：302×3，150×4，207×4。（906；600；828）
2. 直接写得数：0×8，8+0，8−0，0×0。（0；8；8；0）

**提升**

3. 一辆货车每次运 205 箱苹果，运了 4 次，一共运了多少箱？（205×4＝820 箱）
4. 不用算出得数，在 ○ 里填“＞”“＜”或“＝”：305×3 ○ 900。（305 比 300 多，305×3＞300×3＝900，填“＞”）

**挑战**

5. □0□×4＝1632，□里各是几？（408×4＝1632，百位是 4，个位是 8）
6. 一个三位数乘 5，积的个位是 0。这个三位数的个位可能是几？（0、2、4、6、8）

## 九、易错点与应对

1. **乘 0 和加 0 混淆**：0×9 写成 9。原因是只记住“0 很特别”，没想清是哪种运算。应对：用“得 0 还是不变”的分类活动，每次都说出“几个 0 相加”或“加上 0 等于没加”。
2. **中间的 0 漏写**：602×4 写成 248。原因是觉得 0 乘出来是 0，“没东西可写”。应对：强调 0 也要写，用来占位；算完估一估，积比 602 还小，肯定不对（见下图）。
3. **中间有 0 又有进位**：208×4 写成 802。原因是看到 0×4=0 就直接写 0，忘了进位。应对：口令“先乘再加”，0 也不例外；把 203×3 和 208×4 放在一起对比。
4. **末尾的 0 漏写**：130×5 写成 65。原因是把个位的 0 当成“不用算”。应对：从个位乘起，第一步就写下个位的 0；用估算检查数量级。

## 十、反思与说课

- **反思重点**：学生能不能用“规律”或“意义”说出 0×3=0 的理由？208×4 十位写 3 的理由能不能说清？如果只会背结论、竖式靠模仿，说明推理和对比环节还不够。
- **说课可以突出**：本课沿着“两条路推出规律 → 用到含 0 的竖式 → 和加减对比”的主线展开，用算式串培养推理意识，用 203×3 和 208×4 的对比突破“中间有 0 又有进位”的难点，和新教材第 7～8 页的编排一致。

## 常见问题

**《神奇的0》这节课怎么导入比较好？**
可以从三个空盘子导入：每盘 0 个苹果，3 盘一共几个？学生自然列出 0×3=0。再出示教材里“0 来啦”的主题图，让 0 跑进三组算式串，引出“乘 0 会发生什么”。

**怎样让学生理解“0 乘任何数都得 0”？**
用两条路说理：一是看算式串，3×3、2×3、1×3 每次少 3，推出 0×3=0；二是用乘法的意义，0×3 就是 3 个 0 相加。再让学生在课件里随便输入一个大数乘 0，验证“任何数”都成立。

**0 乘一个数和 0 加一个数有什么不同？**
0 乘任何数都得 0，比如 0×7=0；0 加任何数还得那个数，比如 0+7=7；任何数减 0 也还得那个数。教材第 8 页专门把加减放在这里对比，可以用“得 0 还是不变”的分类游戏帮学生分清。

**新教材为什么用三组算式串引出 0 的乘法？**
三组算式串（3×3 到 0×3、8×30 到 8×0、200×3 到 200×0）让学生从规律中推出乘 0 的结果，再用乘法意义检验，体现了“先推理、再验证”的思路，比直接告诉结论更能培养推理意识。

**AI 在这节课里最该用在哪？**
最该用在“听学生怎么说理”和“看学生怎么错”上：课前前测分出乘加混淆和中间 0 漏写，课中用先猜后验的算式串和逐步停顿的竖式让学生先想，课后按错因生成含 0 的分层练习。AI 编的题和例子都要核对。
