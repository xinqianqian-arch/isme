课程页面依据 `content/textbooks/bsd/catalog.json` 自动生成。课时资料可在这里使用 Markdown 逐项增强，文件名采用稳定引用 ID：

`bsd-g4v1-unit-04-lesson-02.md`

示例：

```markdown
---
courseStatus: published
publishSeo: true
videoUrl: ""
shopUrl: ""
---

## 本讲原创教学设计

至少编写 250 字的真实独立内容，详细说明本课目标、分镜、互动演示、练习和易错点。只有发布状态与独立原创内容满足条件，课时页才加入搜索索引。

```

`publishSeo: true` 不等于立即被搜索引擎收录，仅允许该页面参与 Sitemap。未加入完整内容的课时仍可通过教材目录访问，但自动标记 `noindex,follow`。
